# apt: добавить репозиторий

Мы уже говорили, что репозиториев может быть несколько. Добавить свой —
дело двух шагов:

1. Положить строку описания в `/etc/apt/sources.list.d/<имя>.list`.
2. Выполнить `sudo apt update`, чтобы apt пересобрал индексы.

Полноценный сторонний репозиторий (например, Docker) требует ещё
установить ключ подписи и `signed-by=...` — но принцип тот же.

## Задание

Два этапа:

1. Создайте файл `/etc/apt/sources.list.d/custom.list` со строкой:

       deb http://deb.debian.org/debian trixie main

2. Обновите список пакетов.

Нажмите **Enter**.
