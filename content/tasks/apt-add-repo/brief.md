# Сторонний репозиторий

Репозиторий — это сервер, где лежат пакеты и их список. apt знает только те репозитории,
что записаны у него в настройках: основной список Debian — в `/etc/apt/sources.list` или
`/etc/apt/sources.list.d/debian.sources`, а подключённые позже — отдельными файлами в
`/etc/apt/sources.list.d/`. Посмотреть можно обычным `cat`.

Но в Debian есть не всё. Docker, Google Chrome, VS Code выпускают свежие версии быстрее, чем
они попадают в Debian, — поэтому держат **свой** репозиторий. Чтобы apt им пользовался, нужны
две вещи:

- **запись** о репозитории — адрес сервера и какой раздел брать;
- **ключ подписи** — по нему apt проверяет, что пакеты и правда от производителя, а не
  подменены по дороге. Без ключа apt такому репозиторию не поверит.
