# .deb: установка «руками»

Все пакеты в Debian/Ubuntu — это `.deb`-файлы. По сути архив с:

- контрольной информацией (зависимости, версия);
- скриптами установки/удаления;
- собственно файлами.

Установить из готового `.deb` умеет `dpkg` — низкоуровневый установщик,
на котором стоит apt. Разница между ними одна, но важная: `dpkg` ставит
ровно этот файл и **не умеет** доставать зависимости из репозитория, а
`apt` — умеет:

    sudo dpkg -i пакет.deb          # только сам файл; зависимости — твоя забота
    sudo apt install ./пакет.deb    # файл + всё, чего ему не хватает

Если `dpkg` уже остановился на зависимостях, положение спасает
`sudo apt -f install` (fix-broken): apt доставит недостающее и завершит настройку.
Проверить состояние пакета: `dpkg -s имя`.

Скачать файл из терминала можно `wget` или `curl -O`.
