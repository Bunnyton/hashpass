# apt — пакетный менеджер

`apt` устанавливает и обновляет пакеты. Основные команды:

    sudo apt update              # обновить список репозиториев
    sudo apt install firefox     # установить пакет
    sudo apt remove firefox      # удалить пакет
    sudo apt-get install ...     # старый синоним (тоже работает)

Пакет — это архив с зависимостями и файлами. Список пакетов, доступных
для установки, хранится локально и обновляется командой `apt update`.
