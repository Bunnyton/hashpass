# apt

Есть ещё одна команда, с которой не могу тебя не познакомить, — `apt`, пакетный менеджер:
программа, которая устанавливает пакеты (программы) и управляет ими. Например, firefox:

    sudo apt install firefox

Кстати, старая версия этой команды — `apt-get`, её до сих пор можно использовать.

Но откуда берутся приложения? Они скачиваются из **репозиториев** — хранилищ пакетов.
Репозиториев может быть несколько, и версии пакетов в них разные; ставится самая свежая
из тех, о которых apt **знает**.

А знает он то, что узнал в последний раз. Если ты обновлял список 4 месяца назад, то
`sudo apt install firefox` поставит ту версию, что была доступна 4 месяца назад. Чтобы
получить самую свежую, сначала обновляют список:

    sudo apt update
    sudo apt install firefox

Можно поставить и конкретную версию: `sudo apt install python3.13=3.13.5-2`.

Что делает пакет `sl` — не смотри заранее, пусть будет сюрприз.
