# Шпаргалка по apt и dpkg

← [apt: откуда берутся программы](../wiki.md)

## Смотреть (root не нужен)

| Команда | Что делает |
|---|---|
| `apt search слово` | найти пакет по имени и описанию |
| `apt search --names-only '^имя'` | только по имени |
| `apt show пакет` | описание, размер, зависимости |
| `apt list --installed` | что установлено |
| `apt list --upgradable` | что можно обновить |
| `apt-cache policy пакет` | какая версия стоит, какая поставится и откуда |
| `apt-cache depends пакет` | от чего зависит |
| `apt-get -s install пакет` | что *было бы* при установке — без изменений |
| `dpkg -l пакет` | состояние пакета: `ii` стоит, `rc` удалён, остались настройки |
| `dpkg -L пакет` | какие файлы принёс пакет |
| `dpkg -S /путь/к/файлу` | из какого пакета файл |

## Менять (с sudo)

| Команда | Что делает |
|---|---|
| `apt update` | скачать свежие списки пакетов |
| `apt upgrade` | обновить установленные пакеты |
| `apt install пакет` | установить (с зависимостями) |
| `apt install пакет=версия` | установить конкретную версию |
| `apt remove пакет` | удалить, настройки в `/etc` оставить |
| `apt purge пакет` | удалить вместе с настройками |
| `apt autoremove` | убрать зависимости, которые больше никому не нужны |
| `apt -f install` | доделать прерванную установку, достать недостающие зависимости |
| `dpkg -i файл.deb` | поставить ровно этот файл, без зависимостей |

## Полезные ключи

| Ключ | Что делает |
|---|---|
| `-y` | не спрашивать «Do you want to continue?» |
| `-s` | только показать, что будет (у apt-get) |
| `--no-install-recommends` | не ставить рекомендованные пакеты — только обязательные |
