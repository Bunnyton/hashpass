# Массивы

Переменная хранит одно значение. Когда значений много — список серверов, людей, файлов, —
нужен **массив**: одна переменная с пронумерованными ячейками.

    langs=(bash python go)          объявить: элементы через пробел в ( )
    echo ${langs[0]}                bash — нумерация с нуля
    echo ${langs[2]}                go
    echo ${#langs[@]}               3 — сколько элементов
    echo "${langs[@]}"              все элементы
    echo "${!langs[@]}"             0 1 2 — все номера
    langs+=(rust)                   добавить в конец

Перебор с номерами — цикл по `"${!langs[@]}"`:

    for i in "${!langs[@]}"; do
        echo "$i: ${langs[i]}"
    done

Внутри `[ ]` у массива уже идёт арифметика: `${langs[i + 1]}` — следующий элемент. Остаток от
деления — `%`: `$(( 10 % 3 ))` — это 1.
