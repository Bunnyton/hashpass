# Ассоциативный массив: ключ — любая строка

В обычном массиве ключи — числа 0, 1, 2… Чтобы считать «сколько раз встретился адрес», нужен
массив, где ключ — сам адрес. Это **ассоциативный массив** (словарь в Python, объект в JS):

    declare -A age                  объявить обязательно, до первой записи
    age[Аня]=25
    age[Боря]=31
    echo ${age[Аня]}                25
    echo "${!age[@]}"               все ключи (в случайном порядке)

Счётчик по ключу:

    declare -A seen
    seen[$word]=$(( ${seen[$word]:-0} + 1 ))     ${…:-0}: нет ключа — значит 0

А разложить строку на поля умеет `read` — по переменной на слово, остаток — в последнюю:

    read -r date time level msg <<< "2026-11-03 10:00:01 WARN диск заполнен"
    echo $level                     WARN
