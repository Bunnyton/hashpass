# Как искать ошибку в скрипте

Скрипт сломался — не гадай, а спроси у инструментов. Три по порядку:

1. **Прочитай сообщение целиком.** bash пишет файл, номер строки и что ему не понравилось:

       ./deploy.sh: line 12: cd: /srv/app: No such file or directory

2. **Посмотри, что выполняется на самом деле.** `bash -x скрипт` печатает каждую команду
   перед запуском, уже с подставленными значениями (строки с `+`):

       + cp /home/anya/report.txt /backup/
       + echo готово

   Видно, что лежало в каждой переменной. Только часть скрипта — `set -x` … `set +x` внутри.
3. **Спроси анализатор.** `shellcheck скрипт` читает скрипт, не запуская, и знает сотни
   типичных ошибок bash: у каждой код (`SC2086`) и страница с объяснением на
   www.shellcheck.net/wiki.

Почини — значит поправь сам файл (vim или любой редактор) и запусти снова: вывод должен быть
правильным.
