# Концы строк Windows

Windows заканчивает строку двумя символами: `\r\n` (возврат каретки и перевод строки), Linux —
одним `\n`. Для bash `\r` — обычный символ, часть последнего слова в строке:

1. Первая строка — `#!/bin/bash\r`: программы `bash\r` нет — «required file not found» (или
   «bad interpreter»).
2. `do\r` — не ключевое слово `do`, отсюда «syntax error near unexpected token».
3. Глазом `\r` не видно. Видно так: `cat -A файл` показывает его как `^M` перед `$` в конце
   строки; `file файл` скажет «with CRLF line terminators».

Убрать — заменить `\r` в конце каждой строки на ничего: `sed -i 's/\r$//' файл`. Есть и
утилита `dos2unix`.
