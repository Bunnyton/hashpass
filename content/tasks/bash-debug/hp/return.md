# return — это код, а не значение

Функция bash ведёт себя как маленькая программа:

1. `return N` — **код возврата** от 0 до 255, как `exit` у программы. Строку туда не положить:
   «numeric argument required».
2. Результат функция **печатает** — `echo`, а вызывающий забирает вывод через `$( )`:

       upper() { echo "${1^^}"; }
       name=$(upper anya)            ANYA

3. `return` без числа просто выходит из функции (с кодом последней команды). Нужен, когда
   после ответа функция не должна делать ничего больше.

Переменные функции объявляют `local` — иначе они видны всему скрипту.
