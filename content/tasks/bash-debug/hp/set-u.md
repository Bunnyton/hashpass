# set -u: опечатка — это ошибка

По умолчанию bash подставляет вместо несуществующей переменной **пустую строку** и идёт дальше.
`"$CAHCE_DIR"/*` превратилось в `/*` — весь корень. С `rm` вместо `echo` это катастрофа.

Строгий режим включают в начале скрипта, сразу после `#!`:

    set -euo pipefail

- `-u` — несуществующая переменная = ошибка, скрипт останавливается и называет её;
- `-e` — скрипт останавливается на первой упавшей команде, а не идёт дальше вслепую;
- `-o pipefail` — конвейер считается упавшим, если упало любое его звено, а не только
  последнее.

Ещё одна страховка для опасных мест — `${VAR:?}`: «пустая или не задана — остановись».
`rm -rf "${CACHE_DIR:?}"/*` никогда не станет `rm -rf /*`.
