# Окружение

Программа редко работает сама по себе: ей нужно знать, кто её запустил, где его домашний
каталог, на каком языке с ним говорить. Всё это она получает при запуске.

1. Когда одна программа запускает другую, она передаёт ей **окружение** — список строк
   `ИМЯ=значение`.
2. Оболочка, в которой ты работаешь, тоже его получила — при входе в систему.
3. Программа читает из окружения то, что ей нужно, — на любом языке: в C это `getenv`, в
   Python — `os.environ`, в Node.js — `process.env`.

Посмотреть:

    env                 всё окружение, по строке на переменную
    printenv            то же самое
    printenv LANG       одна переменная
    echo $LANG          одна переменная — её подставит оболочка

Своя переменная:

    GREETING=привет     без пробелов вокруг =
    echo $GREETING

Имена переменных по традиции пишут большими буквами.
