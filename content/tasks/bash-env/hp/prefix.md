# Переменная на одну команду

`export` меняет окружение оболочки — и всех, кого она запустит потом. Когда значение нужно
только одной программе, его пишут **перед командой**:

    LANG=C ls --help              ls получит LANG=C, оболочка — нет
    A=1 B=2 программа             несколько — через пробел

Оболочка после такой команды осталась прежней. А если переменная уже лишняя:

    unset GREETING                убрать её совсем
