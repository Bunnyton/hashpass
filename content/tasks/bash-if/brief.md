# Код возврата и if

Каждая программа, завершаясь, отдаёт оболочке число — **код возврата**.

1. `0` — всё хорошо. Любое другое число — что-то пошло не так (какое именно — у каждой программы
   своё, обычно в `man`, раздел EXIT STATUS).
2. Код последней команды лежит в `$?`:

       ls /etc > /dev/null; echo $?          0
       ls /nope 2> /dev/null; echo $?        2

3. `if` запускает команду и смотрит на её код: `0` — выполняет ветку `then`, иначе — `else`.

       if grep -q root /etc/passwd; then
           echo есть
       else
           echo нет
       fi

`grep -q` ничего не печатает — только отвечает кодом. Многие программы умеют так же: проверяют и
молчат. `gzip -t архив` проверяет целостность сжатого файла: у целого молчит и выходит с `0`,
у битого ругается. Ругань не нужна — её прячут в `2>/dev/null`.

Как и цикл, `if` пишут в одну строку через `;`: `if команда; then …; else …; fi`.
