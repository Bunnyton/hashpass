# [ ] — это тоже команда

`[` — не скобка в синтаксисе bash, а **команда** (её второе имя — `test`). Она проверяет условие
из своих аргументов и отвечает кодом: `[ 5 -gt 3 ]` — это команда `[` с аргументами `5 -gt 3 ]`.

1. `if` умеет проверять **любую** команду: `if gzip -t "$f"` — уже условие.
2. `if [ gzip -t "$f" ]` спрашивает не gzip, а `[`: «что значит `gzip -t файл`?» — и `[` не
   понимает такого выражения.
3. `[ ]` нужен, когда спрашиваешь о файлах, строках и числах — сама по себе такой команды нет.
