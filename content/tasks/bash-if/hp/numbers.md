# Числа в [ ] — буквами

Внутри `[ ]` знаки `>` и `<` — это **не сравнение**. Для оболочки `>` везде перенаправление:
`[ $size > 50000 ]` значит «выполни `[ $size ]` и выведи результат в файл `50000`». Файл
появился, а `[ $size ]` всегда успешна — вот все архивы и «больше».

Числа в `[ ]` сравнивают буквами:

    -eq  равно       -ne  не равно
    -gt  больше      -ge  больше или равно
    -lt  меньше      -le  меньше или равно

Есть и другие формы: `(( size > 50000 ))` — арифметика bash, там `>` настоящий; `[[ ]]` — проверка
bash, где `>` сравнивает **строки** по алфавиту («9» > «10»). Размер файла в байтах печатает
`stat -c %s файл`.
