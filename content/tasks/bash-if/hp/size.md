# Размер файла и числа

1. Размер файла в байтах печатает `stat` — одним числом, если задать формат:

       $ stat -c %s /etc/hostname
       7

2. Число из вывода команды — в переменную, как ты уже делал: `size=$(команда)`.
3. Сравнить два числа умеет всё та же команда `[` — у неё для этого свои операторы. Какие,
   перечисляет справка прямо в bash: `help test`, ищи слово Arithmetic.
