# Проверки файлов и elif

Вопросы о файлах задают командой `[` — она молчит и отвечает кодом:

    [ -e путь ]       существует (что угодно)
    [ -f путь ]       обычный файл
    [ -d путь ]       каталог
    [ -s путь ]       файл есть и он не пустой
    [ ! -s путь ]     ! переворачивает ответ

Пробелы обязательны: после `[`, между частями и перед `]`. Имя файла — в кавычках.

Вариантов больше двух — `elif`, проверяются по порядку до первого успешного:

    if [ -d "$p" ]; then echo каталог
    elif [ -f "$p" ]; then echo файл
    else echo другое
    fi
