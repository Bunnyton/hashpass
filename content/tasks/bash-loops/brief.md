# Цикл for

Одну и ту же команду для сотни файлов не набирают сто раз — её повторяет цикл.

1. `for` перебирает список: на каждом круге переменная получает следующее значение.
2. Список чаще всего — шаблон имён: `*.txt` оболочка раскрывает в имена файлов.
3. Тело цикла — между `do` и `done`.

    for f in *.txt; do
        echo нашёл: $f
    done

В терминале то же пишут в одну строку, разделяя части `;`:

    for f in *.txt; do echo нашёл: $f; done

Кусок значения переменной достают прямо в `${…}`:

    name=report.txt
    echo ${name%.txt}         report — хвост .txt отрезан
    echo ${name%.txt}.md      report.md
    echo ${name:0:3}          rep — 3 символа с начала (отсчёт с 0)

Прежде чем что-то двигать, полезно поставить `echo` перед командой — цикл только покажет,
что сделал бы.
