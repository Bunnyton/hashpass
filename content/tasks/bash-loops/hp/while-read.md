# Читать файл по строкам

`for n in $(cat файл)` перебирает не строки, а **слова**: вывод `cat` режется по пробелам и
переводам строк. Имя из трёх слов стало тремя «именами». Строки читают циклом `while`:

    while IFS= read -r line; do
        echo "строка: $line"
    done < list.txt

1. `read` читает из входа одну строку в переменную и успешен, пока строки есть — `while` крутится,
   пока он успешен.
2. `< list.txt` в конце подаёт файл на вход всему циклу.
3. `-r` — не трогать обратные косые, `IFS=` — не срезать пробелы по краям строки.
