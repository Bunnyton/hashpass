# Как оболочка находит команду

Ты уже знаешь: набираешь `ls` — оболочка ищет файл `ls` в каталогах из переменной `PATH`.

1. `PATH` — строка каталогов через двоеточие: `/usr/local/bin:/usr/bin:/bin`.
2. Оболочка перебирает их **по порядку** и запускает первый найденный файл.
3. Не нашла ни в одном — `command not found`, даже если файл лежит в соседнем каталоге.

Спросить у оболочки, где она нашла команду:

    which python3         путь к файлу
    type cd               ещё и встроенные: «cd is a shell builtin»

Поэтому сделать свой скрипт командой можно двумя путями:

1. положить его (или ссылку на него) в каталог, который уже есть в `PATH`;
2. добавить в `PATH` каталог, где лежат твои скрипты.

Ссылка лучше копии: скрипт остаётся там, где ты его правишь, а команда всегда запускает
свежую версию.
