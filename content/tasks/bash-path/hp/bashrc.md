# PATH — это просто переменная

`PATH` можно менять, как любую переменную окружения. Каталог добавляют **к** старому значению:

    PATH="$PATH:/opt/game/bin"      старое + новый каталог в конце

Без `$PATH` в значении ты заменишь весь список — и пропадут все команды, даже `ls`.

Но так он живёт, пока жива эта оболочка. Чтобы каталог был в каждой новой:

1. Каждая новая интерактивная `bash` при старте читает файл **`~/.bashrc`** и выполняет его
   строки, как будто ты набрал их сам.
2. Значит, нужная строка — в конец `~/.bashrc`. Там уже много чего есть: в Debian это файл
   настроек по умолчанию, его не стирают, а дописывают.
