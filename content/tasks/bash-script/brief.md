# Скрипт с аргументами

Команда без аргументов умеет одно. Команда с аргументами — сколько угодно: `cp` не знает
заранее, что копировать, ему говорят.

1. Слова после имени скрипта приходят в него как **аргументы**:

       ./greet.sh Аня "Боря Петров"

2. Внутри они лежат в специальных переменных:

       $1, $2, …       первый, второй аргумент
       $#              сколько их
       "$@"            все, каждый — отдельным словом (с пробелами внутри — тоже)

3. Перебрать все — цикл:

       for name in "$@"; do
           echo "Привет, $name"
       done

Что ещё пригодится:

    basename /home/anya/photos         photos — имя без пути
    dirname /home/anya/photos          /home/anya — путь без имени
    date +%F_%H%M%S                    2026-11-04_153012 — дата и время для имён файлов
    tar -czf архив.tar.gz -C /home/anya photos      упаковать photos, перейдя в /home/anya
    tar -tzf архив.tar.gz              что внутри

`-C` нужен, чтобы в архив попал каталог по имени, а не весь путь от корня.
