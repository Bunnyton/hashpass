# Массив из шаблона

Шаблон, записанный в скобках, превращается в массив имён — **отсортированных по алфавиту**:

    logs=(/var/log/app-*.log)
    echo ${#logs[@]}                сколько нашлось
    echo "${logs[0]}"               первое по алфавиту
    echo "${logs[@]: -1}"           последнее (пробел перед минусом обязателен)

Дата в формате `ГГГГ-ММ-ДД_ЧЧММСС` устроена так, что алфавитный порядок совпадает с порядком
времени: старые архивы — в начале массива.

Часть массива — срез `"${a[@]:начало:сколько}"`:

    "${logs[@]:0:2}"                первые два элемента
