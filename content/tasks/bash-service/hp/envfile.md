# Настройки службы — в окружении

Служба получает окружение не от твоей оболочки, а от systemd. Задать его можно в юните:

    [Service]
    Environment=LEVEL=debug                    одна переменная прямо в юните
    EnvironmentFile=/etc/default/myapp         все строки ИМЯ=значение из файла

1. В файле — строки `ИМЯ=значение`, как в оболочке, но без `export` и без подстановок.
2. Скрипт читает переменную, как любую другую: `$INBOX`. Значение по умолчанию, если её нет:
   `INBOX=${INBOX:-/home/student/inbox}`.
3. `EnvironmentFile=-/путь` с минусом — «файла может и не быть», без минуса служба без него не
   запустится.
4. systemd читает файл при **запуске** службы: поменял файл — перезапусти службу. Поменял юнит —
   сначала `daemon-reload`.
