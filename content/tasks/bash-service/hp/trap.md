# trap — сделать что-то перед смертью

`systemctl stop` посылает службе сигнал **TERM**: «заканчивай». По умолчанию bash от него просто
умирает — на середине работы, молча. `trap` назначает команды на сигнал:

    trap 'echo "выключаюсь"; exit 0' TERM

1. Команды в кавычках выполнятся, когда придёт сигнал; `exit 0` — выйти, иначе скрипт продолжит
   цикл.
2. Кавычки одинарные: переменные внутри подставятся в момент сигнала, а не в момент `trap`.
3. `trap` ставят в начале скрипта — до цикла.

Для уборки при любом выходе есть `trap '…' EXIT`: удалить временные файлы, снять блокировку.
