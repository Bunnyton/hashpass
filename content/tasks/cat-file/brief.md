# Читаем файлы

В любом Linux файлы можно просмотреть текстовым редактором. Но проще всего
взглянуть на содержимое прямо в консоли — командой:

    cat имя_файла

Например:

    cat readme.txt

Если команда «зависла» — жмите `Ctrl+C`.

## Задание

В файле `/home/student/mailbox/key_here.txt` спрятана одна строка со словом
**СЕКРЕТ**. Найдите её и сохраните эту строку (только её!) в
`/home/student/secret.txt`.

Нажмите **Enter**.
