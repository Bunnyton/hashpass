# Читаем файлы

В любом Linux файл можно открыть текстовым редактором. Но проще взглянуть на
содержимое прямо в консоли — командой:

    cat имя_файла

Например:

    cat readme.txt

Если файл длинный, а нужна одна строка, есть команда, которая печатает только
строки с нужным словом:

    grep слово имя_файла

Если команда «зависла» — жми `Ctrl+C`.

## Задание

В файле `/home/student/mailbox/key_here.txt` спрятана одна строка со словом
**СЕКРЕТ**. Покажи в терминале только её.

Нажми **Enter**.
