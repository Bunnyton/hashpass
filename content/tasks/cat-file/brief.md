# Читаем файлы

В любом Linux файл можно открыть текстовым редактором. Но проще взглянуть на
содержимое прямо в консоли — командой:

    cat имя_файла

Например:

    cat readme.txt
    cat /etc/hostname

Имя можно писать и полным путём — тогда неважно, где ты сейчас стоишь.

Если команда «зависла» — жми `Ctrl+C`.
