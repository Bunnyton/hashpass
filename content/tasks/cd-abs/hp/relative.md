# Относительные пути

Если ты в `/home/user/project/admin_tool/mne/nujno/bolshe/papok/1/2/3/4/5/6`, то подняться
на уровень выше абсолютным путём — значит набрать его почти целиком:

    cd /home/user/project/admin_tool/mne/nujno/bolshe/papok/1/2/3/4/5

Поэтому есть **относительные** пути — от того места, где ты стоишь:

    cd ..           # на уровень выше
    cd ./downloads  # в downloads внутри текущего каталога

Где ты сейчас, покажет команда:

    pwd
