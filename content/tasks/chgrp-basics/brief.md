# chgrp: смена группы

У каждого файла есть **владелец** и **группа**. Изменить их можно
командами:

    sudo chown новый_пользователь ./file
    sudo chown user:group ./file      # оба сразу
    sudo chgrp новая_группа ./file    # только группу

Свою текущую группу можно узнать командой `groups`.

В `.secret/rock.txt` спрятан секретный ключ, но файл принадлежит группе
`FiveFingerDeathPunch`, а ты в ней не состоишь — `cat` его не откроет.
