# Владелец и группа

У каждого файла есть **владелец** — тот, кто может менять права (помимо
всемогущего root), — и **группа**. Новому пользователю по умолчанию создаётся
одноимённая группа; посмотреть свои группы можно командой:

    groups

Пользователь может состоять в нескольких группах — так управляют доступом
сразу для многих.

Сменить владельца может только суперпользователь:

    sudo chown new_user ./file.txt
    sudo chown new_user:new_group ./file.txt    # сразу и группу

А чаще пользуются командой попроще — только для группы:

    chgrp new_group ./file.txt
