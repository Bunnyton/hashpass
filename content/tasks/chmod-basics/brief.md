# Права доступа: chmod

Если сделать `ls -l`, слева виден набор букв вроде `-rw-r--r--`. Это
права доступа к файлу. Первая позиция — тип (`-` файл, `d` директория,
`l` символьная ссылка). Затем — **три тройки**:

    - rwx rwx rwx
      \ / \ / \ /
       u   g   o     (user, group, other)

Каждая буква:

    r — читать   (4)
    w — писать   (2)
    x — выполнять (1)

Права можно записать одной **бинарной цифрой** на каждую тройку:

    rwx = 4+2+1 = 7
    rw- = 4+2   = 6
    r-x = 4+0+1 = 5
    r-- = 4+0+0 = 4
    --x = 0+0+1 = 1

Тогда `chmod 754 file` = `rwxr-xr--`.
