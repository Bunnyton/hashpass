# Права доступа

Задумывался, почему один файл ты читаешь, а другой — нет? Это регулируют права.
Их видно слева в `ls -l`:

    -rw-rw-r--  1 anton anton  806 окт 12 22:47 notes.txt

Первая позиция — тип: `-` обычный файл, `d` директория, `l` символьная ссылка.
Дальше три тройки букв:

    -rw-rw-r--
     ^  ^  ^
     |  |  └─ права остальных пользователей
     |  └──── права группы
     └─────── права владельца

`r` — читать, `w` — писать, `x` — запускать (для директории — входить в неё);
`-` — права нет.

Право либо есть, либо нет — поэтому тройку можно записать в двоичном виде и
сложить в одну цифру:

    rwx = 4+2+1 = 7      r-x = 4+0+1 = 5      -wx = 0+2+1 = 3      --x = 1
    rw- = 4+2+0 = 6      r-- = 4+0+0 = 4      -w- = 0+2+0 = 2      --- = 0

Значит, любые права — это три цифры, и выдают их так:

    chmod 754 ./file.txt        # -rwxr-xr--
    chmod 401 ./file.txt        # -r-------x

Права меняет владелец файла (или root).
