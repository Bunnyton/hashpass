# Шпаргалка по правам

← [Права доступа и chmod](../wiki.md)

## Тройка ↔ цифра

| Буквы | Цифра | | Буквы | Цифра |
|---|---|---|---|---|
| `---` | 0 | | `r--` | 4 |
| `--x` | 1 | | `r-x` | 5 |
| `-w-` | 2 | | `rw-` | 6 |
| `-wx` | 3 | | `rwx` | 7 |

Частые наборы: `644` — обычный файл (`-rw-r--r--`), `755` — программа или каталог
(`rwxr-xr-x`), `600` — личный файл (`-rw-------`).

## Что значит право

| | У файла | У каталога |
|---|---|---|
| `r` | читать содержимое | видеть список имён (`ls`) |
| `w` | менять содержимое | создавать, удалять, переименовывать файлы в нём |
| `x` | запускать | входить (`cd`) и открывать файлы по имени |

## chmod буквами

| Запись | Что делает |
|---|---|
| `u` `g` `o` `a` | владелец, группа, остальные, все |
| `+` `-` `=` | добавить, забрать, задать ровно |
| `chmod u+x f` | владельцу — запуск |
| `chmod go-w f` | группе и остальным — без записи |
| `chmod o= f` | остальным — ничего |
| `chmod u+x,g-w f` | несколько правок через запятую, без пробелов |
| `chmod -R …` | рекурсивно, со всем содержимым каталога |

## umask — права новых файлов

Новый файл получает `666`, каталог — `777`, минус биты из **umask**:

    $ umask
    0002
    $ touch fresh.txt; mkdir freshdir; ls -ld fresh.txt freshdir
    drwxrwxr-x 2 anya anya 40 Nov  4 02:25 freshdir
    -rw-rw-r-- 1 anya anya  0 Nov  4 02:25 fresh.txt

Поэтому `x` новому файлу всегда надо выдавать руками.

## Особые биты (видны вместо x)

| Бит | Цифра | Где видно | Зачем |
|---|---|---|---|
| setuid | 4000 | `-rwsr-xr-x /usr/bin/sudo` | программа работает с правами своего владельца |
| setgid | 2000 | `drwxrwsr-x` у каталога | новые файлы получают группу каталога |
| sticky | 1000 | `drwxrwxrwt /tmp` | удалить файл может только его владелец |

    $ ls -ld /tmp
    drwxrwxrwt 59 root root 1940 Nov  4 02:25 /tmp
