# chmod: злая сторона

Помимо числовой записи `chmod 754`, у `chmod` есть **относительная**
запись:

    u — владелец (user)
    g — группа   (group)
    o — остальные (other)
    a — все три сразу
    + / -  — добавить/забрать право

Примеры:

    chmod u+r ./file       # владельцу — читать
    chmod u+rx ./file      # владельцу — читать и запускать
    chmod o-w ./file       # остальным — забрать право писать
    chmod +x ./script.sh   # всем — запускать
    chmod u+w,g+r,o-x file   # несколько наборов через запятую

В `~/target` лежат три файла — `test1`, `test2`, `test3`, — и у всех права
`---------` (000). Раздавать права им будем **только относительной записью**:
никакого `chmod NNN` — это дело чести.
