# chmod: злая сторона

Помимо побитовой записи `chmod 754`, у `chmod` есть **относительная**
запись:

    u — владелец (user)
    g — группа   (group)
    o — остальные (other)
    a — все три сразу
    + / -  — добавить/забрать право

Примеры:

    chmod u+r ./file       # владельцу — читать
    chmod u+rx ./file      # владельцу — читать и запускать
    chmod o-w ./file       # остальным — забрать право писать
    chmod +x ./script.sh   # всем — запускать
    chmod u+w,g+rw,o+r file  # несколько наборов через запятую

Начальные права всех файлов ниже — `---------` (то есть 000).
