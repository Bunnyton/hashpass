# Compose: свой образ и настройки

Свой сервис — это свой образ: в реестре его нет, есть только `Dockerfile` рядом.

## Откуда compose берёт образ

1. Образ для сервиса compose обычно берёт из реестра — по имени в `image:`.
2. Но compose умеет и **собрать** образ сам, если сказать ему, где рецепт — каталог с
   `Dockerfile`:

    services:
      api:
        build: ./api        # каталог, где лежит Dockerfile

3. Тогда `docker compose up -d` при первом запуске соберёт образ и запустит контейнер — как
   `docker build` и `docker run` в одной команде.

## Переменные окружения

Переменные окружения контейнера в `compose.yaml` задаёт раздел `environment` — то же, что
`-e` у `docker run`.
