# Переменные в compose.yaml

Значения, которые меняются от сервера к серверу, держат не в `compose.yaml`, а в отдельном
файле. Как это устроено:

1. Рядом с `compose.yaml` лежит файл **`.env`** — по строке `ИМЯ=значение`. Значение с
   пробелами берут в кавычки.
2. В `compose.yaml` на месте значения пишут `${ИМЯ}`.
3. При запуске compose подставляет вместо `${ИМЯ}` значение — как оболочка. Ищет он его в
   окружении и в `.env`.

    # .env
    NGINX_VERSION=1.27
    WEB_PORT=8080

    # compose.yaml
    services:
      web:
        image: nginx:${NGINX_VERSION}
        ports:
          - "${WEB_PORT}:80"

4. Что получилось после подстановки, покажет `docker compose config`.
