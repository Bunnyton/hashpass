# Файл с переменными целиком

`.env` подставляет значения в сам `compose.yaml`. А передать контейнеру переменные прямо из
файла, ни одной не называя в `compose.yaml`, умеет ключ сервиса **`env_file`**:

    services:
      api:
        env_file: api.env        # каждая строка ИМЯ=значение станет переменной контейнера

Так секреты держат отдельно: `compose.yaml` — в git, файл с паролями — только на сервере.
