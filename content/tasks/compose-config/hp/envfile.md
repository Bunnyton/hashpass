# Файл с переменными целиком

`.env` подставляет значения в сам `compose.yaml`. А бывает нужно другое: передать контейнеру
переменные прямо из файла, ни одной не называя в `compose.yaml`.

1. Переменные лежат в своём файле, по строке `ИМЯ=значение`.
2. У сервиса пишут ключ **`env_file`** с именем этого файла.
3. Каждая строка файла станет переменной окружения контейнера.

    services:
      api:
        env_file: api.env

Так секреты держат отдельно: `compose.yaml` — в git, файл с паролями — только на сервере.
