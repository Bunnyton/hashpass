# Несколько копий одного сервиса

Когда одному контейнеру тяжело, запускают несколько **одинаковых** — копий одного сервиса.
Как это делает compose:

1. Сколько копий нужно, говорят ключом `--scale` у `up`: `--scale <сервис>=<число>`.

    docker compose up -d --scale web=4      # четыре контейнера сервиса web

2. Копии называются по номерам: `проект-web-1`, `проект-web-2` и так далее.
3. Остальные сервисы по-прежнему обращаются к ним по имени сервиса. Склад и витрина говорят
   друг с другом по имени `stock`, а сколько копий за этим именем, им всё равно.
