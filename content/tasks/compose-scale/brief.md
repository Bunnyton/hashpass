# Несколько копий одного сервиса

Когда одному контейнеру тяжело, запускают несколько **одинаковых** — копий одного сервиса.
compose умеет это одной командой:

    docker compose up -d --scale web=4      # четыре контейнера сервиса web

Копии называются по номерам: `проект-web-1`, `проект-web-2` и так далее. Склад и витрина
говорят друг с другом по имени сервиса — `stock`, — а сколько копий за этим именем, им всё
равно.
