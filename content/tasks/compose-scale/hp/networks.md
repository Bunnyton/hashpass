# Сети в compose

По умолчанию compose заводит проекту одну сеть, `проект_default`, и сажает в неё всех. Свои
сети описывают в разделе `networks` — в корне файла, — а у сервиса перечисляют, в каких он:

    services:
      db:
        networks: [back]
      api:
        networks: [back, front]       # api — в двух сетях, мост между ними
    networks:
      back:
        internal: true                # внутренняя: без выхода наружу
      front:

**Внутренняя** сеть (`internal: true`) соединяет контейнеры между собой, но не выпускает их
наружу: ни в интернет, ни на порты машины. Поэтому сервису с проброшенным портом нужна ещё и
обычная сеть.
