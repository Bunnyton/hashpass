# Сети в compose

По умолчанию compose заводит проекту одну сеть, `проект_default`, и сажает в неё всех. Чтобы
развести сервисы по разным сетям:

1. Опиши сети в разделе `networks` — в корне файла, на одном уровне с `services`.
2. У сервиса перечисли в его собственном поле `networks`, в каких сетях он состоит. Сервис
   может быть в нескольких сетях сразу — тогда он мост между ними.
3. Сети, которой нужна изоляция, добавь `internal: true`.

    services:
      db:
        networks: [back]
      api:
        networks: [back, front]       # api — в двух сетях, мост между ними
    networks:
      back:
        internal: true                # внутренняя: без выхода наружу
      front:

**Внутренняя** сеть соединяет контейнеры между собой, но не выпускает их наружу: ни в
интернет, ни на порты машины. Поэтому сервису с проброшенным портом нужна ещё и обычная сеть.
