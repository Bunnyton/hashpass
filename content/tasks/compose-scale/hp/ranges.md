# Каждой копии — свой порт

Почему копии упали:

1. Все копии сервиса получают одинаковые настройки.
2. Записано `"8081:80"` — и все три хотят порт 8081 машины.
3. Порт машины — один на всех: его получит одна копия, остальные упадут.

Поэтому для копий в compose пишут **диапазон** портов машины:

    ports:
      - "9001-9004:80"        # четыре копии — четыре порта: 9001, 9002, 9003, 9004

Каждая копия займёт свободный порт из диапазона. Упавшие копии останутся в
`docker compose ps -a` — повторный `up` их пересоздаст.
