# Каждой копии — свой порт

Все копии сервиса получают одинаковые настройки. Записано `"8081:80"` — и все три хотят порт
8081 машины. Его получит одна, остальные упадут: порт машины — один на всех.

Для копий в compose пишут **диапазон** портов машины:

    ports:
      - "9001-9004:80"        # четыре копии — четыре порта: 9001, 9002, 9003, 9004

Каждая копия займёт свободный порт из диапазона. Упавшие копии останутся в
`docker compose ps -a` — повторный `up` их пересоздаст.
