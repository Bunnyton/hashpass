# Dockerfile

Образ собирают по рецепту — файлу `Dockerfile`. Каждая строка — инструкция:

    FROM debian          # от какого образа отталкиваемся
    COPY app.sh /app.sh  # положить файл с машины в образ
    CMD ["sh", "/app.sh"]  # что запускать в контейнере

Собрать образ с именем `myapp` из каталога `~/project`, где лежит `Dockerfile`:

    docker build -t myapp ~/project

`-t` — имя нового образа, последний аргумент — каталог с рецептом и файлами для него.
Готовый образ появится в `docker images`.
