# Образ — это снимок

Поправил программу, а контейнер всё ещё здоровается с миром? Дело вот в чём:

1. Инструкция COPY положила `greet.sh` в образ **в момент сборки** — копию файла, каким он был
   тогда.
2. Контейнеры запускаются из образа, а не из твоего каталога.
3. Поэтому правка файла на машине им не видна: в образе лежит старая копия.

Поменял что-то для образа — собери его заново той же командой `docker build`: новые
контейнеры получат новую версию.
