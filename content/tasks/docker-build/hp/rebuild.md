# Образ — это снимок

Инструкция COPY положила `greet.sh` в образ **в момент сборки**. Контейнеры запускаются из образа, а не
из твоего каталога, поэтому правка файла на машине им не видна.

Поменял что-то для образа — собери его заново той же командой `docker build`: новые
контейнеры получат новую версию.
