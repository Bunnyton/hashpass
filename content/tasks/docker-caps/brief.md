# root в контейнере — не всемогущий

Раньше в Linux было просто: root может всё, остальные — только своё. Потом «всё» разрезали
на куски — **привилегии ядра** (capabilities). Каждая разрешает одно:

    SYS_TIME          переводить системные часы
    NET_BIND_SERVICE  занимать порты ниже 1024
    KILL              посылать сигналы чужим процессам
    SYS_ADMIN         монтировать, настраивать систему — почти всё сразу

Полный список — в `man 7 capabilities`.

## Сколько привилегий у контейнера

1. Root внутри контейнера получает от docker не все привилегии, а только часть — набор по
   умолчанию.
2. Набор можно менять ключами `docker run`:

    --cap-drop ALL          сбросить все
    --cap-add  NET_ADMIN    добавить одну

## Правило безопасности

1. Сбрось всё.
2. Добавь только то, без чего сервис не работает.
3. Что ему нужно, проще всего узнать опытом: запусти без всего и прочитай в журнале, на чём
   он упал.
