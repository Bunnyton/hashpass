# «are you root?»

pinger — root внутри контейнера, но ping всё равно отвечает «permission denied». Root без
привилегий — просто пользователь с номером 0.

Чтобы посчитать время до ответа, ping собирает пакеты ICMP сам, «сырыми» — в обход обычной
сетевой обработки ядра. Это отдельная привилегия, и ты её только что сбросил вместе с
остальными. Найди её в списке `man 7 capabilities`: в имени есть RAW. Имя в `--cap-add`
пишут без приставки `CAP_`.

Контейнер с неправильными привилегиями проще удалить и запустить заново:
`docker rm -f pinger`.
