# Всё одним файлом

В README магазина — три команды, которые нужно набирать в правильном порядке и с правильными
ключами. Забыл сеть — витрина не видит склад. Перепутал порт — не открывается сайт. На
сервере таких команд десятки.

**Docker Compose** описывает все контейнеры проекта в одном файле `compose.yaml` и поднимает
их одной командой. Каждый контейнер — **сервис**:

    services:
      web:
        image: nginx
        ports:
          - "8000:80"
      db:
        image: postgres
        environment:
          POSTGRES_PASSWORD: secret

Это YAML: вложенность — отступами из пробелов (не табов), списки — строками с `- `.

    docker compose up -d     # поднять всё, что описано в compose.yaml текущего каталога
    docker compose ps        # что сейчас работает

Сеть для сервисов compose создаёт сам — и в ней каждый сервис доступен остальным по **имени
сервиса**.
