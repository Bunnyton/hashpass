# Каталоги в compose.yaml

Всё, что ты писал ключами `docker run`, в compose.yaml становится полями сервиса. Каталог,
который подключали ключом `-v`, — не исключение.

1. В записи сервиса добавь поле `volumes` — на том же уровне, что `image`.
2. Под ним — список, по строке на каталог: `- откуда:куда`, как у `-v`.
3. **Откуда** — каталог на машине. Его можно писать от каталога, где лежит сам compose.yaml:
   `./site`.
4. **Куда** — каталог внутри контейнера.

    services:
      blog:
        image: nginx
        volumes:
          - ./site:/usr/share/nginx/html

5. Сохрани файл и снова выполни `docker compose up -d`: compose сам пересоздаст только те
   контейнеры, описание которых изменилось.
