# База данных в контейнере

**redis** — база данных «ключ — значение»: держит данные в памяти и отвечает за доли
миллисекунды. Её ставят для корзин, сессий, кэша — всего, что нужно быстро. Образ `redis` уже
есть на машине.

## Имя контейнеру

База — сервер, её запускают в фоне. Чтобы потом обращаться к контейнеру не по длинному ID, ему
дают имя ключом `--name`:

    docker run -d --name napper busybox sleep 600    # контейнер с именем napper
    docker ps                                         # имя — в последней колонке

## Как говорить с redis

С базой говорят через программу `redis-cli`:

    redis-cli SET city "Нижний Новгород"     # сохранить значение под ключом city
    redis-cli GET city                       # прочитать его
    redis-cli KEYS '*'                       # какие ключи есть

Значение из нескольких слов берут в кавычки — иначе это несколько значений.

## Команда внутри контейнера

`redis-cli` живёт не на машине, а внутри контейнера, рядом с базой. Чтобы до неё добраться:

1. Контейнер должен работать — `docker ps` покажет его.
2. `docker exec` выполняет команду в работающем контейнере: сначала имя контейнера, следом
   команда.
3. Вывод команды приходит к тебе на экран, как у `docker run`.

    docker exec <контейнер> <команда>
