# База данных в контейнере

**redis** — база данных «ключ — значение»: держит данные в памяти и отвечает за доли
миллисекунды. Её ставят для корзин, сессий, кэша — всего, что нужно быстро.

Образ `redis` уже есть на машине. Говорят с базой через `redis-cli`:

    redis-cli SET city "Нижний Новгород"     # сохранить значение под ключом city
    redis-cli GET city                       # прочитать его
    redis-cli KEYS '*'                       # какие ключи есть

Значение из нескольких слов берут в кавычки — иначе это несколько значений.

`redis-cli` живёт внутри контейнера, рядом с базой. Выполнить команду в работающем
контейнере — `docker exec`:

    docker exec <контейнер> <команда>
