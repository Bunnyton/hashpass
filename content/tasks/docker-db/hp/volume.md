# Куда делся ключ

Новый контейнер — новая чистая файловая система из образа. Всё, что база записала, жило в
старом контейнере и удалилось вместе с ним.

Для данных, которые должны пережить контейнер, у docker есть **тома** (volumes). Два вида:

    -v /home/me/blog:/www         каталог машины (bind mount): ты сам выбираешь, где лежат файлы
    -v pgdata:/var/lib/postgresql/data
                                  именованный том: место на диске выбирает docker, ты знаешь
                                  только имя

Для баз берут именованный том: не нужно думать о путях и правах, а docker сам создаст том при
первом запуске. Списки и подробности — `docker volume ls` и `docker volume inspect <имя>`.

Кстати, образ redis сам просит том для `/data`. Если не дать ему имя, docker создаст
безымянный — в `docker volume ls` это длинный хеш. Данные там лежат, но новый контейнер их не
найдёт: он получит новый безымянный том.
