# Контейнер упал

Сервис запустили, а он не работает. Разбираются по шагам — от «что с ним» к «почему».

## 1. Что с контейнером

    docker ps -a

В колонке STATUS у упавшего — `Exited (1) …`: программа внутри завершилась с ошибкой. Ноль
в скобках — всё хорошо, любое другое число — что-то пошло не так.

## 2. Как его зовут

Контейнер называют по ID или по **имени** — оно в последней колонке `docker ps -a`.

## 3. Что он успел сказать

А **что** пошло не так, программа обычно успевает сказать. Всё, что она печатает, docker
сохраняет — даже у контейнера в фоне и даже у упавшего:

    docker logs web       # что писал контейнер web
