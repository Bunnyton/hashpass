# Настройки снаружи

Образ один на все серверы, а адрес базы на каждом свой. Поэтому такие настройки в образ не
зашивают — их передают при запуске **переменными окружения**: пара «имя=значение», которую
программа читает при старте (`$DB_URL` в скрипте).

    docker run -d -e LANG=ru_RU.UTF-8 -e PORT=8080 myapp
    docker run -d --env-file settings.env myapp     # все переменные из файла

Переменные задаются только при создании контейнера: поменять их у готового нельзя — его
удаляют и создают заново.

Имя контейнеру даёт ключ `--name` — с ним не нужно искать ID в `docker ps`:

    docker run -d --name web myapp
    docker logs web
