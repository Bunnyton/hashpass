# Заглянуть внутрь

Файл лежит внутри контейнера, а у тебя на машине его нет. Добраться до него можно так:

1. Контейнер должен работать — `docker ps`.
2. `docker exec` выполняет команду внутри работающего контейнера — как будто ты зашёл в него:

    docker exec web ls /etc            # одна команда внутри контейнера web
    docker exec -it web sh             # оболочка внутри (выход — exit)

3. Вывод `docker exec` приходит к тебе в терминал — его можно, как всегда, перенаправить в
   файл на машине.
