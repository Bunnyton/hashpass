# Заглянуть внутрь

У работающего контейнера можно выполнить команду — как будто ты зашёл в него:

    docker exec web ls /etc            # одна команда внутри контейнера web
    docker exec -it web sh             # оболочка внутри (выход — exit)

Вывод `docker exec` приходит к тебе в терминал — его можно, как всегда, перенаправить в файл.
