# Контейнер — не виртуальная машина

**Виртуальная машина** — целый компьютер внутри компьютера: у неё своё виртуальное «железо»,
своё ядро и своя операционная система. Поэтому она тяжёлая: гигабайты на диске, минута на
загрузку, и на одном сервере их помещается немного.

**Контейнер** устроен иначе. Ядро у него не своё — он работает на ядре той машины, где
запущен. Контейнер — это обычный процесс машины, которому ядро показывает свой отдельный
мир: свои файлы, свою сеть, свой список процессов. Отсюда скорость: запустить контейнер —
почти то же самое, что запустить программу.

    виртуальная машина            контейнер
    своё ядро                     ядро машины, общее на всех
    гигабайты, минуты             мегабайты, доли секунды
    любая ОС                      только Linux на Linux

Версию ядра Linux печатает `uname` — с ключом, который найдёшь в `uname --help`.
