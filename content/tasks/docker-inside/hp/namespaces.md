# Пространства имён

Вот он, sleep 1000 — среди обычных процессов машины, с обычным номером. Никакой «отдельной
машины» нет: контейнер — это процесс.

Свой мир ему делает ядро. Как это устроено:

1. У Linux есть **пространства имён** (namespaces). Каждое отвечает за одну часть системы.
2. Ядро может поместить процесс в новое пространство имён — и тогда показывает ему
   собственную версию этой части системы, а не общую.
3. Docker при запуске контейнера заводит ему новые пространства имён:

    pid    свой список процессов — внутри видно только себя
    mnt    своё дерево файлов — образ вместо диска машины
    net    своя сеть: свои адреса и порты
    uts    своё имя машины (hostname)
    ipc    свои очереди сообщений и общая память
    user   свои пользователи: root внутри — не root снаружи
           (это пространство docker включает не всегда — это настройка)

4. Процесс остаётся один, но видит мир иначе, чем остальные процессы машины.

Что именно он видит изнутри — проверь дальше.
