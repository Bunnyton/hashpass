# Сколько можно контейнеру

Контейнеры на одной машине делят её память и процессор. По умолчанию ограничений нет: один
прожорливый контейнер может забрать себе всё, и остальным не хватит.

## Кто ставит лимиты

Лимиты ставит ядро. Механизм называется **cgroups** (control groups, контрольные группы):

1. Ядро собирает процессы в группу.
2. Ядро считает, сколько памяти, процессорного времени и других ресурсов группа потратила.
3. Если группе задан предел, больше этого предела ядро ей не даёт.

Docker заводит такую группу каждому контейнеру сам. Тебе остаётся только задать пределы.

## Как задать предел

1. Пределы задают ключами `docker run` при запуске контейнера. Какие есть — в
   `docker run --help`.
2. Объём памяти пишут числом с единицей: `512m` — 512 мегабайт, `2g` — 2 гигабайта.
3. Что потом происходит с контейнером, расскажут `docker ps -a` и его журнал — `docker logs`.
