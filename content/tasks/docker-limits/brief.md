# Сколько можно контейнеру

Контейнеры на одной машине делят её память и процессор. По умолчанию ограничений нет: один
прожорливый контейнер может забрать себе всё, и остальным не хватит.

Лимиты ставит ядро. Механизм называется **cgroups** (control groups, контрольные группы):
ядро собирает процессы в группу и следит, сколько памяти, процессорного времени и других
ресурсов группа потратила. Docker заводит такую группу каждому контейнеру — остаётся задать
пределы ключами `docker run`.

Объём памяти пишут числом с единицей: `512m`, `2g`. Остальные ключи — в `docker run --help`.

Что сейчас происходит с контейнером, расскажут `docker ps -a` и его журнал — `docker logs`.
