# Процессор — тоже по лимиту

1. Процессор лимитируют долей ядер: `1` — одно ядро целиком, `1.5` — полтора, `0.25` —
   четверть.
2. Внутри это тоже cgroups: ядро даёт группе работать только часть каждой десятой доли
   секунды, а остальное время держит её на паузе. При `0.25` — 25 мс работы из каждых 100.
3. Сколько контейнеры тратят прямо сейчас, показывает `docker stats` — живая таблица:
   процессор, память и её лимит, сеть. Выйти — `Ctrl+C`.
