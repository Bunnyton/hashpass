# Процессор — тоже по лимиту

Процессор лимитируют долей ядер: `1` — одно ядро целиком, `1.5` — полтора, `0.25` — четверть.
Внутри это тоже cgroups: ядро даёт группе работать только часть каждой сотой доли секунды, а
остальное время держит её на паузе.

Сколько контейнеры тратят прямо сейчас, показывает `docker stats` — живая таблица: процессор,
память и её лимит, сеть. Выйти — `Ctrl+C`.
