# Код 137: убит за лимит

Когда контейнер упирается в лимит памяти, ядро не даёт ему больше ни байта. Процессу, который
просит ещё, приходит **OOM killer** (out of memory) и завершает его сигналом `SIGKILL` —
номер 9. Без предупреждения: ни сохранить, ни дописать журнал.

Код выхода программы, убитой сигналом, — 128 + номер сигнала. 128 + 9 = **137**. Увидел 137 —
почти наверняка не хватило памяти. Подтвердит это `docker inspect`: там есть поле `OOMKilled`.
