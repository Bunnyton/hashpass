# Код 137: убит за лимит

Что случилось, по шагам:

1. Контейнер упёрся в лимит памяти — ядро не даёт ему больше ни байта.
2. К процессу, который просит ещё, приходит **OOM killer** (out of memory).
3. Он завершает процесс сигналом `SIGKILL` — номер 9. Без предупреждения: ни сохранить, ни
   дописать журнал.
4. Код выхода программы, убитой сигналом, — 128 + номер сигнала: 128 + 9 = **137**.

Увидел 137 — почти наверняка не хватило памяти. Подтвердит это `docker inspect`: там есть
поле `OOMKilled`.
