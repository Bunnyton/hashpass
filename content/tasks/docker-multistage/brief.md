# Лишний вес

Чтобы собрать программу, обычно нужно намного больше, чем чтобы её запустить: компилятор,
библиотеки для сборки, шаблоны, тесты. Сайт на React собирают сотни мегабайт пакетов, а
результат — несколько файлов HTML и JavaScript.

Каждый лишний мегабайт образа кто-то скачивает: сервер при каждом обновлении, коллега,
система проверок. И каждая лишняя программа в образе — ещё одна возможная дыра.

## Как узнать, сколько весит образ

1. `docker images` выводит список образов на машине.
2. Последняя колонка, `SIZE`, — вес образа целиком, со всеми его слоями.
3. Если нужен один образ, допиши его имя — список сократится до него:

    docker images nginx

    REPOSITORY   TAG      IMAGE ID       CREATED          SIZE
    nginx        latest   a1b2c3d4e5f6   2 weeks ago      192MB
