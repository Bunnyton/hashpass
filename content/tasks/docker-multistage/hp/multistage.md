# Сборка в два этажа

Инструменты нужны, чтобы **сделать** сайт, но не чтобы его **показывать**. А всё, что попало
в образ на любом шаге, в нём и остаётся: даже `RUN rm` в конце не поможет — слой с
инструментами уже лежит ниже, а новый слой лишь прячет файлы.

Поэтому Dockerfile делят на **ступени**. В одном файле может быть несколько `FROM`: каждый
начинает новый, чистый образ. Первой ступени дают имя, и следующая берёт из неё только
нужные файлы:

    FROM debian AS build              # ступень-мастерская: всё для сборки
    RUN apt-get install -y gcc
    COPY hello.c /src/
    RUN gcc -o /src/hello /src/hello.c

    FROM debian                       # итоговый образ — чистый
    COPY --from=build /src/hello /usr/local/bin/hello
    CMD ["hello"]

Образом становится **последняя** ступень. Мастерская остаётся в кэше сборки и в образ не
попадает — ни инструменты, ни исходники.
