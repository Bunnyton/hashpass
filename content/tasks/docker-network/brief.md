# Контейнеры в сети

Настоящий сервис редко живёт в одном контейнере: сайт отдельно, база отдельно, склад
отдельно. Каждый — в своём контейнере со своими программами, а между собой они говорят по
сети, как два сервера: один спрашивает по адресу, другой отвечает.

## Как проверить сервис из другого контейнера

Самый простой способ — запустить рядом одноразовый контейнер и спросить из него:

1. В образе `busybox` нет curl, зато есть `wget`.
2. Ключ `-qO-` у `wget` показывает страницу на экране, а не сохраняет её в файл.
3. Ключ `--rm` у `docker run` удаляет контейнер, как только команда в нём закончится: для
   разовой проверки — то что нужно.

    docker run --rm busybox wget -qO- http://example.com/
