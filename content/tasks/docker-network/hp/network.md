# Имена есть только в своей сети

`bad address 'stock'` — busybox не знает такого имени. Почему:

1. Контейнеры, запущенные как обычно, попадают в общую сеть по умолчанию — `bridge`.
2. Связь там есть, но только по IP-адресам, а адреса меняются при каждом перезапуске.
3. **Имён** в этой сети нет.

Имена работают в сетях, которые ты создаёшь сам. В такой сети docker держит свою адресную
книгу: каждый контейнер доступен остальным по имени.

## Как собрать контейнеры в своей сети

1. Создать сеть:

    docker network create backend

2. Запустить контейнер сразу в ней — ключ `--network`:

    docker run -d --name db --network backend postgres

3. Или подключить к ней уже работающий контейнер:

    docker network connect backend web

4. Посмотреть, какие сети есть, — `docker network ls`.

Подключать к сети надо обе стороны: и того, кто отвечает, и того, кто спрашивает.
