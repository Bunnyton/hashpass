# Имена есть только в своей сети

Контейнеры, запущенные как обычно, попадают в общую сеть по умолчанию — `bridge`. Связь там
есть, но только по IP-адресам, а адреса меняются при каждом перезапуске. **Имён** в этой сети
нет — отсюда `bad address 'stock'`.

Имена работают в сетях, которые ты создаёшь сам. В такой сети docker держит свою адресную
книгу: каждый контейнер доступен остальным по имени.

    docker network create backend               # своя сеть
    docker run -d --name db --network backend postgres
    docker network connect backend web          # подключить уже работающий контейнер
    docker network ls                           # какие сети есть

Подключать к сети надо обе стороны: и того, кто отвечает, и того, кто спрашивает.
