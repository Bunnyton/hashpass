# Кому слушать

У проброса есть третья, необязательная часть — адрес машины, на котором слушать:

    -p 8080:80                 все адреса машины: подключится любой, кто видит её в сети
    -p 127.0.0.1:8080:80       только 127.0.0.1 — адрес «сам себе»: подключиться можно
                               только с этой машины

`0.0.0.0` в `docker ps` значит «все адреса». Поменять проброс у работающего контейнера нельзя —
только запустить контейнер заново.
