# Порт машины — только один

Второй контейнер не запустился: порт машины уже занят. Почему так:

1. Внутри каждого контейнера своя сеть, поэтому порт 80 может слушать хоть сто контейнеров
   сразу — правая часть `-p` у всех может быть одинаковой.
2. А вот порт **машины** — один на всех: кто занял 8080 первым, тот его и держит.
3. Значит, левая часть `-p` у каждого контейнера своя:

    контейнер 1: 80    ← машина 8080
    контейнер 2: 80    ← машина 8070      правая часть повторяется,
    контейнер 3: 80    ← машина 8090      левая — у каждого своя

Контейнер, который не смог занять порт, docker создал, но не запустил: он висит в
`docker ps -a` со статусом Created. Его можно убрать — `docker rm`.
