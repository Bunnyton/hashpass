# Реестр образов

Образ мало собрать — его ещё нужно доставить туда, где он будет работать. Для этого образы
хранят в **реестре** (registry) — сервере образов. Самый известный — Docker Hub: оттуда
приходят `alpine`, `redis`, `nginx`.

## Как образ ходит через реестр

1. Ты собираешь образ у себя.
2. `docker push <образ>` отправляет его в реестр.
3. На другой машине `docker pull <образ>` скачивает его оттуда. `docker run` делает это сам,
   если образа на машине нет.

## Куда — написано в имени

Куда отправлять, docker узнаёт из **имени** образа. Полное имя — из трёх частей:

    registry.example.com:5000 / team/app : 2.1
    └─ адрес реестра ───────┘  └ имя ──┘  └ метка

- адрес реестра можно не писать — тогда это Docker Hub;
- метку тоже можно не писать — тогда это `latest`.

## Свой реестр

Свой реестр — это тоже просто контейнер, сервер вроде сайта:

1. Образ для него — `registry:2`, он уже есть на машине.
2. Внутри контейнера реестр слушает порт 5000.
3. Работает он, пока его не остановят, поэтому запускают его, как любой сервер, в фоне.
