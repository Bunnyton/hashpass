# Реестр образов

Образы хранят в **реестре** (registry) — сервере образов. Самый известный — Docker Hub: оттуда
приходят `alpine`, `redis`, `nginx`. Команды две:

    docker pull <образ>    скачать из реестра
    docker push <образ>    отправить в реестр

Куда отправлять, docker узнаёт из **имени** образа. Полное имя — из трёх частей:

    registry.example.com:5000 / team/app : 2.1
    └─ адрес реестра ───────┘  └ имя ──┘  └ метка

Адрес можно не писать — тогда это Docker Hub. Метку тоже — тогда это `latest`.

Свой реестр — это тоже просто контейнер: образ `registry:2` уже есть на машине. Внутри он
слушает порт 5000.
