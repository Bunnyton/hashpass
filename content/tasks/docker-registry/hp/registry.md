# Адрес реестра — в имени

docker пошёл на `docker.io` — это Docker Hub. Так он поступает с любым образом, в имени
которого нет адреса реестра.

Чтобы образ уехал в твой реестр:

1. Дай образу имя, которое начинается с адреса реестра: `localhost:5000/...`. Новое имя
   существующему образу даёт `docker tag`. Образ при этом не копируется — у него просто
   появляется ещё одно имя.
2. Отправь образ под этим новым именем: `docker push`.

    docker tag app registry.example.com:5000/app:2.1
    docker push registry.example.com:5000/app:2.1

Реестр на `localhost` docker разрешает без HTTPS — для любого другого адреса понадобился бы
сертификат.
