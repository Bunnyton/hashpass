# Удалить образ

Образы с машины удаляет `docker rmi` (длинная запись — `docker image rm`). Как это работает:

1. `docker rmi <имя>` снимает с образа **одно имя**.
2. У образа может быть несколько имён — `docker tag` только добавляет новое. Пока у образа
   остаётся хоть одно имя, он лежит на диске.
3. Снято последнее имя — docker удаляет и сам образ, его слои.
4. Образ, из которого сделан контейнер (даже остановленный), docker не удалит: сначала
   убирают контейнер.

    docker rmi app registry.example.com:5000/app:2.1     # два имени одного образа разом

Что осталось, покажет `docker images`: у одного образа с несколькими именами в колонке
IMAGE ID одинаковый номер.
