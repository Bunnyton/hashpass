# Образ и контейнер

Образы на этой машине уже лежат — например, `busybox` и `alpine` (маленький Linux на 8 МБ).
Какие именно, показывает

    docker images

## Как запустить команду в контейнере

    docker run busybox echo привет

Что при этом происходит, по шагам:

1. Docker берёт образ — он назван сразу после `docker run` (здесь `busybox`).
2. Из образа создаётся новый контейнер со своими файлами.
3. Внутри контейнера выполняется команда — всё, что написано после имени образа
   (здесь `echo привет`).
4. Вывод команды приходит к тебе на экран.
5. Команда закончилась — контейнер остановился.

Docker здесь работает от твоего имени, `sudo` ему не нужен.
