# Образ и контейнер

**Образ** — готовая файловая система с программами: например, `busybox` или `alpine` (маленький
Linux на 8 МБ). Образы на машине показывает

    docker images

**Контейнер** — запущенный образ: отдельная мини-система со своими файлами и процессами. Ядро
у контейнера общее с машиной, поэтому стартует он мгновенно — это не виртуальная машина.

Запустить команду внутри нового контейнера:

    docker run busybox echo привет

Сначала образ, следом команда, которая выполнится в контейнере. Команда закончилась —
контейнер остановился.

Docker здесь работает от твоего имени, `sudo` ему не нужен.
