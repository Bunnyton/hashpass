# Каталог машины в контейнере

Контейнер — вещь одноразовая. Его запускают, останавливают, удаляют и создают заново из
образа: обновить сервер — значит выбросить старый контейнер и запустить новый из свежего
образа. Всё, что программа записала внутрь контейнера, уходит вместе с ним.

А данные должны жить дольше: статьи блога, база данных, загруженные файлы. Поэтому их держат
**снаружи** — в каталоге машины — и подключают в контейнер при запуске.

## Как подключить каталог

Каталог машины подключают ключом `-v` (volume) у `docker run`:

    docker run -d -p 3000:80 -v /home/student/photos:/www wiki

Что делает `-v`, по шагам:

1. Слева от двоеточия — каталог на машине (здесь `/home/student/photos`).
2. Справа — путь внутри контейнера, куда этот каталог ляжет (здесь `/www`).
3. Всё, что было в образе по этому пути, накрывается подключённым каталогом.
4. Программа в контейнере видит файлы машины как свои: читает их и пишет прямо в каталог
   машины.

Сервер в образе `wiki` отдаёт файлы из каталога `/www` внутри контейнера — значит, подключённый
туда каталог он и покажет.
