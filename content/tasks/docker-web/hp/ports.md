# Проброс портов

У контейнера своя сеть: его порт 80 снаружи не виден, и на машине по этому адресу никто не
отвечает. Порт нужно **опубликовать** при запуске:

    docker run -d -p 3000:80 образ

`-p 3000:80` — соединения на порт 3000 машины уходят на порт 80 контейнера. Порт машины
выбирай любой свободный (не меньше 1024 — порты ниже без root не открыть).

Работающему контейнеру порт уже не добавить — нужен новый контейнер.
