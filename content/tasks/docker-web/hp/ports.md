# Проброс портов

Браузер не достучался: у контейнера своя сеть, и его порт 80 снаружи не виден. На машине по
этому адресу никто не отвечает.

Порт нужно **опубликовать** при запуске — пробросить порт машины в порт контейнера:

    docker run -d -p 3000:80 образ

Как это работает, по шагам:

1. `-p 3000:80` — слева порт машины, справа порт внутри контейнера.
2. Браузер стучится на порт 3000 машины.
3. Docker передаёт соединение на порт 80 контейнера — туда, где слушает сервер.

Порт машины выбирай любой свободный, не меньше 1024: порты ниже без root не открыть.

Работающему контейнеру порт уже не добавить — нужен новый контейнер.
