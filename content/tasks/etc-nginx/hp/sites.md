# Это не тот сайт

«Welcome to nginx!» — стандартная страница самого nginx. На этом порту ответил новый пустой сайт:
у блока `server` нет своего `root`, и nginx показал то, что лежит у него по умолчанию.

Как nginx собирает свои настройки:

1. `nginx.conf` — общие настройки, а в конце строка `include /etc/nginx/sites-enabled/*;`:
   подключить все включённые сайты.
2. Каждый сайт — свой файл в `sites-available/` с блоком `server`: на каком порту ждать
   (`listen`), откуда брать страницы (`root`).
3. Включают сайт ссылкой на этот файл из `sites-enabled/`.

Например, сайт библиотеки:

    server {
        listen 127.0.0.1:9000;
        root /var/www/library;
    }

Сайт отдела уже описан в своём файле — переезжать ему нужно там. А лишний пустой `server`
лучше убрать: это второй сайт, он никому не нужен.
