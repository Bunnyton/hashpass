# Учётки в /etc

Пользователь в Linux — это не папка и не программа, а **строка в файле**:

    /etc/passwd    имя, номер, группа, домашний каталог, оболочка
    /etc/shadow    пароли (зашифрованные, читает только root)
    /etc/group     группы и кто в них состоит

Можно открыть их и посмотреть — `cat /etc/passwd`. Вот строка пользователя alice:

    alice:x:1001:1001::/home/alice:/bin/bash

---

# useradd

Писать эти строки руками не нужно — их добавляет команда `useradd` (от имени администратора):

    sudo useradd alice

Кто есть кто, покажет `id`:

    $ id alice
    uid=1001(alice) gid=1001(alice) groups=1001(alice)
