# find: точный уровень

У `find` есть и «нижняя» граница глубины — `-mindepth`. В паре они дают
**ровно N-й уровень**:

    find <dir> -mindepth 3 -maxdepth 3

А чтобы отсеять директории и оставить только файлы — `-type f` (или
`-type d` для директорий).

## Задание

Найдите файлы, которые лежат **ровно на 3-м уровне вложенности** внутри
`/home/student/search`.

Условие: **нельзя** использовать `-name`.
