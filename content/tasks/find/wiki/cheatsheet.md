# Шпаргалка по find

← [find: поиск файлов](../wiki.md)

    find [где …] [условия] [действие]

Где — один или несколько каталогов (`.` — текущий). Без действия find печатает пути.

## Условия (tests)

| Условие | Что проверяет |
|---|---|
| `-name 'шаблон'` | имя (только последняя часть пути), `*` `?` `[...]` |
| `-iname 'шаблон'` | то же без учёта регистра |
| `-path 'шаблон'` | весь путь целиком: `-path '*/logs/*'` |
| `-type f` / `d` / `l` | файл / каталог / символьная ссылка |
| `-maxdepth N` | не глубже N (0 — сам стартовый каталог) |
| `-mindepth N` | не мельче N |
| `-empty` | пустой файл или пустой каталог |
| `-size +10M` / `-size -1k` | больше 10 МиБ / меньше 1 КиБ (`c` — байты, `k`, `M`, `G`) |
| `-mtime -7` | менялся за последние 7 суток (`+7` — раньше) |
| `-mmin -30` | менялся за последние 30 минут |
| `-newer файл` | новее указанного файла |
| `-user имя` / `-group имя` | владелец / группа |
| `-perm -u+x` | права: у владельца есть x |

## Операторы

| Запись | Значит |
|---|---|
| `усл1 усл2` (или `-a`) | и |
| `усл1 -o усл2` | или (слабее, чем «и») |
| `-not усл` или `! усл` | не |
| `\( … \)` | группа; пробелы вокруг скобок обязательны |

## Действия

| Действие | Что делает |
|---|---|
| `-print` | напечатать путь (по умолчанию) |
| `-ls` | как `ls -l` для каждой находки |
| `-exec cmd {} \;` | запустить `cmd` для каждой находки |
| `-exec cmd {} +` | запустить `cmd` один раз со всеми находками сразу |
| `-delete` | удалить (сначала проверь тот же find без него!) |

## Частые связки

| Задача | Как |
|---|---|
| сколько нашлось | `find … \| wc -l` |
| по алфавиту | `find … \| sort` |
| без «Permission denied» на экране | `find / … 2>/dev/null` |
| искать текст в найденных файлах | `find … -type f -exec grep -l 'слово' {} +` |
