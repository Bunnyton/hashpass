# Ключи

Почти у каждой команды есть опции — их называют ключами. Они немного, а иногда
и сильно меняют то, что команда делает:

    команда -ключ

Например, `ls -t` сортирует файлы по времени. Несколько ключей можно писать
раздельно или слитно — `ls -t -r`, `ls -tr`, `ls -rt` делают одно и то же.

А ещё в Linux есть **скрытые файлы** — те, чьё имя начинается с точки. Так
прячут настройки, чтобы не мешали.
