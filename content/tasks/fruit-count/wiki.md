# Считаем по шагам: sort, uniq, wc и файлы

Сколько разных строк в списке? Ответ собирается из трёх команд: **sort** ставит одинаковые
строки рядом, **uniq** склеивает соседние повторы, **wc -l** считает строки. Здесь каждый шаг
кладёт результат в свой файл — так удобно проверять себя: открыл промежуточный файл и увидел,
что получилось.

Пример — список питомцев из ветклиники:

    $ cat pets.txt
    кот
    пёс
    кот
    хомяк
    пёс
    кот
    попугай

## Шаг за шагом — через файлы

`>` отправляет вывод команды в файл: файл создаётся сам, старое содержимое стирается. На экран
ничего не выходит:

    $ sort pets.txt > sorted.txt
    $ cat sorted.txt
    кот
    кот
    кот
    попугай
    пёс
    пёс
    хомяк

Следующая команда берёт этот файл как обычный. Промежуточные файлы хороши, пока учишься:
каждый шаг можно открыть и проверить. Когда шаги отлажены, их соединяют конвейером `|` и файлы
не нужны — об этом [wiki fruit-store](/web/wiki/bunnyton/fruit-store).

## uniq видит только соседей

`uniq` сравнивает строку с предыдущей. Поэтому на неотсортированном списке повторы остаются:

    $ uniq pets.txt
    кот
    пёс
    кот
    хомяк
    пёс
    кот
    попугай

А после `sort` одинаковые строки стоят рядом, и `uniq` их склеивает. Ключ `-c` ещё и
подпишет, сколько раз встретилась каждая строка:

    $ sort pets.txt | uniq -c
          3 кот
          1 попугай
          2 пёс
          1 хомяк

## wc -l — число строк, и только число

Если дать `wc` имя файла, он напечатает число **и имя**:

    $ wc -l pets.txt
    7 pets.txt

Чтобы осталось только число, подай файл **на вход** значком `<` — тогда `wc` читает поток и
имени файла не знает:

    $ wc -l < pets.txt
    7

Число, как и любой вывод, тоже можно отправить в файл через `>`.

## Грабли

- `sort файл > файл` — файл станет пустым: `>` очищает его до того, как `sort` начнёт читать.
  Всегда пиши результат в **новый** файл.
- Пробел в конце строки делает её «другой»: `кот` и `кот ` для `uniq` — разные строки.
- `wc -l` считает переводы строк: если у последней строки нет `\n`, она не посчитается.
