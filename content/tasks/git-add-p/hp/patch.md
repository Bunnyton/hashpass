# В коммит — не весь файл

`git add файл` кладёт в индекс файл **целиком** — со всеми правками сразу. А `git add -p`
(patch) идёт по правкам кусками и про каждый спрашивает: брать?

    $ git add -p notes.txt
    @@ -1,3 +1,4 @@
     Список покупок
    +молоко
     хлеб
    (1/2) Stage this hunk [y,n,q,a,d,s,e,?]?

Ответы:

- `y` — взять кусок в индекс, `n` — не брать;
- `q` — хватит, остальное не брать;
- `?` — подсказка по всем буквам.

Проверить, что попало в индекс, а что осталось только на диске:

    git diff --cached      # будет в коммите
    git diff               # останется на диске

Уже закоммитил лишнее? Коммит можно снять, не трогая файлы, — как, ты знаешь по заданию
про `git reset`.
