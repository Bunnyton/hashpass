# git add -p: в коммит — часть файла

В файле две правки, а коммит нужен про одну. `git add -p` идёт по правкам кусками (hunk) и
про каждый спрашивает:

    $ git add -p calc.sh
    @@ -1,8 +1,11 @@
     #!/bin/sh
     # Калькулятор: ./calc.sh 12 + 5
    +pow() {  # TODO: отрицательные степени, а ещё ^ в case ниже
    ...
    (1/2) Stage this hunk [y,n,q,a,d,j,J,g,/,e,p,?]? n
    @@ -11,6 +14,6 @@ case "$op" in
    -    /) echo $((a / b)) ;;
    +    /) [ "$b" -ne 0 ] || { echo "На ноль делить нельзя" >&2; exit 1; }; echo $((a / b)) ;;
    (2/2) Stage this hunk [y,n,q,a,d,K,g,/,e,p,?]? y

## Ответы

| Буква | Что делает |
|---|---|
| `y` / `n` | взять кусок / пропустить |
| `s` | разбить кусок на меньшие — если правки разделены хоть одной неизменной строкой |
| `e` | открыть кусок в редакторе и оставить нужные строки руками |
| `q` | закончить, остальное не брать |
| `a` / `d` | взять / пропустить все оставшиеся куски этого файла |
| `?` | справка |

## Проверить перед коммитом

    $ git diff --cached --stat
     calc.sh | 2 +-
     1 file changed, 1 insertion(+), 1 deletion(-)
    $ git diff --stat            # что осталось на диске
     README.md | 2 ++
     calc.sh   | 5 ++++-

## Родственники

- `git restore -p` — откатить на диске часть правок.
- `git reset -p` — вынуть часть из индекса.
- `git stash -p` — отложить на полку часть правок.
- `git commit -p` — то же, что `add -p` и сразу коммит.
