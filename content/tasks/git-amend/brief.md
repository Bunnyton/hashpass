# Поправить последний коммит

Коммит сделан, а в нём ошибка: забыл файл, опечатался в сообщении, прихватил лишнее.
Если коммит ещё не отправлен на сервер, новый «исправляющий» коммит не нужен — последний
коммит можно переделать.

## git commit --amend

`--amend` — «поправить». Как это работает:

1. Ты готовишь исправление как обычно: правишь файлы, кладёшь их в индекс `git add`.
2. `git commit --amend` берёт последний коммит, добавляет к нему то, что в индексе,
   и **ставит новый коммит на его место**. Коммитов в истории столько же, сколько было.
3. git откроет редактор с прежним сообщением — поправь его или просто сохрани и выйди.
   Сообщение не нужно менять? Добавь ключ `--no-edit`.

Пример на другом проекте:

    $ git log --oneline
    4c1a9e2 Страница контактов
    $ git add map.png
    $ git commit --amend --no-edit
    $ git log --oneline
    b07f3d1 Страница контактов        # тот же коммит — уже с map.png

Хеш изменился: это новый коммит. Поэтому отправленные коммиты так не правят — у
напарников остался бы старый.
