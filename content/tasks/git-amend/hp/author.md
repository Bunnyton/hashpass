# Чьё имя в коммите

У каждого коммита есть **автор** — имя и почта. Их видно в `git log`:

    commit b07f3d1…
    Author: Лена Котова <lena@studio.local>

## Откуда git берёт имя

1. Из настроек: `user.name` и `user.email`.
2. Настройки лежат в нескольких местах. Главные:
   - `~/.gitconfig` — твои, для всех репозиториев (`git config --global …`);
   - `.git/config` внутри репозитория — только для него (`git config …` без `--global`).
3. Если имя есть в обоих местах, **побеждает репозиторий**.

Кто и где что записал, покажет одна команда:

    git config --list --show-origin

Убрать настройку из файла репозитория:

    git config --unset user.name

## Автор не меняется сам

Автор записывается, когда коммит создают впервые. Даже `--amend` его сохраняет: правки
новые, а автор прежний. Чтобы git взял автора заново, у `git commit` есть отдельный
ключ — он в `git commit --help`, рядом со словом author.
