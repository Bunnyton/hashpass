# Поиск — это режим

Пока идёт поиск, git держит каталог на коммите посреди истории, а не на ветке. Чинить
отсюда нельзя: новый коммит повиснет в стороне от `main`.

Поиск заканчивают явно:

    git bisect reset     # закончить поиск и вернуться на ветку, с которой начинал

Хеш виновника git уже напечатал на прошлом шаге — он пригодится и после `reset`.
