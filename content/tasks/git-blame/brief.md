# Кто это написал?

Чтобы понять, откуда взялась строка, git умеет подписать **каждую строку** файла: каким
коммитом, кто и когда её менял.

    $ git blame notes.txt
    3fa1c02e (Анна Смирнова 2026-10-02 12:00:00 +0300 1) Список покупок
    9b77e410 (Олег Кузнецов 2026-10-05 09:30:00 +0300 2) молоко

Хеш слева — коммит. Что в нём было и зачем, расскажут `git show <хеш>` и его сообщение.

Только часть строк: `git blame -L 10,20 файл`.
