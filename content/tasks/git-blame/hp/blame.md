# blame показывает последнего, кто трогал строку

`git blame` пишет у каждой строки коммит, который менял её **последним**. Неважно, что это
была за правка: смысл, опечатка или два пробела. Переформатировал файл — и весь файл
теперь «твой».

Поэтому, когда blame указал на коммит, сначала посмотри, что этот коммит сделал:

    git show <хеш>

Если там только пробелы, отступы или перенос строк — виновник глубже. Как заглянуть за
такой коммит:

    git blame -w файл             # не замечать правки, где поменялись только пробелы
    git blame <хеш>^ -- файл      # blame на момент ДО этого коммита

`<хеш>^` — родитель коммита: файл, каким он был за шаг до правки.
