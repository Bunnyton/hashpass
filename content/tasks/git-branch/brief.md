## Что такое ветка

**Ветка** — отдельная линия истории. В ней можно спокойно коммитить сколько угодно, а
основная ветка `main` остаётся рабочей, пока новое не готово.

Ветка в git дешёвая: это просто метка с именем, которая указывает на последний коммит линии.
Создаётся мгновенно, места почти не занимает — поэтому ветки заводят на каждую мелочь.

## Как работают с веткой

1. Посмотри, какие ветки есть и в какой ты сейчас (текущая — со звёздочкой):

       git branch

2. Создай ветку для своей задачи и сразу перейди в неё:

       git switch -c feature

3. Правь файлы и коммить как обычно. Коммиты попадают в ту ветку, в которой ты стоишь.
4. Чтобы вернуться в основную ветку:

       git switch main

5. Когда задача готова, ветку вливают в `main`. Так каждый в команде делает своё в своей
   ветке, не мешая другим.

При переключении git меняет файлы в каталоге на версию из той ветки. Не пугайся, если
что-то «пропало»: оно в другой ветке.
