# Ветки

Ветка — отдельная линия истории. В ней можно спокойно коммитить, а основная ветка `main`
остаётся нетронутой, пока работа не готова.

    git branch               # список веток, текущая — со звёздочкой
    git switch -c feature    # создать ветку feature и перейти в неё
    git switch main          # вернуться в main

Коммиты делаются в ту ветку, в которой ты стоишь.
