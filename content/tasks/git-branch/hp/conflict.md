# Конфликт

Обе ветки поменяли одно и то же место, и git не знает, какой вариант оставить. Он записал в
файл оба и ждёт решения:

    <<<<<<< HEAD
    вариант из ветки, в которой ты стоишь
    =======
    вариант из вливаемой ветки
    >>>>>>> feature

Как разобрать:

1. Открой файл и найди метки.
2. Оставь то, что должно получиться: один вариант, другой или оба.
3. Удали строки-метки `<<<<<<<`, `=======`, `>>>>>>>`.
4. Добавь файл в индекс — `git add`.
5. Закончи слияние — `git commit`.

Передумал — `git merge --abort` вернёт всё как было до слияния.
