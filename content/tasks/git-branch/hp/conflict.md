# Конфликт

Обе ветки поменяли одно и то же место, и git не знает, какой вариант оставить. Он
записал в файл оба и ждёт решения:

    <<<<<<< HEAD
    вариант из ветки, в которой ты стоишь
    =======
    вариант из вливаемой ветки
    >>>>>>> feature

Открой файл, оставь то, что должно получиться (можно оба варианта), и удали строки-метки
`<<<<<<<`, `=======`, `>>>>>>>`. Потом — как обычно: `git add` файла и `git commit`.
Передумал — `git merge --abort` вернёт всё как было до слияния.
