# Слияние

Готовую ветку **вливают** в основную. Делается это в два шага:

1. Перейди в ветку, которая принимает изменения:

       git switch main

2. Назови ветку, которая вливается:

       git merge feature

git сам соединит изменения обеих веток в новом коммите.

Пока ты работал, коллега тоже мог что-то закоммитить в `main` — посмотри `git log main`.
