# Слияние притащит всё

`git merge` вливает ветку целиком: вместе с исправлением в релиз поедут корзина-черновик,
новые цены и версия 1.1-dev — всё, что в main сделано после выпуска 1.0. Покупателям это
показывать рано.

Как вернуть релиз:

1. Слияние ещё ждёт разрешения конфликта? Его отменяет `git merge` с ключом *abort*.
2. Слияние уже готово? Найди в `git reflog` хеш, где ветка стояла до него.
3. `git reset --hard <хеш>` вернёт ветку на прежнее место.
