# Теги

Ветка ползёт вперёд с каждым коммитом. А версии нужна метка, которая не сдвинется никогда:
«вот ровно это и выпущено как 1.0.1». Это **тег**.

Теги бывают двух видов:

- **простые** — просто имя на коммите;
- **аннотированные** — у них есть автор, дата и сообщение, как у коммита.

Для выпусков ставят аннотированные: через год будет видно, кто и когда выпустил версию и
что в ней.

Как поставить тег:

1. Посмотри, какие теги уже есть:

    git tag

2. Поставь аннотированный тег:

    git tag -a v2.0 -m "Версия 2.0"     # аннотированный тег на текущий коммит

   Тег ставится на коммит, в котором ты стоишь, — или на тот, который назовёшь после
   имени тега.
3. Загляни, что получилось:

    git show v2.0
