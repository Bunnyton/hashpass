# Теги

Ветка ползёт вперёд с каждым коммитом. А версии нужна метка, которая не сдвинется никогда:
«вот ровно это и выпущено как 1.0.1». Это **тег**.

Бывают простые теги — просто имя на коммите — и **аннотированные**: у них есть автор, дата
и сообщение, как у коммита. Для выпусков ставят аннотированные: через год будет видно, кто
и когда выпустил версию и что в ней.

    git tag                             # список тегов
    git tag -a v2.0 -m "Версия 2.0"     # аннотированный тег на текущий коммит
    git show v2.0                       # что в теге

Тег ставится на коммит, в котором ты стоишь, — или на тот, который назовёшь после имени тега.
