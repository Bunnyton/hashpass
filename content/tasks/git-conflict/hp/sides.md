# Взять файл одной стороны целиком

Пока слияние не закончено, `git checkout` умеет достать файл в версии одной из сторон —
целиком, без меток. Как довести такое слияние:

1. Для файла, где права одна сторона, возьми её версию:

       git checkout --ours  config.yaml     # как было в твоей ветке
       git checkout --theirs config.yaml    # как в вливаемой ветке

   Конфликта в файле больше нет.
2. Добавь этот файл в индекс — `git add`, как после ручной правки.
3. Файлы, где нужны обе стороны, разбери руками, как раньше, и тоже `git add`.
4. Проверь `git status`: не должно остаться ни одного файла в конфликте.
5. Закончи слияние — `git commit`.
