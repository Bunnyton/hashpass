# Взять файл одной стороны целиком

Пока слияние не закончено, `git checkout` умеет достать файл в версии одной из сторон —
целиком, без меток:

    git checkout --ours  config.yaml     # как было в твоей ветке
    git checkout --theirs config.yaml    # как в вливаемой ветке

После этого конфликта в файле нет — останется `git add`, как после ручной правки.

Файлы, где нужны обе стороны, разбирай руками, как раньше. Слияние закончит `git commit`,
когда в `git status` не останется ни одного файла в конфликте.
