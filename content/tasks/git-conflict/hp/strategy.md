# Стратегия слияния

Цены из hotfix-prices правильнее всегда — значит, и решать каждый раз руками нечего. Такое
решение можно отдать git заранее.

Слияние делает **стратегия** (сейчас — `ort`). У неё есть настройки, их передают ключом `-X`:

    git merge -X ours    feature     # в спорных строках — наша версия
    git merge -X theirs  feature     # в спорных строках — версия вливаемой ветки

Это не «взять файл целиком»: бесспорные правки обеих сторон git всё равно сливает, а
сторону выбирает только там, где правки спорят.

Начатое слияние сначала отмени — `git merge --abort` вернёт всё как было.
