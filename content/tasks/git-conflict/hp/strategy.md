# Стратегия слияния

Цены из hotfix-prices правильнее всегда — значит, и решать каждый раз руками нечего. Такое
решение можно отдать git заранее.

## Как это устроено

1. Слияние делает **стратегия** (сейчас — `ort`).
2. У стратегии есть настройки, их передают ключом `-X`:

       git merge -X ours    feature     # в спорных строках — наша версия
       git merge -X theirs  feature     # в спорных строках — версия вливаемой ветки

3. Бесспорные правки обеих сторон git всё равно сливает как обычно.
4. Сторону он выбирает только там, где правки спорят.

Это не «взять файл целиком», как с `git checkout`: правки другой стороны в бесспорных местах
остаются.

## Как начать заново

1. Начатое слияние сначала отмени — `git merge --abort` вернёт всё как было.
2. Потом влей ветку снова, уже с нужной настройкой стратегии.
