# Выкладка по git push: серверные хуки и CI/CD

Сайт выкладывают на сервер руками. Студент пишет серверный хук post-receive, который сам
выкладывает main после каждого push, выкатывает правку одним push, а потом ставит проверку
pre-receive, которая не пускает сломанную страницу, — CI/CD в миниатюре.
