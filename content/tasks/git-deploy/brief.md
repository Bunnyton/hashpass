# Хуки на сервере

Хуки бывают не только у тебя в `.git/hooks`, но и у репозитория на сервере — того, куда
делают `git push`. Серверный репозиторий **голый** (bare): в нём только история, без рабочего
каталога, поэтому его хуки лежат прямо в `hooks/` внутри него.

Главные серверные хуки:

    pre-receive    до приёма push: код выхода не 0 — push отклонён целиком
    post-receive   после приёма: push уже принят, можно что-то сделать с новым кодом

Серверный хук — такой же исполняемый скрипт. Запускает его git, и запускает внутри
репозитория: команды git в хуке работают с ним без всяких путей.

Выложить ветку в обычный каталог умеет `git checkout`, если сказать ему, где рабочий
каталог, ключом `--work-tree`:

    git --work-tree=/var/www/blog checkout -f main     # файлы ветки main → в /var/www/blog

`-f` — перезаписать, что там лежит.
