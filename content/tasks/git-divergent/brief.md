# Две истории сразу

Пока ты работал, кто-то отправил на сервер свои коммиты. Теперь у тебя есть коммиты,
которых нет на сервере, а на сервере — коммиты, которых нет у тебя. Ветки **разошлись**:

          A ← B ← C          твой main
               ↖
                 D ← E       main на сервере

Сложить их можно двумя способами, и оба ты уже видел:

1. **Слияние** — коммит с двумя родителями. История честная, но с развилкой.
2. **Перестройка** (rebase) — твои коммиты переезжают поверх чужих. История — прямая линия.

В разных командах правило разное. Какое у твоей — сказано в задании.
