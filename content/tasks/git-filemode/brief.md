# Изменено всё — или ничего?

`git status` считает файл изменённым, если он хоть чем-то отличается от последнего
коммита. Чем именно — показывает `git diff`:

    git diff             # все отличия разом
    git diff notes.md    # отличия одного файла

Строки с `-` — как было в коммите, с `+` — как стало сейчас. Строки без знака — контекст
вокруг, они не менялись.

Когда изменённых файлов десятки, начни с одного: что git считает в нём изменением?
