# Права — тоже часть коммита

Строки `old mode 100644` / `new mode 100755` значат: у файла поменялись **права**, а не
текст. git хранит у каждого файла один бит — исполняемый он или нет:

- `100644` — обычный файл;
- `100755` — исполняемый, как скрипт.

## Откуда это взялось

Флешки обычно отформатированы в FAT или exFAT. Там нет прав Linux вообще — и когда файлы
копируют обратно, каждый становится `rwxr-xr-x`. git видит: было 644, стало 755.

## Как найти настоящую правку в этом шуме

Файл, у которого поменялись только права, в `git diff` — это две строки про mode и ни
одной строки с `+`/`-`. Короче всего видно в сводке:

    git diff --stat

Рядом с каждым файлом — сколько строк в нём изменилось. У «просто прав» там `0`.
