# Git: перезапись общей ветки

Студент перестроил ветку, которая уже лежит на сервере, а коллега тем временем отправил в
неё свой коммит. Нужно отправить ветку, не затерев чужую работу: забрать и посмотреть,
перенести чужой коммит, перезаписать. Во втором шаге — осторожная перезапись
`--force-with-lease`.
