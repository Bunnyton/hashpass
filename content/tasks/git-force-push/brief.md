# Перестроил то, что уже на сервере

`git rebase` не двигает коммиты, а делает **новые** — с теми же правками, но другими
хешами. Пока ветка жила только у тебя, это никого не касалось. Но она уже на сервере:

          C ← D              search на сервере (старые коммиты)
         ↙
    A ← B ← E ← F            main
                 ↖
                   C' ← D'   твоя search после rebase

Для сервера твоя search — другая история. Обычный `git push` откажет: он только
**добавляет** коммиты и никогда не выбрасывает те, что на сервере уже есть.

Заменить ветку на сервере своей — ключ `--force`:

    git push --force

Он не спрашивает и не проверяет: всё, что лежало в ветке на сервере и чего нет у тебя,
из ветки исчезнет.

Посмотреть, что на сервере сейчас, не трогая свою ветку:

    git fetch                        # обновить origin/* — ничего не сливает
    git log --oneline origin/feature
