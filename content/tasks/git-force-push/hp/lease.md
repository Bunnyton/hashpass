# Перезаписывать осторожно

`git push --force` заменяет ветку на сервере твоей, что бы там ни лежало. Если кто-то
успел отправить коммит после твоего последнего `git fetch`, этот коммит пропадёт.

Есть осторожная версия — `--force-with-lease`:

    git push --force-with-lease

Она перезаписывает ветку на сервере, **только если там то же**, что ты видел в последний
раз — в `origin/<ветка>`. Кто-то успел отправить своё — git откажет:

     ! [rejected]        feature -> feature (stale info)

Тогда: `git fetch`, посмотри новое в `origin/<ветка>`, перенеси к себе — и снова
`--force-with-lease`.

С этого момента в общих ветках — только так.
