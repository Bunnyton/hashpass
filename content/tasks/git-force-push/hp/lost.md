# Чат команды, 10:42

**Олег:** а где мой коммит в search? «Поиск: регистр не важен», Я его вчера отправил! Вот хеш:

    247dd9ff4220f800ba53a8a466f79bc0083dde4f

`--force` заменил ветку на сервере твоей — целиком. Всё, чего не было у тебя, из ветки
пропало. Если бы ты перед этим сделал `git fetch`, коммит Олега был бы у тебя
в `origin/search` — и ты бы его увидел.

Повезло: сам коммит ещё лежит на сервере, просто ни одна ветка на него не указывает. Его
можно забрать по хешу и перенести к себе:

    git fetch origin <хеш>      # забрать коммит с сервера — только по полному хешу
    git cherry-pick <хеш>       # переложить к себе в ветку

А потом снова отправить ветку на сервер.
