# Своя команда git

Длинные команды, которые набираешь каждый день, git разрешает назвать коротко — это
**алиас** (псевдоним).

1. Заведи алиас командой `git config --global alias.<имя> "<что подставлять>"`. Например,
   короткое `st` вместо `status -s`:

       git config --global alias.st "status -s"

2. git запишет его в твой `~/.gitconfig`, в раздел `[alias]`.
3. Теперь `git st` значит `git status -s` — в любом репозитории, пока жив этот файл.
4. Всё, что набрано после алиаса, git допишет в конец: `git st README.md` = `git status -s README.md`.
