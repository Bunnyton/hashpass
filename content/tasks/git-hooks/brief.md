# Хуки: git проверяет сам

**Хук** (hook, «крючок») — обычный скрипт, который git запускает сам в нужный момент: перед
коммитом, после слияния, перед отправкой на сервер. Если скрипт завершился с кодом не 0, git
останавливает действие.

Хуки лежат в `.git/hooks` каждого репозитория. `git init` кладёт туда примеры с окончанием
`.sample` — они не работают, пока их не переименовать. Хук называется ровно по событию:

    pre-commit     перед коммитом — можно проверить, что в него войдёт
    commit-msg     когда сообщение написано — можно проверить его
    pre-push       перед git push

Хук — исполняемый файл со строкой `#!/bin/sh` в начале, как любой твой скрипт. Без права на
запуск git его не тронет и честно об этом предупредит.

Что войдёт в коммит — то есть что лежит в индексе, — показывает `git diff --cached`.
Отказ объясни человеку: `echo "…" >&2` перед `exit 1`.
