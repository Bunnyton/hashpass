# Хуки: git проверяет сам

**Хук** (hook, «крючок») — обычный скрипт, который git запускает сам в нужный момент: перед
коммитом, после слияния, перед отправкой на сервер.

## Как git запускает хук

1. Ты делаешь действие — например, `git commit`.
2. git ищет в `.git/hooks` файл с именем этого события.
3. Нашёл исполняемый файл — запускает его. Без права на запуск git его не тронет и честно
   об этом предупредит.
4. Скрипт завершился с кодом 0 — действие идёт дальше. Не 0 — git его останавливает.

Свой каталог `.git/hooks` есть у каждого репозитория. `git init` кладёт туда примеры
с окончанием `.sample` — они не работают, пока их не переименовать.
Хук называется ровно по событию:

    pre-commit     перед коммитом — можно проверить, что в него войдёт
    commit-msg     когда сообщение написано — можно проверить его
    pre-push       перед git push

## Из чего состоит хук

1. Первая строка — `#!/bin/sh`, как у любого твоего скрипта.
2. Дальше — проверка. Что войдёт в коммит, то есть что лежит в индексе, показывает
   `git diff --cached`.
3. Проверка не прошла — объясни человеку, в чём дело, и откажи: `echo "…" >&2`, а следом
   `exit 1`.
