# Хук commit-msg

Как git проверяет сообщение коммита:

1. Сообщение git сначала пишет во временный файл.
2. Потом запускает хук `commit-msg` и передаёт ему путь к этому файлу **первым
   аргументом** — в скрипте это `$1`.
3. Хук читает файл и проверяет его.
4. Отвечает кодом выхода: 0 — сообщение годится, не 0 — коммита не будет.

Свой пароль-хук не трогай: оба хука работают вместе, каждый на своём шаге.
