# Хук commit-msg

Сообщение коммита git сначала пишет во временный файл и только потом запускает хук
`commit-msg`. Путь к этому файлу хук получает **первым аргументом** — в скрипте это `$1`.

Хук читает файл, проверяет и отвечает кодом выхода: 0 — сообщение годится, не 0 — коммита
не будет. Свой пароль-хук не трогай: оба хука работают вместе, каждый на своём шаге.
