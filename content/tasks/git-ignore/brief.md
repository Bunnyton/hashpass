# Что git не должен видеть

В рабочем каталоге всегда есть то, что в историю класть нельзя:

- журналы, которые пишет сервер;
- результаты сборки — их соберут заново из исходников;
- кэш и временные файлы редактора;
- пароли.

Если их не спрятать, `git status` превращается в простыню, а `git add .` однажды утащит
всё это в коммит.

## Файл .gitignore

Список того, что git должен не замечать, лежит в файле **`.gitignore`** в корне проекта.
Как им пользоваться:

1. Создай `.gitignore` в корне проекта любым редактором.
2. Пиши по одному шаблону на строку:

       *.tmp          # все файлы с окончанием .tmp — в любом каталоге
       build/         # каталог build целиком
       secret.txt     # один конкретный файл
       # строка с решёткой — комментарий

   `*` — любые символы в имени, `/` в конце — «это каталог».
3. Посмотри `git status`: то, что подошло под шаблоны, из списка пропадёт.
4. Сам `.gitignore` коммитят, как обычный файл: правила нужны всей команде.
