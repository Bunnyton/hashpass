# Что git не должен видеть

В рабочем каталоге всегда есть то, что в историю класть нельзя: журналы, которые пишет
сервер, результаты сборки (их соберут заново из исходников), кэш, временные файлы
редактора. А ещё — пароли.

Если их не спрятать, `git status` превращается в простыню, а `git add .` однажды утащит
всё это в коммит.

Список того, что git должен не замечать, лежит в файле **`.gitignore`** в корне проекта:
по шаблону на строку.

    *.tmp          # все файлы с окончанием .tmp — в любом каталоге
    build/         # каталог build целиком
    secret.txt     # один конкретный файл
    # строка с решёткой — комментарий

`*` — любые символы в имени, `/` в конце — «это каталог». Сам `.gitignore` коммитят, как
обычный файл: правила нужны всей команде.

Что получилось — всегда покажет `git status`.
