# .gitignore не отпускает то, что уже в истории

Правила `.gitignore` касаются только **неотслеживаемых** файлов — тех, которых ещё нет в
репозитории. `.env` закоммичен давно, git его знает и продолжает следить, что бы ни было
написано в `.gitignore`.

Чтобы git его отпустил, файл надо убрать из **индекса** — из списка того, что войдёт в
следующий коммит. Обычный `git rm` убирает файл и из индекса, и с диска. А у него есть
ключ, который трогает только индекс: файл остаётся на месте, а в следующем коммите
записано «файла больше нет».

После такого коммита `.env` для git станет неотслеживаемым — и тогда строка в
`.gitignore` начнёт работать.
