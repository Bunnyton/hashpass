# .gitignore не отпускает то, что уже в истории

Правила `.gitignore` касаются только **неотслеживаемых** файлов — тех, которых ещё нет в
репозитории. `.env` закоммичен давно: git его знает и продолжает следить, что бы ни было
написано в `.gitignore`.

Как git отпускает такой файл:

1. Файл убирают из **индекса** — из списка того, что войдёт в следующий коммит.
   Обычный `git rm` убирает файл и из индекса, и с диска. Но у него есть ключ, который
   трогает только индекс: файл остаётся на месте.
2. Делают коммит. В нём записано «файла больше нет», хотя на диске он есть.
3. После такого коммита файл для git становится неотслеживаемым — и тогда строка в
   `.gitignore` начинает работать.
