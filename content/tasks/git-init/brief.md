# git — первые команды

Все команды git работают в каталоге репозитория (или глубже) — как `ls` смотрит туда, где
ты стоишь. Поэтому сначала перейди в каталог проекта, а потом:

1. Заведи историю (репозиторий) в текущем каталоге:

       git init

2. Спроси, что git думает о файлах прямо сейчас — какие новые, какие изменены, какие уже
   сохранены:

       git status

3. Сохрани состояние коммитом с сообщением:

       git commit -m "Что сделано"
