# git

**git** хранит историю файлов в каталоге: каждое сохранённое состояние — **коммит** с
автором, временем и сообщением «что поменял». К любому коммиту можно вернуться, любые два —
сравнить.

Завести историю (репозиторий) в текущем каталоге:

    git init

Что git думает о файлах прямо сейчас — новые, изменённые, сохранённые:

    git status

Сохранить состояние коммитом с сообщением:

    git commit -m "Что сделано"

Все команды git работают в каталоге репозитория (или глубже) — как `ls` смотрит туда, где ты стоишь.
