# Сначала — в индекс

git не сохраняет в коммит всё подряд. Сначала файлы кладут в **индекс** — список того, что
войдёт в следующий коммит:

    git add notes.txt      # один файл
    git add .              # всё в текущем каталоге

`git status` показывает обе группы: «Changes to be committed» — уже в индексе,
«Untracked» и «not staged» — пока нет. Когда всё нужное в индексе — `git commit`.
