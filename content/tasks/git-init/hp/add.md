# Сначала — в индекс

git не сохраняет в коммит всё подряд. Между файлами и коммитом есть промежуточный список —
**индекс**: то, что войдёт в следующий коммит. Поэтому коммит делают в три шага:

1. Положи файлы в индекс:

       git add notes.txt      # один файл
       git add .              # всё в текущем каталоге

2. Проверь `git status`. В нём две группы:
   - «Changes to be committed» — уже в индексе;
   - «Untracked» и «not staged» — пока нет.
3. Когда всё нужное в индексе — `git commit`.
