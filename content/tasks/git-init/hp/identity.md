# Кто ты?

Каждый коммит подписан: имя и почта автора. git их пока не знает, поэтому коммит не вышел.

1. Представься один раз — git запомнит это для всех репозиториев (ключ `--global` пишет в
   `~/.gitconfig`):

       git config --global user.name "Имя"
       git config --global user.email "почта@example.com"

2. Повтори коммит.

Почта может быть любой — git её не проверяет.
