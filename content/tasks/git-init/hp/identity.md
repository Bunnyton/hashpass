# Кто ты?

Каждый коммит подписан: имя и почта автора. git их пока не знает — представься один раз,
и он запомнит для всех репозиториев (ключ `--global` пишет в `~/.gitconfig`):

    git config --global user.name "Имя"
    git config --global user.email "почта@example.com"

Почта может быть любой — git её не проверяет.
