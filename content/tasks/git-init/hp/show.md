# Что внутри коммита

`git log` перечисляет коммиты — хеш, автор, дата, сообщение, — но самих правок не показывает.
Чтобы увидеть, что поменялось, коммит открывают целиком:

    git show 5e1f0c3     # один коммит: кто, когда и какие строки поменял

1. Хеш — длинное имя коммита, оно стоит в `git log` после слова `commit`.
2. Набирать его целиком не нужно: хватит первых семи знаков.
