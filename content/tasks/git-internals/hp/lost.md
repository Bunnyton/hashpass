# Объекты, на которые никто не ссылается

`git add` не ждёт коммита: он сразу кладёт содержимое файла в склад объектов, а в индекс
записывает ссылку на него. Уберёшь файл из индекса — ссылка пропадёт, а объект останется. На
него больше никто не ссылается: ни коммит, ни индекс. Такой объект называется **dangling** —
«висячий», ничей.

Ничьи объекты git не удаляет сразу — только при уборке, и то если им больше двух недель. А
найти их умеет проверка целостности репозитория:

    git fsck        # проверить склад и показать ничьи объекты

Имени файла у blob нет — только содержимое. Какой из ничьих объектов нужный, придётся
посмотреть.
