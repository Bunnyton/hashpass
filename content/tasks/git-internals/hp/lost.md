# Объекты, на которые никто не ссылается

Как файл может пропасть из истории, но остаться в репозитории:

1. `git add` не ждёт коммита: он сразу кладёт содержимое файла в склад объектов.
2. В индекс он записывает только ссылку на этот объект.
3. Уберёшь файл из индекса — ссылка пропадёт, а объект останется.
4. На него больше никто не ссылается: ни коммит, ни индекс. Такой объект называется
   **dangling** — «висячий», ничей.

Ничьи объекты git не удаляет сразу — только при уборке, и то если им больше двух недель. А
найти их умеет проверка целостности репозитория:

    git fsck        # проверить склад и показать ничьи объекты

Имени файла у blob нет — только содержимое. Какой из ничьих объектов нужный, придётся
посмотреть.
