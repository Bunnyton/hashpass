# История

Список коммитов, от новых к старым:

    git log
    git log --oneline      # по строке на коммит

У каждого коммита есть **хеш** — длинное шестнадцатеричное имя вроде `3f9c2e1d…`. Для команд
git хватает первых семи символов. Показать один коммит целиком — что и где поменялось:

    git show 3f9c2e1

История одного файла: `git log notes.txt`.
