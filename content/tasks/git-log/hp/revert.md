# Отмена коммита

Коммит, который уже в истории, не стирают — его **отменяют новым коммитом** с обратной правкой.
Был `+ строка` — отмена делает `- строка`. Всё, что сделали после, остаётся на месте.

    git revert 41c0a2e

1. git считает, что поменял коммит `41c0a2e`, и делает правку наоборот.
2. Откроется редактор с готовым сообщением «Revert "…"» — сохрани и выйди (в vim: `:wq`).
   Не хочешь редактор — добавь `--no-edit`, сообщение останется как есть.
3. В `git log` появится новый коммит. Старый тоже на месте: в истории видно и ошибку, и её отмену.

Если после ошибочного коммита кто-то правил те же строки, git остановится на конфликте — его
разбирают так же, как при слиянии.
