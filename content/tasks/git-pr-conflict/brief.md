# Когда pull request не сливается

Сайт сливает pull request сам, только если ветку можно влить в main без вопросов. Что
мешает, он пишет под кнопкой слияния. Чаще всего это одно из двух:

- **конфликт** — пока PR ждал, в main влили другой, и он правит те же строки;
- **красные проверки** — тесты на коде ветки упали.

Ни то ни другое на сайте не чинят: правят у себя в ветке и отправляют её снова. PR
обновляется сам.

Твоя ветка — `combo` в ~/shop. Сайт — `carbonyl http://localhost:8930`.
