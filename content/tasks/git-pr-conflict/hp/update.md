# Обновить ветку pull request

Пока твой PR ждал, в main влили чужой. Теперь они правят одни и те же строки, и сайт не
может слить твою ветку сам: конфликт разбирают **у себя**, а на сервер отправляют уже
разобранное.

1. Забери свежий main с сервера: `git fetch`.
2. Влей его в свою ветку — или перестрой ветку поверх него:

       git merge origin/main          # коммит слияния в твоей ветке
       git rebase origin/main         # или: твои коммиты поверх main

3. Разбери конфликт, как обычно, и закончи слияние (или перестройку).
4. Отправь ветку. После `rebase` у коммитов новые хеши — понадобится осторожная перезапись.

PR обновится сам, и проверки пройдут заново — уже на коде вместе с новым main.
