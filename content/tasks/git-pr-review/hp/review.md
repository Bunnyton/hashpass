# Как делают ревью

Ревьюер читает **изменения** — не весь проект, а diff pull request'а. Вопросы к каждой
правке простые: что эта строка делает? что будет на обычных данных? на краевых?

Замечание оставляют прямо **у строки** — значок 💬 рядом с её номером. Так автор видит,
о чём речь, и обсуждение не теряется.

Когда прочитал всё, отправляешь отзыв целиком — внизу страницы, раздел «Ревью»:

- **одобрить** — можно сливать;
- **запросить изменения** — сливать нельзя, пока автор не поправит;
- **комментарий** — вопрос без решения.

Тесты в PR тоже код. Если тест поменяли вместе с программой — проверь, что тест
по-прежнему проверяет правильное, а не подогнан под новое поведение.
