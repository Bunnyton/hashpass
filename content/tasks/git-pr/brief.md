# Через pull request

В командах main обычно **защищена**: напрямую в неё не отправить. Каждое изменение идёт
так:

1. Своя ветка, коммиты в ней.
2. Ветку — на сервер.
3. На сайте команды — **pull request**: «влейте мою ветку в main».
4. Коллеги смотрят изменения и пишут отзыв, автоматические проверки гоняют тесты.
5. Всё хорошо — ветку сливают в main кнопкой на сайте.

Первые два шага ты уже умеешь:

    git switch -c имя-ветки
    git push -u origin имя-ветки
