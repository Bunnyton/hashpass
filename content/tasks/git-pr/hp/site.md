# Лепка — сайт, где живёт pull request

Ветка на сервере — это только код. Чтобы её влили в main, открывают **pull request**
(на GitLab — merge request): страницу с вопросом «влейте, пожалуйста, мою ветку в main».
На ней видно, что изменилось, проходят ли проверки, и коллеги пишут отзывы. Сливают —
кнопкой на сайте.

У команды свой сайт для этого — **Лепка**: http://localhost:8930. Открыть прямо в
консоли — браузером `carbonyl`:

    carbonyl http://localhost:8930

Ссылки и кнопки нажимаются мышью, текст вводится с клавиатуры, назад — `Alt+←`.
Выход — `Ctrl+C`.

На сайте: репозиторий → ветки → «открыть pull request» → заголовок и описание →
«Создать pull request».
