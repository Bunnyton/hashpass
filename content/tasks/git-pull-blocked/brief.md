# Когда git pull отказывает

`git pull` — это `git fetch` (скачать новые коммиты) + `git merge` (влить их в твою ветку).
Слияние меняет файлы в рабочем каталоге. Поэтому перед слиянием git смотрит: не затрёт ли
он что-то, чего нет ни в одном коммите?

Если затрёт — git **ничего не делает** и объясняет почему:

    error: Your local changes to the following files would be overwritten by merge:
    	notes.md
    Please commit your changes or stash them before you merge.
    Aborting

Это не поломка, а защита. Твоя правка цела, репозиторий в прежнем состоянии.

## Что делать

1. Прочитай ответ git до конца: какой файл мешает и что он предлагает.
2. Убери помеху так, чтобы ничего не потерять.
3. Повтори `git pull`.
4. Верни своё, если убирал временно.

Что сейчас изменено и что лежит вне git, всегда скажет `git status`.
