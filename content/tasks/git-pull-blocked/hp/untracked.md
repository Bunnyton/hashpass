# Неотслеживаемый файл на дороге

Твой `report.txt` git ни разу не видел в коммитах — это **неотслеживаемый** файл.
А напарница прислала свой файл с тем же именем. Слияние положило бы её файл на место
твоего, и черновик пропал бы без следа: у git нет его копии. Поэтому git отказывается.

Как пройти:

1. Убери свой файл с дороги — переименуй или перенеси.
2. Повтори `git pull`: файл напарницы встанет на своё место.
3. Сравни два отчёта и реши, что из твоего черновика взять.

Полка тоже годится, но только с ключом для неотслеживаемых файлов — без него `git stash`
таких файлов не берёт.
