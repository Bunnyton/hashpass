# Это слияние, а не перенос

`git merge` склеивает линии **коммитом слияния** — именно против этого правило команды.
Ветка search при этом так и растёт от старого main.

Как вернуться назад:

1. Слияние ещё не закончено (git ждёт разрешения конфликта)? Его можно отменить целиком —
   у `git merge` есть для этого ключ, он в `git merge --help` рядом со словом *abort*.
2. Коммит слияния уже сделан? Не беда: `git reflog` помнит каждое положение ветки. Найди в
   нём хеш до слияния.
3. `git reset --hard <хеш>` вернёт ветку на это положение.

Потом — перенос.
