# Это слияние, а не перенос

`git merge` склеивает линии **коммитом слияния** — именно против этого правило команды.
Ветка search при этом так и растёт от старого main.

Если слияние ещё не закончено (git ждёт разрешения конфликта), его можно отменить целиком —
у `git merge` есть для этого ключ, он в `git merge --help` рядом со словом *abort*.

Если коммит слияния уже сделан — не беда: `git reflog` помнит каждое положение ветки, а
`git reset --hard <хеш>` возвращает её на любое из них.

Потом — перенос.
