# Ветка — это просто имя

Коммиты ветки `epilogue` никуда не делись: удалилось только **имя**, метка, которая на них
указывала. Метку можно повесить заново на любой коммит — `git branch` принимает после имени
новой ветки хеш, с которого её начать.

Осталось понять, какой коммит был вершиной ветки. Журнал HEAD читается снизу вверх: где ты
стоял в ветке в последний раз, перед тем как уйти из неё?
