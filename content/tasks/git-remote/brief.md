# Сервер

Общий репозиторий команды лежит на сервере — GitHub, GitLab или просто машина в офисе. У себя
работают с его **клоном**: полной копией со всей историей.

    git clone https://github.com/user/project.git      # создаст каталог project
    git clone /srv/git/other.git ~/other                # путь на этой же машине тоже годится

Сервер для клона называется `origin`. Свои новые коммиты отправляют туда командой

    git push
