# Сервер

Пока история лежит только на твоём компьютере, у неё две беды:

- умрёт диск — пропадёт всё;
- коллеги не видят твоих правок.

Поэтому общий репозиторий команды держат на **сервере** — GitHub, GitLab или просто машина
в офисе.

## Клон

git распределённый: у каждого участника лежит **полная копия** со всей историей — **клон**.
Работают у себя: коммитят, смотрят историю, создают ветки — без сети. А сервер нужен, чтобы
обмениваться коммитами.

## Как работают с сервером

1. Один раз скачай проект целиком — склонируй его:

       git clone https://github.com/user/project.git   # создаст каталог project
       git clone /srv/git/other.git ~/other             # путь на этой же машине тоже годится

   Сервер, с которого склонировали, git запоминает под именем `origin`.
2. Работай в клоне как обычно: правь файлы, делай коммиты.
3. Отправь свои новые коммиты на сервер:

       git push

Коммит, который ты не отправил, есть только у тебя. Отправил — его получат все, кто заберёт
изменения с сервера.
