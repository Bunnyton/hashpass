# Сначала забери чужое

Сервер отказал: в его `main` есть коммиты, которых у тебя нет, — кто-то отправил их раньше.
Затереть их git не даст. Сначала скачай и влей чужие изменения к себе:

    git pull

Если ваши коммиты не трогали одни и те же строки, git соединит их сам и откроет редактор
для сообщения слияния — сохрани и выйди. Потом снова `git push`.
