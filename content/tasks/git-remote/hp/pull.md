# Сначала забери чужое

Сервер отказал: в его `main` есть коммиты, которых у тебя нет, — кто-то отправил их раньше.
Затереть их git не даст. Порядок такой:

1. Скачай и влей чужие изменения к себе:

       git pull

2. Если ваши коммиты не трогали одни и те же строки, git соединит их сам и откроет редактор
   для сообщения слияния — сохрани и выйди.
3. Теперь у тебя есть всё, что на сервере, плюс твоё. Снова `git push`.
