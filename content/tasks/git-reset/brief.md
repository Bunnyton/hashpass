# Три места, где живут изменения

У git изменения проходят три ступени, и отменять их можно на каждой:

    рабочий каталог  --git add-->  индекс  --git commit-->  история (HEAD)

- **Рабочий каталог** — файлы, как ты их видишь и правишь.
- **Индекс** (staging area) — черновик следующего коммита: то, что ты уже отложил `git add`.
- **История** — коммиты. `HEAD` — коммит, на котором ты сейчас стоишь.

`git status` показывает первые два: «Changes to be committed» — это индекс, «Changes not
staged for commit» — файлы. А в скобках под каждым заголовком git сам пишет, какой
командой это отменить.

Коммиты отсчитывают от `HEAD` тильдой:

    HEAD~1    # на коммит раньше
    HEAD~3    # на три коммита раньше
