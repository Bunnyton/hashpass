# Три места, где живут изменения

В git можно отменить почти всё. Но команда отмены зависит от того, где сейчас лежит
изменение, — поэтому сначала разберёмся с местами.

## Путь изменения

У git изменение проходит три места:

    рабочий каталог  --git add-->  индекс  --git commit-->  история (HEAD)

1. **Рабочий каталог** — файлы, как ты их видишь и правишь.
2. **Индекс** (staging area) — черновик следующего коммита: то, что ты уже отложил `git add`.
3. **История** — коммиты. `HEAD` — коммит, на котором ты сейчас стоишь.

Отменить изменение можно в любом из трёх мест.

## Где что лежит — спроси git status

`git status` показывает первые два места:

- «Changes to be committed» — это индекс;
- «Changes not staged for commit» — это файлы.

А в скобках под каждым заголовком git сам пишет, какой командой это отменить.

## Как назвать коммит в истории

Коммиты отсчитывают назад от `HEAD` тильдой:

    HEAD~1    # на коммит раньше
    HEAD~3    # на три коммита раньше
