# git reset — передвинуть HEAD

`git reset <коммит>` переставляет ветку на другой коммит: всё, что было после него,
пропадает из истории. А что станет с правками из этих коммитов — решает ключ:

    --soft    правки остаются в индексе — готовы к новому коммиту
    --mixed   правки остаются в файлах, индекс пуст (так по умолчанию)
    --hard    правки стираются — и в индексе, и в файлах

`--soft` и `--mixed` ничего не теряют: файлы на диске остаются как были. Правки из снятых
коммитов просто снова становятся незакоммиченными.

Снимать так стоит только коммиты, которые ещё не ушли на сервер: у напарников они уже есть.
