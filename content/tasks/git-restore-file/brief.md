# Достать файл из прошлого

В git ничего не пропадает насовсем: удалённый файл и старая версия файла лежат в
истории. Нужно только найти коммит и достать из него файл.

## 1. Найти коммиты, где менялся файл

    git log --oneline -- notes.md

Покажет только коммиты, которые трогали `notes.md` — даже если сейчас файла уже нет.
Свежие сверху.

## 2. Посмотреть файл, каким он был в коммите

    git show 3f2a9c1:notes.md

Через двоеточие: коммит, потом путь. Ничего не меняет — просто печатает.

## 3. Вернуть файл в рабочий каталог

    git restore --source=3f2a9c1 notes.md

Кладёт файл из указанного коммита на место, остальные файлы не трогает. Вместо хеша
годится любое имя коммита: ветка, тег, `HEAD~2`.
