# Отменить коммит, который уже у всех

Коммит ушёл на сервер, его забрали напарники, поверх уже есть новые коммиты. `reset` тут
не годится: он переписывает историю. Отменяют **новым коммитом**:

    git revert <коммит>

1. git смотрит, что поменял этот коммит.
2. Делает новый коммит с обратными правками.
3. Всё, что было после, остаётся на месте.

Ты так уже чинил магазин с портом 80800. Посмотреть историю вместе с развилками веток:

    git log --oneline --graph

Слияние на этой картинке — коммит, в который сходятся две линии.
