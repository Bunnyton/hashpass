# Какую сторону слияния оставить

У обычного коммита один родитель — предыдущий коммит. У **слияния** родителей два:

    *   7c1e0d2 Merge branch 'search'
    |\
    | * 5b2a9f1 Поиск: фильтр по дате        ← родитель 2: ветка, которую вливали
    * | 3e8d4c0 Цены на лето                 ← родитель 1: main, куда вливали
    |/

Отменить слияние — значит вернуться к одному из родителей. git не угадывает, к какому, —
номер родителя указывают ключом `-m`:

    git revert -m 1 7c1e0d2

`-m 1` — оставить сторону первого родителя (main, куда вливали) и убрать всё, что пришло из
ветки. Родителей коммита по порядку покажет `git log -1 --format=%p <коммит>`.

Коммит отмены git откроет в редакторе с готовым сообщением — достаточно сохранить и выйти.
