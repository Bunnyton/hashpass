# Повторное слияние — с подвохом

Ты отменил слияние, но **само слияние в истории осталось**. Для git коммиты ветки promo
уже влиты в main. Поэтому `git merge promo` несёт только то, что появилось в ветке
**после** первого слияния, — исправление Олега. А исправлять ему нечего: файл, который он
правил, твоя отмена удалила. Отсюда конфликт.

Как вернуть ветку целиком:

1. `git merge --abort` — выйти из застрявшего слияния, всё вернётся как было.
2. Отмени свою отмену — тот же `git revert`, только на коммит отмены. Правки promo
   вернутся в main.
3. Влей promo: придёт только новое — исправление.
4. Проверь `./test.sh`.

Это обычная история в командах: «откатили релиз — починили — вернули».
