# Секреты не живут в git

Пароли, ключи и токены держат в отдельном файле — часто его зовут `.env`. Программа читает
его при запуске, а в репозиторий он не попадает: кто склонировал код, тот не должен получить
доступ к базе.

    $ cat .env
    API_TOKEN=hunter2

Что сейчас лежит в репозитории и что в каком коммите менялось, ты уже умеешь смотреть:

    git ls-files          # файлы, которые знает git
    git log --stat        # какие файлы трогал каждый коммит
    git log -p            # и сами правки

Как перестать следить за файлом, не удаляя его с диска, ты видел в задании про
`.gitignore`.
