# Коммит — это навсегда

Новый коммит убрал `.env` из **последнего** снимка. Но предыдущие коммиты не изменились:
каждый — неизменный снимок всех файлов. Загляни:

    git log -p -- .env

Пароль на месте. Склонирует кто-нибудь репозиторий — получит и его.

Чтобы файла не было в истории, переписывают **тот коммит, где он появился**. Это умеет
уже знакомый `git rebase -i`. Кроме `pick` и `squash` у него есть `edit`: rebase
остановится на этом коммите и даст его поправить.

Пример: в коммит «Добавил конфиг» попал `secrets.txt`.

    git rebase -i <коммит-до-него>    # напротив «Добавил конфиг» — edit вместо pick
    git rm --cached secrets.txt       # убрать из коммита, оставить на диске
    git commit --amend --no-edit      # переписать остановленный коммит
    git rebase --continue             # переложить остальные коммиты поверх

Коммит, который ты сделал только что, после этого станет лишним. Его можно убрать заранее
(`git reset`) — или пусть rebase сам спросит о нём.
