# Отложить работу

Ты полдня делаешь в боте доставку: правки в двух файлах и один новый, ничего ещё не
закоммичено и не работает до конца. И тут пишет менеджер: покупатели видят цену −9000 ₽,
надо починить сейчас. Что делать с недоделкой?

- Закоммитить полуготовое нельзя: в истории окажется сломанный бот.
- Выкинуть — жалко.
- Чинить поверх недоделки — в коммит с исправлением уедет и она.

## Полка

Для этого у git есть **полка** — `git stash`. Как она работает:

1. Забирает незакоммиченные изменения.
2. Возвращает каталог к последнему коммиту: чисто, как будто ты ничего не трогал.
3. Хранит отложенное в репозитории, пока ты его не заберёшь.

Команды:

    git stash          # убрать изменения на полку
    git stash list     # что лежит на полке

Чистый ли каталог, всегда скажет `git status`.
