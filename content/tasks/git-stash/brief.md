# Отложить работу

Ты полдня делаешь в боте доставку: правки в двух файлах и один новый, ничего ещё не
закоммичено и не работает до конца. И тут пишет менеджер: покупатели видят цену −9000 ₽,
надо починить сейчас.

Коммитить полуготовое нельзя: в истории окажется сломанный бот. Выкинуть — жалко. Чинить
поверх недоделки — в коммит с исправлением уедет и она.

Для этого у git есть **полка** — `git stash`. Она забирает незакоммиченные изменения и
возвращает каталог к последнему коммиту: чисто, как будто ты ничего не трогал. Отложенное
хранится в репозитории, пока ты его не заберёшь.

    git stash          # убрать изменения на полку
    git stash list     # что лежит на полке

Чистый ли каталог, всегда скажет `git status`.
