# Забрать с полки

Полка — стопка: последнее отложенное лежит сверху, в `git stash list` это `stash@{0}`.
Забирают тоже сверху — и снова командой `git stash`, только с другим словом после неё.

Все слова, которые понимает `git stash`, перечислены в `git stash --help`, в разделе
COMMANDS: у каждого — абзац о том, что оно делает. Ищи то, что возвращает отложенное
в каталог.

Отложенное ляжет поверх того, что сейчас в последнем коммите, — как будто ты сделал эти
правки только что.
