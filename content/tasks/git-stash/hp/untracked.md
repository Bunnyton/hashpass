# Новые файлы на полку сами не попадают

Полка git забирает только то, за чем git уже следит: изменения в файлах, которые есть в
истории. Новый файл git ещё не знает — в `git status` он в списке **Untracked files**.
Поэтому git оставляет его в каталоге: вдруг это мусор, который тебе и не нужен в истории.

Чтобы новый файл уехал на полку вместе с остальным, есть два пути:

1. Сначала добавить его в индекс (`git add`) — тогда git о нём знает.
2. Или попросить `git stash` прихватить неотслеживаемые файлы. У него есть для этого ключ —
   ищи в `git stash --help` слово *untracked*.

Отложенное раньше никуда не делось — `git stash list` покажет все полки по порядку.
