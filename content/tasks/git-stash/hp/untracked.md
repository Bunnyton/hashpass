# Новые файлы на полку сами не попадают

Полка git забирает только то, за чем git уже следит: изменения в файлах, которые есть в
истории. Новый файл git ещё не знает (в `git status` он в списке **Untracked files**),
поэтому оставляет его в каталоге — вдруг это мусор, который тебе и не нужен в истории.

Чтобы новый файл уехал на полку вместе с остальным, его надо либо сначала добавить
(`git add`), либо попросить `git stash` прихватить неотслеживаемые файлы — у него есть
для этого ключ, ищи в `git stash --help` слово *untracked*.

Отложенное раньше никуда не делось — `git stash list` покажет все полки по порядку.
