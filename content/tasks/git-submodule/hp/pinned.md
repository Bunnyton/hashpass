# Подмодуль закреплён на коммите

Игра помнит не «последнюю версию движка», а **конкретный коммит** движка. Сколько бы Олег
ни выпустил новых версий, у всех, кто клонирует игру, будет тот же коммит — пока кто-то
не переведёт ссылку.

Перевести — две части:

1. **Внутри** подмодуля поставить нужный коммит. Подмодуль — обычный репозиторий: в нём
   работают `git fetch`, `git switch`, `git log`. Есть и короткий путь из корня проекта:

       git submodule update --remote    # подтянуть подмодули к их ветке на сервере

2. **В главном** репозитории закоммитить новую ссылку. `git status` покажет подмодуль как
   изменённый: `modified: lib (new commits)`. Дальше как с обычным файлом — `git add`,
   `git commit`.
