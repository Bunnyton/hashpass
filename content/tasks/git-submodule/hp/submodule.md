# Репозиторий внутри репозитория

Посмотри, что лежит в корне проекта:

    cat .gitmodules

Это **подмодуль** (submodule): каталог, в котором живёт *другой* git-репозиторий со своей
историей и своим сервером. Главный репозиторий хранит про него только две вещи: адрес
(в `.gitmodules`) и **коммит**, на котором подмодуль закреплён.

`git clone` по умолчанию подмодули не скачивает — каталог остаётся пустым. Скачать и
поставить на закреплённый коммит:

    git submodule update --init

`git submodule status` покажет, что с ними сейчас: минус в начале строки — подмодуль ещё
не скачан.

А в следующий раз клонируй сразу с подмодулями: `git clone --recurse-submodules <адрес>`.
