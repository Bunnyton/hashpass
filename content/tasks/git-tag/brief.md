# Тег — закладка на релиз

Тег — метка на коммит, которая никуда не ползёт. Аннотированный тег хранит ещё автора,
дату и сообщение. Ты ставил такой в задании про `cherry-pick`:

    git tag -a v3.0 -m "Версия 3.0" <коммит>

Без `<коммит>` тег встанет туда, где ты сейчас, — на последний коммит. А релиз не всегда
последний: после него уже могли что-то закоммитить.

Посмотреть, какие теги есть и на какие коммиты они смотрят:

    git tag
    git log --oneline --decorate
