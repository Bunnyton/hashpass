# Свой репозиторий — на сервер

Когда ты клонируешь репозиторий, git сам запоминает, откуда он: это сервер с именем
`origin`. А если репозиторий начат у тебя (`git init`), сервера у него нет:

    $ git remote -v
    $

Связать с сервером — один раз:

    git remote add origin /srv/git/notes.git     # имя «origin» и адрес
    git remote -v                                # проверить

Первая отправка — с ключом `-u`: он запоминает, что твоя main ездит в main на сервере.
Дальше хватит просто `git push` и `git pull`.

    git push -u origin main
