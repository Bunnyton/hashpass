# Две истории без общего начала

Обычно у твоей ветки и серверной есть общий предок — коммит, с которого вы разошлись.
Слияние начинается от него.

Здесь общего предка нет. Ты сделал `git init` у себя, а коллега создала репозиторий на
сервере со своим первым коммитом. Это две **несвязанные** истории:

    A ← B ← C        твой main
    X                main на сервере (README, LICENSE)

git подозревает ошибку: вдруг ты тянешь не тот репозиторий? Поэтому отказывается.
Если всё верно и истории действительно нужно соединить, скажи об этом явно:

    git pull --allow-unrelated-histories <сервер> <ветка>

Файл с одинаковым именем в обеих историях git не сможет сложить сам — придётся разобрать
конфликт, как обычно.
