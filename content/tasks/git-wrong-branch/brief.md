# Ветка — это метка

Коммиты не «лежат в ветке». Ветка — просто **метка** с именем, приклеенная к одному
коммиту. Сделал коммит — метка текущей ветки переехала на него.

Как это выглядит:

    A ← B ← C        main
                     ↑ ты здесь

1. `git branch имя` клеит **новую** метку на коммит, где ты стоишь. Ничего не переключает и
   не двигает.
2. Метку можно переставить на любой другой коммит — ты уже делал это `git reset`.
3. Коммит, на который смотрит хоть одна метка, не пропадёт.

## Что лежит на сервере

После `git clone`, `git fetch`, `git pull` git помнит, где ветки стоят на сервере. Это тоже
метки, только с приставкой `origin/`: `origin/main` — main на сервере, как ты видел её в
последний раз. Насколько твоя ветка ушла вперёд, пишет `git status`:

    Your branch is ahead of 'origin/main' by 2 commits.

А целиком картинку — с метками на каждом коммите — показывает `git log --oneline --all`.
