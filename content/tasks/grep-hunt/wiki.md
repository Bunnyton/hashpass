# grep: найти строки в файле

Файл на четыреста строк глазами не прочитаешь — да и не надо. `grep` пробегает файл и
показывает только те строки, где есть нужное слово. Логи, конфиги, чужой код, свои заметки —
`grep` нужен везде, где текста больше одного экрана.

Примеры ниже — на маленьком списке дел `todo.md`:

    $ cat todo.md
    Список дел на неделю
    FIXME: поправить опечатку в шапке
    купить кофе
    fixme: проверить бэкап
    FIXME: обновить сертификат
    позвонить в банк

## Строки со словом

Сначала — что искать, потом — где:

    $ grep FIXME todo.md
    FIXME: поправить опечатку в шапке
    FIXME: обновить сертификат

`grep` различает регистр: строчное `fixme` не нашлось. Если регистр не важен — ключ `-i`:

    $ grep -i fixme todo.md
    FIXME: поправить опечатку в шапке
    fixme: проверить бэкап
    FIXME: обновить сертификат

Если в слове есть пробел или особые символы (`*`, `$`, `?`), бери его в одинарные кавычки:
`grep 'disk full' app.log`.

## Где именно: номера строк

`-n` ставит перед каждой находкой номер строки — удобно, чтобы потом открыть файл на нужном месте:

    $ grep -n FIXME todo.md
    2:FIXME: поправить опечатку в шапке
    5:FIXME: обновить сертификат

## Всё, кроме: `-v`

`-v` переворачивает поиск — показывает строки, где слова **нет**:

    $ grep -v FIXME todo.md
    Список дел на неделю
    купить кофе
    fixme: проверить бэкап
    позвонить в банк

Так из конфига убирают комментарии (`grep -v '^#'`), а из лога — шумные строки.

## grep умеет считать

Часто нужен не список, а число: «сколько ошибок за ночь?». Можно отдать строки другой
команде, но у самого `grep` есть ключ для подсчёта — найди его в `grep --help`. Пара вещей,
которые стоит знать про подсчёт:

- считаются **строки**, а не слова: если в строке слово встретилось дважды, это одна строка;
- ключи складываются: `-i` вместе с ключом подсчёта посчитает и `FIXME`, и `fixme`;
- если файлов несколько, `grep` подпишет, из какого файла каждая строка (`proj/b.txt` —
  ещё один файл с заметками):

      $ grep FIXME todo.md proj/b.txt
      todo.md:FIXME: поправить опечатку в шапке
      todo.md:FIXME: обновить сертификат
      proj/b.txt:FIXME в другом файле

## Целый каталог: `-r` и `-l`

`-r` ищет во всех файлах каталога и его подкаталогов, `-l` печатает только имена файлов, где
нашлось:

    $ grep -r FIXME proj
    proj/b.txt:FIXME в другом файле
    proj/a.txt:FIXME: поправить опечатку в шапке
    proj/a.txt:FIXME: обновить сертификат
    $ grep -rl FIXME proj
    proj/b.txt
    proj/a.txt

Так в проекте ищут, где используется функция или где спрятан пароль.

## Шпаргалка ключей

| Ключ | Что делает |
|---|---|
| `-i` | не различать регистр |
| `-n` | номера строк |
| `-v` | строки **без** слова |
| `-w` | только целое слово: `кот`, но не `котлета` |
| `-o` | только сама находка, а не вся строка |
| `-r` | все файлы каталога |
| `-l` | только имена файлов |
| `--color` | подсветить находку |

Ключи склеиваются: `-in` — то же, что `-i -n`. Полный список — `grep --help` и `man grep`.
