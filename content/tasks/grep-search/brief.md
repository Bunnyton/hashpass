# grep — автоматизация поиска

Обходить дерево руками — долго. Настоящий поиск делает `grep`.

    grep слово файл             # найти слово в файле
    grep -r слово каталог        # то же, но рекурсивно по каталогу
    grep -l                     # показать только имена файлов
    grep -h                     # скрыть имя файла в выводе

Just Google it! (или `man grep`).
