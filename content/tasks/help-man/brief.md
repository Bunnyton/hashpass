# Справка: --help и man

Когда буквенных ключей много, их можно объединять:

    ls -lat
    ls -alt
    ls -l -a -t
    ls -l -at

Все эти команды делают одно и то же.

Но ключом может быть и целое слово — тогда пишут **два дефиса**. Самый
полезный из таких ключей есть почти у каждой команды и печатает краткую
справку по самой команде:

    grep --help
    cp --help

Это шпаргалка. Настоящую **справочную страницу** (manual page) — со всеми
тонкостями — открывает команда `man`:

    man ls
    man grep

Внутри — навигация как в `less`: стрелки, `/` для поиска, `q` — выход.
