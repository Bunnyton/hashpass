# %N — номер задания вместо PID

Почти все команды оболочки про задания понимают **`%номер`**: `fg %1`, `bg %2`. И не только
они: там, где оболочка ждёт PID, можно написать номер задания со знаком процента — она сама
подставит нужный PID.

Номер задания виден в `jobs`. Но это работает только в той
оболочке, которая запустила задание, — чужие процессы находят по PID.
