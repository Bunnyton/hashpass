# Модуль в системе

`insmod` берёт файл по пути и ничего не знает о зависимостях. Системные модули грузит
`modprobe` — по **имени**:

```sh
sudo modprobe loop       # найдёт loop.ko сам, подтянет то, от чего он зависит
sudo modprobe -r loop    # выгрузит
```

Ищет он в каталоге модулей того ядра, что работает: `/lib/modules/$(uname -r)/`. Готовые
модули ядра лежат в `kernel/`, а сторонние кладут рядом — в `updates/` или `extra/`.

Kbuild умеет ставить собранное сам — та же команда сборки, только цель `modules_install`
вместо `modules` (и от root: каталог системный).
