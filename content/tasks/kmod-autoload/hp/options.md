# Параметры по умолчанию

`modprobe` перед загрузкой читает `/etc/modprobe.d/*.conf`. Строка `options` задаёт параметры
модулю — как если бы их написали после имени:

```
# /etc/modprobe.d/loop.conf
options loop max_loop=16
```

Там же `blacklist имя` — запретить автозагрузку. Настройки работают при загрузке модуля: уже
загруженный их не увидит.
