# Модули ядра: первый модуль

Студент пишет модуль hello: собирает его Kbuild-ом (ловушка — без MODULE_LICENSE сборщик
отказывает), грузит в ядро, находит его строку в журнале ядра, выгружает и подписывает
(автор, описание — modinfo). Модули живут в «учебном ядре» — виртуальной машине QEMU внутри
консоли, которой отдана файловая система консоли: insmod, rmmod, lsmod, modprobe, depmod, dmesg
и uname -r работают с ним, kernel — шелл в нём. Ядро компьютера ученика не трогается.
