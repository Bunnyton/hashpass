# Oops

`Killed` — ядро убило `insmod` прямо посреди загрузки модуля. Значит, в журнале ядра — отчёт
о падении, **oops**. Он длинный, но читается сверху вниз:

```
BUG: kernel NULL pointer dereference, address: 0000000000000008   ← что случилось
...
RIP: 0010:имя_функции+0x1a/0x40 [модуль]                         ← где: функция+смещение/размер
...
Call Trace:                                                       ← кто её позвал
 <TASK>
 другая_функция+0x50/0x90 [модуль]
 do_one_initcall+0x58/0x300
```

`NULL pointer dereference` — код полез по пустому указателю: адрес 0 (или чуть больше — тогда
это поле структуры, до которой не дошли). `RIP` — регистр «где сейчас выполняется код»: в нём
и есть место падения.
