# Ядро после oops

Модуль упал посреди `init` — и застрял в ядре полузагруженным: выгрузить его нельзя (ядро не
знает, в каком он состоянии), загрузить второй с тем же именем — тоже. После oops ядро уже не
доверяет само себе — флаг `tainted`, в настоящей системе такую машину перезагружают.

Учебное ядро перезагружается так:

```sh
sudo systemctl restart hpkernel
```

Это как `reboot`, только для учебного ядра: консоль и твои файлы остаются.
