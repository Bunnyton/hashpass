# Модули ядра: параметры

hello получает параметр who: insmod hello.ko who=Тук — и модуль здоровается по имени. Затем
значение меняется на лету через /sys/module/hello/parameters/who в шелле учебного ядра; права
0444 из примера писать не дают — студент узнаёт, что третье число в module_param — права файла.
