# Параметры модуля

В `~/kmod` лежит твой `hello` — он пока здоровается только с миром.

Программе аргументы передают в командной строке, модулю — так же, при загрузке:

```sh
sudo insmod greet.ko name=Вася count=3
```

Чтобы модуль их принял, переменную объявляют параметром:

```c
static char *name = "гость";             /* значение по умолчанию */
module_param(name, charp, 0444);         /* имя, тип, права файла в /sys */
MODULE_PARM_DESC(name, "Кого встречать");

static int count = 1;
module_param(count, int, 0444);
```

Типы — `charp` (строка), `int`, `bool` и другие. Третье число — права файла, через который
параметр виден снаружи: `/sys/module/greet/parameters/name`. `0444` — читать могут все, писать
никто.

Что модуль принимает, расскажет `modinfo greet.ko` — строками `parm:`.
