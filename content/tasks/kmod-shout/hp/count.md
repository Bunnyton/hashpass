# Счётчик в /sys

Параметр модуля — это переменная, которую видно файлом в `/sys/module/<модуль>/parameters/`. Раньше
параметр был строкой (`charp`), а бывает и числом:

```c
static int moons;
module_param(moons, int, 0444);   /* /sys/module/<модуль>/parameters/moons */
```

Модуль может менять такую переменную сам — `cat` файла всегда показывает текущее значение.
