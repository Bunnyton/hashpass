# Свой модуль ядра

Студент пишет модуль ядра Linux: от «привета» в журнале ядра до своего символьного устройства
`/dev/hashpass`, которое отдаёт строку и запоминает записанное. Модуль собирается под ядро
маленькой виртуальной машины (команда `vm`) и испытывается в ней — ядро компьютера не трогается.
