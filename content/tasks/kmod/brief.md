# Свой модуль ядра

Ядро — программа, которая управляет железом, памятью и процессами. Модуль — кусок кода, который
подгружается в уже работающее ядро без перезагрузки: так приходят почти все драйверы.

У модуля нет `main`. Вместо неё две функции: одну ядро зовёт при загрузке модуля, другую — при
выгрузке. Пишет модуль не в терминал, а в журнал ядра — через `pr_info`. Скелет на примере
модуля `greet`:

```c
#include <linux/module.h>
#include <linux/init.h>

MODULE_LICENSE("GPL");

static int __init greet_init(void)
{
        pr_info("greet: загрузился\n");
        return 0;              /* 0 — всё хорошо, модуль остаётся в ядре */
}

static void __exit greet_exit(void)
{
        pr_info("greet: выгрузился\n");
}

module_init(greet_init);
module_exit(greet_exit);
```

Собирает модули не `gcc` напрямую, а система сборки самого ядра — Kbuild. Ей нужен `Makefile`
из одной строки — какие модули собрать (имя `.o`, а не `.c`):

```make
obj-m += greet.o
```

И команда, которая отдаёт этот каталог сборщику ядра:

```sh
make -C /lib/modules/<версия ядра>/build M=$PWD modules
```

`-C` — каталог сборки того ядра, в котором модуль будет жить, `M=` — где лежат твои файлы.
Версию ядра показывает `uname -r`.
