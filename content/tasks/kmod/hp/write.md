# Запись

`echo abc > /dev/hashpass` — это вызов `write` твоего драйвера:

```c
static ssize_t moon_write(struct file *f, const char __user *buf, size_t n, loff_t *off);
```

Данные лежат в памяти программы — к себе их забирает `copy_from_user(куда, buf, сколько)`
(вернёт 0, если всё скопировалось). Вернуть нужно, сколько байт принято. Буфер у драйвера
конечный — больше, чем в него влезает, не бери. И запомни длину: `read` должен отдать ровно то,
что записали.
