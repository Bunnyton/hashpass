# Ссылки

Бывает, один и тот же файл нужен в нескольких местах: конфиг программы — там,
где его ищет программа, а правишь ты его у себя в домашнем каталоге. Копия тут
не годится — правки разъедутся. Нужна **ссылка**.

Символьная ссылка — маленький файл, внутри которого записан путь к другому
файлу или каталогу. Открываешь ссылку — попадаешь туда, куда она указывает.
Создаёт её `ln -s`: сначала — на что ссылаемся, потом — имя ссылки:

    ln -s /etc/hostname myhost         # myhost -> /etc/hostname
    ln -s projects/site site           # ссылка на каталог

`ls -l` показывает ссылку стрелкой: `myhost -> /etc/hostname`.
