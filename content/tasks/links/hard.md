# Жёсткие ссылки

У файла в Linux есть данные и есть **имя** в каталоге, которое на них указывает.
Жёсткая ссылка — это просто **ещё одно имя** тех же данных. Не копия и не
указатель: оба имени равноправны, правишь через одно — меняется и другое.

Делает её тот же `ln`, только без `-s`:

    ln report.txt report-copy.txt

Во втором столбце `ls -l` — число имён у файла: у обычного 1, после `ln` — 2.
