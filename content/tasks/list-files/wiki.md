# Список файлов в файл: ls и >

Иногда список файлов нужен не на экране, а в файле: приложить к отчёту, сравнить «до» и
«после», отдать другой программе. Для этого хватает `ls` и перенаправления `>`.

## ls смотрит в любой каталог

Без аргументов `ls` показывает текущий каталог, с аргументом — указанный:

    $ ls photos
    cat.jpg
    dog.jpg
    sea.png

Путь можно дать относительный (`photos`, `../photos`) или от корня (`/home/student/photos`).

## > — вывод в файл

Символ `>` после команды отправляет её вывод в файл: создаёт его или **перезаписывает**:

    $ ls photos > photos.txt
    $ cat photos.txt
    cat.jpg
    dog.jpg
    sea.png

Заметь: на экране `ls` пишет имена в строку, а в файл — **по одному в строке**. `ls` видит, что
его вывод идёт не человеку, а в файл или в другую программу, и выбирает удобный для обработки
вид. Такой файл легко посчитать (`wc -l`) или отсортировать (`sort`).

## >> — дописать

`>>` добавляет в конец, ничего не стирая. Так можно собрать в один файл списки нескольких
каталогов: первый — через `>`, остальные — через `>>`.

## Ошибки в файл не попадают

    $ ls nosuch > out.txt
    ls: cannot access 'nosuch': No such file or directory
    $ cat out.txt
    $

Сообщение об ошибке ушло на экран, а файл остался пустым. Ошибки идут отдельным каналом; в файл
их отправляет `2>`:

    $ ls nosuch 2> err.txt
    $ cat err.txt
    ls: cannot access 'nosuch': No such file or directory

## Полезные ключи для списков

| Ключ | Что делает |
|---|---|
| `-1` | строго по одному имени в строке (и в терминале) |
| `-a` | и скрытые файлы (с точки) |
| `-l` | подробно: права, владелец, размер, дата |
| `-t` | по времени изменения, свежие сверху |
| `-R` | заодно все вложенные каталоги |

## Грабли

- Файл-результат, сохранённый **в тот же** каталог, может сам попасть в список: оболочка
  создаёт его до того, как `ls` начнёт читать каталог.
- Повторный `>` молча стирает прошлый список.
