# Скрытые файлы и ключи

В Linux **скрытые** файлы — те, чьё имя начинается с точки: `.bashrc`,
`.profile`, `.hidden_key`. Обычный `ls` их не покажет.

У практически каждой команды есть **ключи** — короткие модификаторы:

    ls -l      # длинный формат
    ls -a      # включая скрытые
    ls -la     # оба вместе (буквы можно писать слитно)
    ls -l -a   # или раздельно
