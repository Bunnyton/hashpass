# Поиск в куче файлов: звёздочки, cat и инструменты

Сотня файлов в разветвлённом дереве, и где-то в одном — нужная строка. Можно открывать по
одному. Можно заставить оболочку перечислить их за тебя. А можно взять инструмент, который
для этого и придуман.

## Звёздочка — оболочка подставит имена

`*` в пути — «любые символы». Оболочка (bash) **до** запуска команды заменяет шаблон списком
подходящих имён, и команда получает уже готовые имена. Посмотреть, во что развернётся
шаблон, проще всего через `echo`:

    $ echo letters/*
    letters/2024 letters/2025 letters/readme.md
    $ echo letters/*/*
    letters/2024/drafts letters/2024/jan.txt letters/2025/drafts letters/2025/jul.txt
    $ echo letters/*/*.txt
    letters/2024/jan.txt letters/2025/jul.txt

Одна звёздочка — один уровень дерева. Нужно глубже — добавь ещё `/*`.

Если ничего не подошло, шаблон остаётся как есть:

    $ echo nothing*
    nothing*

## cat берёт сколько угодно файлов

`cat`, как и `cp`, `mv`, `rm`, принимает много имён подряд — вместе со звёздочкой это сотни
файлов одной командой:

    $ cat letters/*/*.txt
    Дорогой дневник
    Привет из лета

Каталоги в список тоже попадают — `cat` на них поругается, но остальное выведет:

    $ cat letters/*/*
    cat: letters/2024/drafts: Is a directory
    Дорогой дневник
    cat: letters/2025/drafts: Is a directory
    Привет из лета

Ругань мешает читать? Её можно убрать с экрана: `2>/dev/null` после команды выбрасывает
сообщения об ошибках.

## Порядок в голове — порядок на диске

Когда инструменты ограничены, помогает тактика:

- `ls каталог/*/` — заглянуть сразу во все подкаталоги;
- то, что уже проверил, — убрать с дороги: `mv` в сторону или `rm -r` (осторожно: корзины нет);
- **Tab** дописывает длинные случайные имена без опечаток.

## Инструменты: искать по содержимому

Звёздочки хороши, пока уровней мало. Когда файлов тысячи, ищут не глазами, а программой,
которая сама читает файлы и печатает только совпадения. Главная такая — `grep`:

    $ grep 'меня' shop/veg/carrot.md
    ищи меня тут
    $ grep 'меня' shop/veg/*
    shop/veg/carrot.md:ищи меня тут

Когда файлов несколько, `grep` пишет перед строкой имя файла — сразу видно, **где** нашлось.
Обходить каталоги вглубь он тоже умеет; как именно — подскажет `grep --help`. Про шаблоны
поиска — wiki [регулярных выражений](/web/wiki/bunnyton/regex), про поиск файлов по
имени и свойствам — [find](/web/wiki/bunnyton/find).

## Где это пригодится

- найти, в каком конфиге задан параметр, не зная файла;
- найти в логах всех служб одну ошибку;
- вспомнить, в каком из своих скриптов ты уже писал нужную строчку.

Мораль задания: перебрать руками можно, но правильный инструмент экономит часы.
