# Midnight Commander: файловый менеджер в терминале

**mc** (Midnight Commander) — две синие панели прямо в терминале, как в Norton Commander из
девяностых. Ходишь стрелками, копируешь между панелями, смотришь и правишь файлы — и всё без
мыши и графики. Его ставят на серверы именно потому, что там графики нет, а разбираться в
чужих каталогах приходится.

Установить: `sudo apt install mc`. Запустить — `mc`, выйти — **F10**.

## Экран

- **Две панели** — в каждой свой каталог. Активная та, где подсвечена строка; **Tab** —
  перейти на другую.
- **Внизу — подписи F-клавиш**: забыл, что делает F6, — посмотри вниз. На них можно и
  щёлкнуть мышью.
- **Над подписями — командная строка**: набираешь обычную команду, Enter — она выполнится
  в каталоге активной панели.
- **Ctrl+O** — спрятать панели и увидеть терминал под ними; ещё раз Ctrl+O — вернуть.

## Ходить и смотреть

| Клавиша | Что делает |
|---|---|
| стрелки, Enter | выбрать, войти в каталог; `..` наверху — на уровень выше |
| **F3** | посмотреть файл (во встроенном просмотрщике F7 — поиск по тексту) |
| **Alt+.** | показать или спрятать скрытые файлы (с точкой) |
| **Ctrl+\\** | избранные каталоги |
| **F9** | верхнее меню: там всё, включая то, что не помнишь наизусть |

## Копировать, двигать, удалять

| Клавиша | Что делает |
|---|---|
| **F5** | копировать на другую панель |
| **F6** | переместить или переименовать |
| **F7** | создать каталог |
| **F8** | удалить |
| **Insert** | отметить файл (несколько — несколько раз) |
| **+** / **\*** | отметить по маске (`*.log`) / перевернуть отметку |

Отметил файлы — F5 или F6 сработают сразу для всех. Перед каждым действием mc показывает
диалог, где можно поправить путь назначения.

## Искать

**Alt+?** (или F9 → Command → Find file) открывает поиск:

- **Start at** — с какого каталога начинать (`.` — текущий);
- **File name** — маска имени: `*` — все файлы, `*.csv` — только CSV;
- **Content** — текст **внутри** файлов. Это главное: mc откроет и прочитает каждый файл
  за тебя.

Результаты — списком; Enter на строке переносит панель к найденному файлу, кнопка
**Panelize** складывает все находки в панель, и с ними можно работать как с каталогом.

В командной строке это делает `grep -r слово каталог` — см. [wiki grep-hunt](/web/wiki/bunnyton/grep-hunt).

## Редактор mcedit

**F4** — редактировать выбранный файл, **Shift+F4** — новый файл (имя mc спросит). То же из
командной строки: `mcedit имя`.

| Клавиша | В редакторе |
|---|---|
| **F2** | сохранить |
| **F10** или Esc | выйти (если не сохранил — спросит) |
| **F7** / **F4** | найти / заменить |
| **F3** | начать и закончить выделение блока |
| **F5** / **F6** / **F8** | копировать / переместить / удалить блок |
| **Ctrl+Y** | удалить строку |
| **Ctrl+U** | отменить |

В Debian F4 по умолчанию может открыть внешний редактор (`nano`, `vim`). Встроенный включается
в F9 → Options → Configuration → **Use internal edit**.

## Копировать текст с экрана

mc перехватывает мышь, поэтому обычное выделение не работает. Зажми **Shift** и выделяй
мышью — выделение достанется терминалу, дальше копируй как обычно.
