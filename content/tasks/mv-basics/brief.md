# Перемещение — mv

По аналогии с `cp` есть команда `mv`:

    mv source dest

Только она не копирует, а **переносит** (или **переименовывает**) файлы.

Шпаргалка:

    mv → move
    cp → copy

Кстати, в Linux у файлов нет «расширений» в винда-смысле. Точка и три
буквы в конце — просто часть имени. Тип файла ОС определяет по сигнатуре
внутри самого файла (см. команду `file`).
