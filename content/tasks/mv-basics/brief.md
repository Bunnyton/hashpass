# Перемещение — mv

По аналогии с `cp` есть команда `mv`:

    mv source dest

Только она уже не копирует, а **переносит** файлы. Чтобы запомнить:

    mv → move
    cp → copy

**Текущая директория** — та, в которой ты сейчас находишься. Её покажет `pwd`.
В относительных путях `.` означает текущую директорию, а `..` — на уровень выше.
