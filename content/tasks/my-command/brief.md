# Своя команда

Когда ты набираешь `ls`, оболочка ищет файл с именем `ls` в каталогах из переменной
**`PATH`** и запускает его. Посмотри сам:

    echo $PATH          # где ищут команды, через двоеточие
    which ls            # где нашёлся ls

Значит, своя команда — это файл с командами (**скрипт**), который лежит в одном из этих
каталогов и которому разрешено исполняться.

Скрипт начинается со строки, которая говорит, чем его выполнять:

    #!/bin/bash
    echo "Привет, $USER"

Дальше — `chmod +x файл`, и файл можно запускать. Для всех пользователей команды кладут
в `/usr/local/bin` (через `sudo`).

Что пригодится внутри скрипта:

    n=5                       # переменная (без пробелов вокруг =)
    echo $n                   # её значение
    n=$((n + 1))              # арифметика
    n=$(cat файл)             # вывод команды — в переменную
    echo $n > файл            # и обратно в файл

Если файла ещё нет, `cat` ругнётся. `$(cat файл 2>/dev/null || echo 0)` вернёт
содержимое, а если файла нет — 0.
