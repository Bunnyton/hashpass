# Зайти на другую машину

Файлы сайта лежат на сервере, а не у тебя. Чтобы их поправить, нужно оказаться **там**.

1. `ssh` открывает оболочку на другой машине: `ssh <пользователь>@<машина>`.
2. Первый раз ssh спросит, доверяешь ли ты этой машине, — ответь `yes`.
3. Потом — пароль того пользователя на той машине.
4. Дальше всё, что ты набираешь, выполняется на сервере. На какой ты машине, видно в начале строки приглашения (и скажет `hostname`).
5. `exit` закрывает ssh и возвращает тебя домой.

```
ssh anna@printer
```

Веб-сервер **nginx** берёт страницы из каталога, который записан в его настройках:
`/etc/nginx/sites-enabled/default`, строка `root`.
