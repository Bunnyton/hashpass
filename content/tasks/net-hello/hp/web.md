# Сайт без браузера

Сайт — это программа на другой машине (веб-сервер), которая по запросу отдаёт страницу.
Браузер только просит страницу и рисует её. Попросить можно и из консоли:

1. `curl` отправляет запрос по адресу и печатает ответ сервера как есть — текстом.
2. Адрес сайта начинается с `http://`, дальше имя машины: `http://printer/`.

```
curl http://printer/
```

На экран придёт HTML — текст страницы с разметкой в угловых скобках. Читать его можно глазами.
