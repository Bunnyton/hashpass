# Всё своё — с собой

AppImage не ставит зависимостей: всё, что нужно программе, кладут внутрь AppDir. Взять
готовое из пакетов Debian можно без установки:

```sh
apt-get download cowsay           # скачать .deb в текущий каталог (root не нужен)
dpkg -x cowsay_*.deb HelloCat.AppDir   # распаковать файлы пакета в AppDir
```

`dpkg -x` только распаковывает: скрипты пакета не запускаются, и всё, что они делают при
установке (например, ссылки на команды), не появится.

Программа из AppDir найдёт соседей, только если ей сказать, где искать. Это делает `AppRun`
через переменные окружения: `PATH` — где искать команды, а многие программы читают и свои
переменные. `figlet` берёт шрифты из каталога в `FIGLET_FONTDIR`.
