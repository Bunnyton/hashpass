# Контрольные суммы

Для каждого файла из `source` PKGBUILD хранит контрольную сумму — `makepkg` сверит её перед
сборкой. Так пакет не соберётся из подменённого или битого архива.

Суммы не считают руками: `makepkg -g` скачает исходники, посчитает и напечатает готовую
строку `sha256sums=(…)` — её остаётся вписать в PKGBUILD. Поменял архив — сумму пересчитать.
