# Пакеты: .deb руками

Из готовой программы pelmeni студент собирает .deb через dpkg-deb: дерево с DEBIAN/control,
установка через apt (figlet приходит по Depends — ставить его руками нельзя), выпуск 1.1 с
man-страницей и обновление установленного пакета. Образ — база всего блока: в нём все
сборщики пакетов.
