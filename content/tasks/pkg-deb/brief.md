# Пакет .deb изнутри

`.deb` — это архив: файлы программы плюс **паспорт** пакета (имя, версия, от чего зависит).
`apt install` скачивает такой файл и раскладывает его по системе. Собрать свой — значит
сложить то же самое руками.

Пакет собирают из каталога, который повторяет корень системы. Что должно оказаться в
`/usr/bin`, лежит в `<каталог>/usr/bin`; паспорт — в `<каталог>/DEBIAN/control`. Например,
пакет `hello-cat`:

```
hello-cat/
├── DEBIAN/
│   └── control
└── usr/
    └── bin/
        └── hello-cat
```

`control` — строки «поле: значение»:

```
Package: hello-cat
Version: 0.3
Architecture: all
Maintainer: Вася Пупкин <vasya@example.com>
Description: печатает котика
```

`Architecture: all` — пакет для любого процессора (скрипт); бинарник под x86 был бы `amd64`.

Собирает пакет `dpkg-deb`:

```sh
dpkg-deb --root-owner-group --build hello-cat hello-cat_0.3_all.deb
```

`--root-owner-group` — файлы в пакете будут принадлежать root, а не тебе. Имя файла по
традиции — `имя_версия_архитектура.deb`.

Исходники лежат в `~/pelmeni`: сама программа `pelmeni` и всё, что к ней прилагается.
