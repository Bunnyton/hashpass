# Пакет .deb

`.deb` — это архив: файлы программы, разложенные так, как они лягут в систему, плюс **паспорт**
пакета — имя, версия, от чего зависит. `apt install` скачивает такой архив и раскладывает его.

Чтобы понять, как пакет устроен, достаточно заглянуть в любой готовый:

```sh
apt download cowsay                    # скачать .deb в текущий каталог, без установки
dpkg-deb -I cowsay_*.deb               # паспорт
dpkg-deb -c cowsay_*.deb               # какие файлы и куда ляжут
dpkg-deb -R cowsay_*.deb cowsay-tree   # разложить всё в каталог — вместе с паспортом
```

В разложенном каталоге видно, из чего пакет собран: дерево повторяет корень системы
(`cowsay-tree/usr/games/cowsay` встанет в `/usr/games/cowsay`), а паспорт лежит в
`DEBIAN/control`.

Собрать свой — обратная операция: сложить такой же каталог и упаковать его.

```sh
dpkg-deb --root-owner-group --build cowsay-tree cowsay_1.0_all.deb
```

`--root-owner-group` — файлы в пакете будут принадлежать root, а не тебе. Имя файла по
традиции — `имя_версия_архитектура.deb`; `all` — пакет для любого процессора (скрипт).

Исходники твоей программы — в `~/pelmeni`.
