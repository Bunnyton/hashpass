# control

`dpkg-deb` ищет паспорт строго в `DEBIAN/control` внутри собираемого каталога — большими
буквами, без расширения. Обязательные поля:

| Поле | Что это |
|---|---|
| `Package` | имя: строчные латинские буквы, цифры, `+ - .` |
| `Version` | версия, начинается с цифры |
| `Architecture` | `all` для скриптов, `amd64` для бинарников |
| `Maintainer` | кто собрал: `Имя <почта>` |
| `Description` | одна строка — о чём пакет |

Каждое поле — с новой строки, после двоеточия пробел. В конце файла — перевод строки.
