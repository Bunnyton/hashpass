# Зависимости

Программе нужен `figlet`, а пакет об этом молчит. На твоём компьютере его можно доставить
руками, но пакет для того и нужен, чтобы ставиться **одной командой** где угодно.

Что нужно пакету, пишут в `control` полем `Depends`:

```
Depends: figlet, curl (>= 7.0)
```

Через запятую; в скобках — версия, если важна. `dpkg` такой пакет поставит только когда всё
нужное уже стоит, а `apt install ./файл.deb` сам скачает недостающее из репозитория.

Поменял `control` — пересобери пакет и поставь заново.
