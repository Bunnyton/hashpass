# Исходный пакет Debian

Всё в репозиториях Debian и Ubuntu собрано не из готового дерева, а из **исходников**. Рядом с
кодом программы лежит каталог `debian/` — рецепт, — и команда `dpkg-buildpackage` по нему сама
собирает, раскладывает и упаковывает.

Исходники любого пакета можно скачать и посмотреть — root не нужен:

```sh
apt-get source cowsay        # скачать и распаковать исходники в ./cowsay-<версия>/
```

Главное внутри — `debian/`:

| Файл | Что в нём |
|---|---|
| `control` | паспорт исходников и пакетов, которые из них получаются |
| `rules` | как собрать |
| `changelog` | история версий — отсюда берётся версия пакета |

Сделать такой каталог для своей программы с нуля не нужно: заготовку пишет `dh_make`. Его
запускают в каталоге исходников:

```sh
dh_make -n -s -y -p cowsay_3.8     # -n: упаковка живёт вместе с программой, -s: один пакет
dpkg-buildpackage -us -uc -b       # собрать .deb; -us -uc: без подписи, -b: только пакет
```

Готовый `.deb` появится на уровень выше каталога исходников. Кто ты и какая у тебя почта,
`dh_make` спросит у переменных `DEBFULLNAME` и `DEBEMAIL` — можно и не задавать.

Исходники твоей программы — в `~/pelmeni`.
