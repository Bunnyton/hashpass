# lintian

`lintian` проверяет пакет по правилам Debian — сотни проверок: права, пути, описание, лицензия.

```sh
lintian hello-cat_0.4_all.deb
```

Каждая строка — `буква: пакет: проблема`. Если есть хоть одна `E:`, `lintian` завершается с
ошибкой.

Одна ошибка здесь — ложная тревога: `description-synopsis-is-duplicated` на русском описании.
`lintian` сравнивает строки без русских букв и принимает разные фразы за одинаковые. Её можно
не чинить.
