# Зависимости и история

От чего зависит пакет, spec пишет в заголовке:

```
Requires: figlet
```

История версий — последний раздел, `%changelog`, свежее — сверху:

```
%changelog
* Mon Nov 09 2026 Вася Пупкин <vasya@example.com> - 0.4-1
- Котик стал пушистее.
```

Новая версия — новый тарбол `имя-версия.tar.gz` в `SOURCES`: `%setup` будет искать каталог
`имя-версия/`.
