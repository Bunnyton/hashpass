# Полевой аудит

Систему собирали в спешке — даже базовых инструментов нет. Ваша задача:

1. Установить пакет **`procps`** (там живут `ps`, `pgrep`, `pkill`) и оставить след установки — файл `/install-status.txt` с одной строкой `Status: install ok installed`.
2. Запустить фоновый `sleep 600 &` и, воспользовавшись свежеустановленным `pgrep`, записать число активных sleep-процессов в `/proc-count.txt`.

Обе стадии проверяются **вживую по файлу-артефакту**, а не по наличию бинарника: важно, что вы что-то реально сделали, а не просто «apt посмотрел».

Нажмите **Enter**.
