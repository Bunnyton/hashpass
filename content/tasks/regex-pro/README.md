# Регулярные выражения: продолжение

Вторая половина regular_tutor (github.com/Bunnyton/regular_tutor): `\b` и `\S`, `grep -P`,
просмотр вперёд и назад, отрицательный просмотр, нежадные повторы. Студент вытаскивает из
чека суммы, из лога — имена, из текста — слова в кавычках; принимается любой шаблон с той же
находкой.
