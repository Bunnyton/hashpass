# Регулярные выражения

По мотивам regular_tutor (github.com/Bunnyton/regular_tutor). Шаг за шагом: `.`, наборы `[ ]`,
отрицание `[^ ]`, повторы `{ }` и `-E`, экранирование, `*` и `+`, `^` и `$`, `?`, группы `( )`.
Студент пишет шаблон для grep, и ответ принимается по тому, что grep показал: подходит любой
шаблон с той же находкой. Продолжение — regex-pro.
