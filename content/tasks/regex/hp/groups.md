# Группы: ( )

В `-E` круглые скобки собирают кусок шаблона в одно целое — и повтор действует на весь кусок:

    (abc){3}       abcabcabc
    (ха)+          ха, хаха, хахахаха
    ( ?[0-9]){4}   четыре цифры, перед каждой может быть пробел

    $ echo "ха хаха хахаха" | grep -E '(ха){3}'
    ха хаха ==хахаха==

Сравни: без скобок повтор достаётся только последнему символу:

    $ echo "abcabcabc abccc" | grep -E 'abc{3}'
    abcabcabc ==abccc==

Скобки говорят «повтори вот это всё».
