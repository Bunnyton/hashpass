# Повторы: { }

`[0-9][0-9][0-9]` — три цифры подряд. А если их двадцать? Для повторов есть фигурные скобки:

    [0-9]{3}       ровно три цифры
    [abc]{3,5}     от трёх до пяти символов из a, b, c
    a{2,}          два a и больше

`{ }` — уже **расширенный** синтаксис, обычный grep его не понимает. Включи его ключом `-E`:

    $ echo "aaaaa bbbb ccc" | grep -E '[abc]{4,5}'
    ==aaaaa== ==bbbb== ccc

В `-E` у круглых скобок тоже появляется смысл (до него дойдём). А чтобы искать **настоящую**
скобку, перед ней ставят обратную косую черту: `\(` и `\)`.
