# Шпаргалка по регуляркам grep

← [Регулярные выражения в grep](../wiki.md)

| Шаблон | Что находит | Пример |
|---|---|---|
| `.` | любой один символ | `.ар` → кар, бар |
| `[abc]` | один из перечисленных | `c[ao]t` → cat, cot |
| `[0-9]` | одна цифра | `[0-9][0-9]` → 42 |
| `[^a-z]` | один символ, кроме перечисленных | `[^0-9]` — не цифра |
| `*` | предыдущее сколько угодно раз, и ноль тоже | `ab*` → a, ab, abbb |
| `+` (`\+`) | один или больше | `[0-9]+` → 7, 2026 |
| `?` (`\?`) | ноль или один | `colou?r` → color, colour |
| `{n}` (`\{n\}`) | ровно n раз | `[0-9]{4}` → 2026 |
| `{n,m}` | от n до m раз | `b{2,3}` → bb, bbb |
| `^` | начало строки | `^#` — строка начинается с # |
| `$` | конец строки | `;$` — строка кончается ; |
| `( )` (`\( \)`) | группа — повтор на весь кусок | `(ха)+` → хаха |
| `\|` в `-E` | или | `cat\|dog` |
| `\.` `\\` `\(` | сам символ, а не команда | `3\.14` |

В скобках `( )` — запись для `grep -E`; без `-E` те же команды пишутся с обратной косой.

## Ключи grep

| Ключ | Что делает |
|---|---|
| `-o` | показать только находки |
| `-E` | расширенный синтаксис |
| `-i` | не различать регистр |
| `-v` | строки, где шаблона **нет** |
| `-c` | сколько строк нашлось |
| `-n` | номера строк |
| `-r` | искать во всех файлах каталога |
| `-P` | регулярки как в Perl/Python: `\d`, просмотры `(?=…)` — это уже задание regex-pro |
