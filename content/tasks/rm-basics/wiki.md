# rm: удаление файлов, каталогов и скрытого

`rm` (remove) удаляет. Без корзины, без «Отменить» и обычно без вопросов. Поэтому в этом деле
главное — сначала посмотреть, что именно сейчас исчезнет.

## Файл

    $ rm a.txt
    $ ls
    b.log
    pics

Удалить несколько — перечисли через пробел или дай шаблон со звёздочкой.

## Каталог: -r

Каталог `rm` без спроса не трогает:

    $ rm pics
    rm: cannot remove 'pics': Is a directory

`-r` (recursive) удаляет каталог со всем, что внутри, на любую глубину. `-v` покажет каждый шаг:

    $ rm -rv full
    removed 'full/f'
    removed directory 'full'

Для **пустого** каталога есть осторожный `rmdir` — с непустым он откажется:

    $ rmdir full
    rmdir: failed to remove 'full': Directory not empty

## -f и -i

| Ключ | Что делает |
|---|---|
| `-f` (force) | не спрашивает и молчит, даже если файла нет |
| `-i` | спрашивает про каждый файл: `rm: remove regular empty file 'b.log'?` |
| `-I` | спросит один раз, если файлов больше трёх или есть `-r` |

    $ rm nosuch
    rm: cannot remove 'nosuch': No such file or directory
    $ rm -f nosuch
    $

`-rf` — самая опасная пара букв в Linux: молча и целиком.

## Звёздочка не видит скрытое

`*` разворачивает оболочка, и **имена с точки** в этот список не входят:

    $ ls -a
    .
    ..
    .cache
    .env
    a.txt
    b.log
    pics
    $ echo *
    a.txt b.log pics
    $ echo .*
    .cache .env

Поэтому «удалить всё через `*`» оставляет скрытые файлы и каталоги — увидеть их можно только
через `ls -a` (или `ls -A` — то же без `.` и `..`). Для скрытых есть свой шаблон — `.*`. В
современном bash (5.2+) он не цепляет `.` и `..`; в старых оболочках цеплял, и `rm -r .*`
пытался удалить родительский каталог — поэтому сначала всегда `echo шаблон`.

## Как удалять и не плакать

1. `ls -a` — что здесь вообще есть.
2. `echo шаблон` — во что развернётся звёздочка, ровно этот список и удалится.
3. Только потом `rm`.

Ещё:

- `rm -r каталог/` с опечаткой в пути (или пробелом в неправильном месте: `rm -r / tmp/x`) —
  классика катастроф. Перечитай перед Enter.
- Файл, удалённый `rm`, не лежит в корзине: восстановить его обычными средствами нельзя.
- Удалить файл с дефисом в начале имени: `rm -- -странное-имя` или `rm ./-странное-имя`.
