# Службы

**Служба** (service, она же демон) — программа, которая работает в фоне всё время, пока
включён компьютер: веб-сервер, база данных, SSH, планировщик. У неё нет терминала, и запускает
её не человек, а система.

Ты уже видел, что фоновые задания умирают вместе с терминалом. Службе так нельзя, поэтому ею
управляет **systemd** — процесс с PID 1:

1. при загрузке он запускает службы, которым положено работать;
2. следит за ними: знает их PID, ловит их вывод в журнал;
3. если служба упала — может перезапустить её;
4. при выключении останавливает их по порядку.

# Юниты

Как запускать службу, systemd читает из **юнит-файла** — короткого текстового описания:

    /lib/systemd/system/      юниты, которые поставили пакеты
    /etc/systemd/system/      юниты администратора — они главнее

Внутри — что запускать и когда (подробнее разберём, когда будешь писать свою службу):

    [Service]
    ExecStart=/usr/sbin/nginx -g 'daemon off;'

    [Install]
    WantedBy=multi-user.target

Имя юнита — имя файла: `nginx.service`. Окончание `.service` в командах можно не писать.

# systemctl — пульт управления

    systemctl status nginx       жива ли, PID, последние строки журнала
    systemctl start nginx        запустить сейчас
    systemctl stop nginx         остановить сейчас
    systemctl restart nginx      остановить и запустить
    systemctl enable nginx       запускать при загрузке
    systemctl disable nginx      не запускать при загрузке
    systemctl list-units --type=service     все службы

Запомни разницу: **start/stop** — про «сейчас», **enable/disable** — про «после
перезагрузки». Это независимые вещи: служба может работать и не быть включённой в
автозапуск, и наоборот.

Менять состояние служб может только администратор — через `sudo`. Смотреть — кто угодно.

# journalctl — журнал служб

Всё, что служба печатает, systemd складывает в журнал:

    journalctl -u nginx          журнал одной службы
    journalctl -u nginx -e       сразу в конец (свежее — внизу)
    journalctl -u nginx -f       следить вживую, выйти — Ctrl+C

Служба не запустилась — первым делом смотрят сюда: причина почти всегда написана прямо там.
