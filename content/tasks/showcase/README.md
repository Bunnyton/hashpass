# showcase — брифинг автора

Это задание демонстрирует **почти все** возможности hashpass: сборку образа,
скрытый слой `/hp`, настройки, `on enter`, действия `say` / `read` / `exec`,
приёмку по `observe` (файлы), по **выводу команды**
(`observe output` — строго при `settings similarity 100`, нечётко ниже) и по
скрытому грейдеру (`check exec`), подсказки — плюс верхнеуровневое вступление и финал.

Этап 2 показывает **`variant`** (несколько решений → эталон, ОБЩИЙ для всех:
какой командой считать — не важно, важно ровно число) и **политику команд** `allow`/`deny`
(неразрешённые команды в консоли **не выполняются** — `echo 3`-подстава не сработает).

Этапы 3–4 показывают два вида скрытого грейдера: **проверку ФС/бинаря** (`command -v sl` —
пакет появился) и **проверку самой команды студента** (грейдер видит `$1` — засчитывается,
когда `sl` действительно запущен, а не только установлен).

---

Всё идёт *вживую* в терминале — включая `hint output "..."` и приёмку по
выводу команды: консоль записывает вывод и передаёт его хосту, так что этап 2
принимается по самому `stdout` вашей команды.
Нажмите Enter, чтобы продолжить.
