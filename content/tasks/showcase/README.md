# showcase — брифинг автора

Это задание демонстрирует **почти все** возможности hashpass: сборку образа,
скрытый слой `/hp`, настройки, voice, `on_enter`/`on_pass`, действия
`say` / `read` / `exec`, приёмку по `observe` (файлы), по **выводу команды**
(`observe output` — строго при `settings similarity 100`, нечётко ниже) и по
скрытому грейдеру, подсказки (в том числе `hint output` — по выводу) и react —
плюс верхнеуровневые действия-вступление и действия-финал.

Этап 2 показывает ещё два приёма: **`variant`** — несколько разных решений, из
которых выводится эталон, ОБЩИЙ для всех (какой командой считать — не важно,
важно ровно число), и **политику команд** `allow`/`deny` — приёмка только
разрешёнными командами (`echo 3`-подстава не проходит: посчитать надо по-настоящему).

---

Всё идёт *вживую* в терминале — включая `hint output "..."` и приёмку по
выводу команды: консоль записывает вывод и передаёт его хосту, так что этап 2
принимается по самому `stdout` вашей команды.
Нажмите Enter, чтобы продолжить.
