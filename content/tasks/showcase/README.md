# showcase — брифинг автора

Это задание демонстрирует **почти все** возможности hashpass: сборку образа,
скрытый слой, настройки, `on enter`, действия `say` / `read` / `exec`,
приёмку по `observe` (файлы), по **выводу команды**
(`observe output` — строго при `settings similarity 100`, нечётко ниже), наличие файла
(`observe bool`), подсказки — плюс верхнеуровневое вступление и финал. Всё проверяется прямо в
Taskfile, без скриптов проверки.

Шаг 2 показывает **`variant`** (несколько решений → эталон, ОБЩИЙ для всех:
какой командой считать — не важно, важно ровно число) и **политику команд** `allow`/`deny`
(неразрешённые команды в консоли **не выполняются** — `echo 3`-подстава не сработает).

Шаги 3–4 показывают приёмку по **наличию файла** — `observe bool /usr/games/sl` (пакет
поставлен) — и **по самой команде студента** — `accept cmd "sl" ok` (принимается сам запуск
`sl`). Шаг 5 — ответ в файле (`observe /home/student/secret`).

---

Всё идёт *вживую* в терминале — включая `hint output "..."` и приёмку по
выводу команды: консоль записывает вывод и передаёт его хосту, так что шаг 2
принимается по самому `stdout` вашей команды.
