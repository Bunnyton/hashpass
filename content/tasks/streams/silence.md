# Тишина

Каждому потоку — свой номер: `0` — ввод (stdin), `1` — обычный вывод (stdout),
`2` — ошибки (stderr). Номер ставят перед `>`; `>` без номера — это `1>`.

Поток можно направить **в другой поток**: `2>&1` значит «ошибки — туда же, куда
сейчас идёт обычный вывод». Порядок важен — перенаправления читаются слева
направо.

А чтобы выбросить вывод совсем, есть особый файл `/dev/null`: всё, что в него
пишут, исчезает.
