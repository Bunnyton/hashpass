# sudo — «superuser do»

В Linux у каждого пользователя своя песочница. Есть, однако, один
пользователь, у которого ограничений почти нет — **root**, суперпользователь.

Чтобы не входить каждый раз под ним, придумали `sudo`:

    sudo touch /etc/hosts

Команда выполнится от имени root. На «настоящей» машине `sudo` спросит твой
пароль; здесь, в учебном контейнере, — не спрашивает и запускает сразу.

## Задание

Два этапа:

1. Создай файл `/home/file.txt`. Обычному пользователю в каталоге `/home`
   писать нельзя.
2. Удали этот файл. Он создан root'ом.

Нажми **Enter**.
