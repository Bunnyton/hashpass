# sudo — «superuser do»

В Linux у каждого пользователя своя песочница. Есть, однако, один
пользователь, у которого ограничений почти нет — **root**, суперпользователь.

Чтобы не входить каждый раз под ним, придумали `sudo`:

    sudo touch /etc/hosts

Команда выполнится от имени root, но пароль запрашивается у вас
(для `student` пароль — `student`).

## Задание

Два этапа:

1. Создайте файл `/home/file.txt`. Обычному пользователю в каталоге `/home`
   писать нельзя — понадобится `sudo`.
2. Удалите этот файл. Он создан root'ом, обычный `rm` не справится.

Нажмите **Enter**.
