# Временные файлы

Программам постоянно нужно место «на минутку»: распаковать архив, собрать промежуточный
файл, положить кусок загрузки. Для этого есть два каталога:

    /tmp       для совсем временного: может исчезнуть при перезагрузке
    /var/tmp   для временного, но подольше: перезагрузку переживает

Писать в них может любой пользователь, а удалять — только своё.

# Где живёт каталог

Каталог может лежать на одном диске, на другом, в сети или вообще в памяти. Откуда он
взялся, показывает `df` — «disk free»:

    $ df -h /home
    Filesystem      Size  Used Avail Use% Mounted on
    /dev/sda2       457G  120G  314G  28% /

Первый столбец — **что** смонтировано, последний — **куда**. Здесь /home — часть
корневого раздела на диске /dev/sda2.

Перезагружать машину по-настоящему здесь нельзя — консоль закроется. Перезагрузку
изображает команда `restart`.
