# dd — целые строки

Строки удаляют так часто, что для этого есть отдельная команда — удвоенный оператор:

    dd     удалить строку
    3dd    удалить три строки подряд, начиная с текущей

Ошибся — не страшно:

    u        отменить последнее действие (undo), можно нажимать много раз
    Ctrl+R   вернуть отменённое (redo)
