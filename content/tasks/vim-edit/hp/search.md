# Поиск и прыжки

В длинном файле листать стрелками — долго. vim прыгает сразу туда, куда нужно:

    /текст   найти вниз по файлу, Enter
    ?текст   найти вверх
    n        следующее совпадение
    N        предыдущее

    gg       в начало файла
    G        в конец файла
    42G      на строку 42 (или :42)
    Ctrl+G   показать, где ты и сколько всего строк

Номера строк у тебя уже слева. А найденное подсвечивается — убрать подсветку: `:noh`.
