# Шпаргалка: язык vim

← [Язык vim: операторы, движения, поиск](../wiki.md)

## Операторы

| Клавиша | Что делает | Удвоенная — на всю строку |
|---|---|---|
| `d` | удалить (в карман) | `dd` |
| `c` | удалить и сразу вставка | `cc` |
| `y` | скопировать | `yy` |

## Движения

| Клавиша | Докуда |
|---|---|
| `w` | начало следующего слова |
| `e` | конец слова |
| `b` | начало слова назад |
| `0` / `$` | начало / конец строки |
| `gg` / `G` | начало / конец файла |
| `42G` | строка 42 |
| `/текст` | следующее «текст» |

Оператор + движение: `dw`, `d$`, `ce`, `y$`, `dG`. Число повторяет: `d3w`, `3dd`.

## Одиночные команды

| Клавиша | Что делает |
|---|---|
| `x` | удалить символ |
| `r` + символ | заменить символ |
| `p` / `P` | вставить после / перед |
| `D` / `C` | как `d$` / `c$` |
| `.` | повторить последнюю правку |
| `u` / `Ctrl+R` | отменить / вернуть |
| `n` / `N` | следующее / предыдущее совпадение |
| `Ctrl+G` | где я в файле |
| `:noh` | убрать подсветку поиска |
