# Что откроет ./task.sh

`./task.sh` запускает vim сразу с двумя файлами, бок о бок — так же сделает `vim -O файл1 файл2`:

    ┌───────────────────────┬───────────────────────┐
    │ edit.txt              │ true.txt              │
    │ испорченный —         │ образец —             │
    │ его исправляешь ты    │ только для чтения     │
    └───────────────────────┴───────────────────────┘

Курсор стоит в одном окне за раз. Переключиться — **Ctrl+w**, потом **l** (в правое окно) или
**h** (в левое): «окно» плюс знакомое направление.

# Как увидеть разницу

Глазами сравнивать сорок строк — долго. vim умеет сравнивать сам: набери **:diffthis** в одном
окне, перейди в другое и набери там тоже. Теперь:

1. строки, которые отличаются, подсвечены;
2. внутри строки ярче подсвечены именно те символы, которые разные;
3. окна листаются вместе.

После правок подсветка иногда отстаёт — **:diffupdate** пересчитает её.

# Как проверить и выйти

Правишь тем, что уже знаешь: `x`, `i`, `A`, `dw`, `cw`, `r`, `dd`, `p`.

1. **:w** — сохранить edit.txt;
2. **:!./check.sh** — запустить проверку, не выходя из vim (`:!` выполняет команду
   оболочки). «Внимательнее, салага!» — различия ещё есть; Enter вернёт в vim;
3. **:qa** — выйти из обоих окон сразу (`:wqa` — сохранив всё).

Если запутался, учебник vim всегда под рукой: `vimtutor -l ru`.
