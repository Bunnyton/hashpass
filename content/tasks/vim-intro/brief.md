# VIM

      _   ________  ___
     | | / /  _/  |/  /
     | |/ // // /|_/ /
     |___/___/_/  /_/

Когда-то люди придумали настолько мощный текстовый редактор, что его до сих пор используют
вместо IDE. Суть в том, что он превращает каждое нажатие клавиши в осмысленное действие:
в три нажатия удалить весь текст, два слова, пятнадцать символов — и многое другое.

Познакомиться с ним помогает встроенный учебник — его можно запустить прямо здесь:

    vimtutor -l ru -c 1
    vimtutor -l ru -c 2
    vimtutor -l ru -c 3 ...

А ещё есть проект openvim, адаптированный на русский язык:
http://185.212.148.108:8889

Чтобы приступить к заданию:

    ./task.sh
