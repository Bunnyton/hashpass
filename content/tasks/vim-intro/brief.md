# Те самые три буквы...

      _   ________  ___
     | | / /  _/  |/  /
     | |/ // // /|_/ /
     |___/___/_/  /_/

Когда-то придумали настолько мощный текстовый редактор, что до сих пор
его используют вместо IDE. Он позволяет превратить каждое нажатие
клавиши в осмысленное действие.

Стандартный туториал запускается так:

    vimtutor        # английский
    vimtutor ru     # русский

Есть и более дружелюбный, интерактивный проект openvim
(http://openvim.com/), адаптированный на русский.

## Задание

Запустите `vimtutor` и пройдите хотя бы первый урок. Выход из vim:

    :q      # если ничего не редактировали
    :q!     # если редактировали и не хотите сохранять
    :wq     # если хотите сохранить и выйти

Нажмите **Enter**.
