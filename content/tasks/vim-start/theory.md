# vim

Тебе ещё не раз придётся править файлы прямо в терминале: на сервере нет мыши, окон и
«Блокнота». Зато почти везде есть **vim** — редактор, которому больше тридцати лет и который
до сих пор выбирают вместо IDE.

Почему его боятся: в vim клавиши **не печатают буквы**, пока ты не попросишь. Вопрос «как выйти
из vim» на Stack Overflow посмотрели больше трёх миллионов раз.

Почему его любят: каждая клавиша — команда. `dd` — удалить строку, `dw` — слово, `5j` — пять
строк вниз. Руки не уходят с клавиатуры, а правка в три нажатия, которая в обычном редакторе
заняла бы минуту мышью.

---

# Режимы

У vim несколько режимов, и в каждом клавиши значат разное:

            i, a, A                     :
      ┌──────────────────┐     ┌──────────────────┐
      │                  ▼     │                  ▼
    ОБЫЧНЫЙ           ВСТАВКА    ОБЫЧНЫЙ     КОМАНДНАЯ СТРОКА
      ▲                  │     ▲                  │
      └──────────────────┘     └──────────────────┘
              Esc                  Enter или Esc

1. **обычный** (normal) — в нём vim открывается. Клавиши — команды: двигаться, удалять,
   копировать;
2. **вставка** (insert) — клавиши печатают текст, как в любом редакторе. Внизу экрана
   написано `-- INSERT --`;
3. **командная строка** — набираешь `:` и команду внизу экрана, Enter — выполнить.

Запомни главное: **Esc всегда возвращает в обычный режим**. Не понимаешь, что происходит, —
жми Esc.

# Как выйти

Выход — команда командной строки. Из обычного режима:

    :q        выйти (vim не даст, если есть несохранённые правки)
    :q!       выйти и выбросить все правки
    :w        сохранить, не выходя
    :wq       сохранить и выйти

Двоеточие, буквы, Enter. Если не срабатывает — сначала Esc.

Открыть файл: `vim имя_файла`.
