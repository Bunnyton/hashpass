# Где лежит программа

Команда — исполняемый файл, найденный по PATH, слева направо. Студент делает из своего скрипта
команду в /usr/local/bin, добавляет в PATH каталог bin вендора, меняет каталоги местами, чтобы
отвечал report 2.1, — и убеждается, что чужой каталог впереди PATH подменяет даже whoami.
