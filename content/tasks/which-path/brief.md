# Где лежит программа

Команда — это файл. Когда ты набираешь имя, оболочка ищет файл с таким именем в каталогах
из переменной `PATH`:

    $ echo $PATH
    /usr/local/bin:/usr/bin:/bin

Ищет **слева направо** и запускает **первый** найденный. Остальные с тем же именем она
даже не видит.

Спросить, что запустится, можно у самой оболочки:

    $ which python3
    /usr/bin/python3
    $ type ls
    ls is aliased to `ls --color=auto'

`type` честнее: он знает и про псевдонимы, и про встроенные команды оболочки.
