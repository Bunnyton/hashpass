# bash помнит, где что нашёл

Обходить PATH на каждую команду — долго, поэтому bash **запоминает**: «report — это
/usr/local/bin/report». Если файл оттуда убрали или переложили, bash по старой памяти
идёт туда и получает «No such file or directory».

Что он помнит, покажет `hash`, а забыть всё велит `hash -r`. Новая оболочка начинает
с пустой памятью.
