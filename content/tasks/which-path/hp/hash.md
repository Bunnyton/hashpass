# bash помнит, где что нашёл

Обходить PATH на каждую команду — долго, поэтому bash **запоминает**: «whoami — это
/usr/bin/whoami». Пока помнит — в PATH больше не заглядывает. Положили файл с тем же именем в
каталог левее — bash его не заметит. Убрали файл, который он запомнил, — пойдёт туда по старой
памяти и получит «No such file or directory».

Что он помнит, покажет `hash`, а забыть всё велит `hash -r`. Новая оболочка начинает
с пустой памятью.
