# Кто первый, тот и report

Теперь `report` есть в двух каталогах PATH. Оболочка перебирает их **слева направо** и
останавливается на первом найденном файле — каталог, дописанный в конец, проигрывает тем, что
стоят раньше.

Кто сейчас выигрывает, покажет `type -a имя`: все найденные по порядку, первый — тот, что
запустится.
