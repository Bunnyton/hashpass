# Свой каталог в PATH

Класть каждую программу в `/usr/local/bin` — долго, а у вендора в `bin` их целый набор. Проще
добавить в `PATH` весь каталог. `PATH` — обычная переменная, и её можно менять. Каталог
добавляют **к** старому значению, иначе пропадут все команды, даже `ls`:

    export PATH="$PATH:/opt/game/bin"     старое + новый каталог в конце

Так он живёт, пока жива эта оболочка. Каждая новая `bash` при старте читает **`~/.bashrc`** и
выполняет его строки, как будто ты набрал их сам, — значит, чтобы было навсегда, эту строку
дописывают в конец `~/.bashrc`. А чтобы и текущая оболочка прочитала файл заново, не
перезапускаясь: `source ~/.bashrc`.
