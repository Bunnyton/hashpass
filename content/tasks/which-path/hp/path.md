# Две версии — один PATH

Как дописать каталог в PATH и сделать это навсегда, ты уже знаешь. Здесь важен **порядок**:
оболочка перебирает каталоги PATH слева направо и останавливается на первом найденном файле.
Каталог, добавленный в конец, проиграет тем, что стоят раньше.

Кто сейчас выигрывает, покажет `type -a имя`: все найденные по порядку, первый — тот, что
запустится.
