# Почему сработало

Ты набрал просто `report`, без пути, — а оболочка нашла `/usr/local/bin/report`. Она ищет файл
с таким именем в каталогах из переменной `PATH`:

    $ echo $PATH
    /usr/local/bin:/usr/bin:/bin

Ищет **слева направо** и запускает **первый** найденный. Нет ни в одном каталоге — `command
not found`, даже если файл лежит в соседнем. Поэтому report из домашнего каталога по имени не находился, а из
`/usr/local/bin` — нашёлся.

Спросить, что запустится, можно у самой оболочки:

    $ which python3
    /usr/bin/python3
    $ type ls
    ls is aliased to `ls --color=auto'

`type` честнее: он знает и про псевдонимы, и про встроенные команды оболочки (`cd` — не файл,
его не найти ни в одном каталоге: менять каталог самой оболочки может только она сама).
