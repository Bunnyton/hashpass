# Столбцы и строки

Конфиги и вывод команд в Linux — это таблицы из текста. Из таблицы часто нужен
один столбец. Его вырезают:

    cut -d: -f1 /etc/passwd          # столбцы разделены «:», нужен первый
    ls -l | awk '{print $9}'         # столбцы разделены пробелами, нужен девятый

`cut` режет по одному символу-разделителю, `awk` — по любым пробелам.
