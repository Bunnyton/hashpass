# xargs

Бывает, команду нужно выполнить с **каждой** строкой из конвейера — а сама
команда принимает только один аргумент или вообще не читает ввод. Для этого
есть `xargs`: он берёт строки и подставляет их в команду.

    ls | grep -v .txt | xargs rm                     # rm со всеми именами сразу
    ls | grep .mp3 | xargs -I {} cp {} ./music/      # cp для каждого файла отдельно

`-I {}` значит «выполни команду для каждой строки, подставив её вместо `{}`».
Символ может быть любым: `-I % cp % ./music/` работает так же.
