Данный проект призван облегчить освоение пользователями Linux. При помощи данного проекта легко можно создавать интерактивные задания под Linux.

Механизм приема задания заключается в фиксации текущего состояния системы. Если система (а вместе с ней и вывод последней команды) приняла необходимое состояние, то пользователь получает ключ.

Проект также оснащен всеми необходимыми инструментами для тонкого управления и [Создания заданий](Создание%20заданий%20(tasks).md):
- [Хуки для обработки команд до их выполнения](Хуки%20(hooks).md)
- [Хуки для обработки вывода (файлов и команд) до получения от них хэша для фиксации состояния](Создание%20заданий%20(tasks).md)
- [Создание образов](Образы%20(images).md)
- [Приложение для запуска заданий в простом и понятном режиме](Приложение%20для%20запуска%20заданий%20(Production).md)

Для запуска среды исполнения используется systemd-nspawn + overlay
