# Phase 1 — CLI/command split (`hashpass` student / `hashengine` author)

**Spec:** `docs/superpowers/specs/2026-09-08-hashpass-hashengine-pool-design.md` (§4.1, §14.1).

**Goal:** Two entry points — `hashpass` (student) and `hashengine` (author) — as thin argparse
front-ends over the existing `hashpass.cli` command functions. Shared core keeps the `hashpass`
import namespace (no mass rename). One distribution for now. **No behavior change** to any existing
command; only the command that hosts it moves.

**Architecture:** `hashpass.cli` stays the command library (all `cmd_*` + helpers unchanged). Two
new thin modules own only argument parsing + the error boundary:
- `hashpass.student_cli:main` → `run`, `list`(=images), `pull`, `login`, no-arg `task_mode`.
- `hashengine.cli:main` → `build`, `push`, `serve`, `login`, `images`.
`login`/`pull`/`images` legitimately appear in both (same functions); the real divergence is
build/push/serve (engine) vs run/task_mode (student). `register` and the parallel pull land in
Phases 2/5.

## Global constraints (from spec §3)

No 185.x deploy; local build/test only; push to origin allowed; Python 3.13; stdlib only;
network calls mockable + fail-quiet. Phase 1 touches none of the network paths.

## File structure

- Create `src/hashengine/__init__.py`, `src/hashengine/cli.py`, `src/hashengine/__main__.py`.
- Create `src/hashpass/student_cli.py`.
- Modify `src/hashpass/cli.py` — remove the top-level `main`/`build_parser`/`_dispatch` (relocated
  into the two front-ends); keep every `cmd_*` and helper.
- Modify `src/hashpass/__main__.py` — point at `student_cli.main`.
- Modify `pyproject.toml` — two `[project.scripts]`.
- Modify `Makefile` — keep `install` (both scripts); add `install-student` (editable install; a
  comment notes true student-only packaging arrives with Phase 8).
- Modify tests that drive `hashpass.cli.main([...])`: `tests/test_cli.py`, `tests/test_cli_e2e.py`.

## Tasks

### Task 1 — `hashengine` thin CLI
**Files:** create `src/hashengine/__init__.py`, `src/hashengine/cli.py`, `src/hashengine/__main__.py`.
- `cli.py`: `build_parser()` with subcommands `build` (taskfile, `-t/--tag`), `push` (ref,
  registry), `serve`, `login` (registry, `-u/--user`), `images`; `main(argv=None)` builds env,
  dispatches to `hashpass.cli.cmd_build/cmd_push/cmd_serve/cmd_login/cmd_images`, with the SAME
  try/except error boundary and `_EXIT_ABORTED` as today's `hashpass.cli.main`.
- `__main__.py`: `from hashengine.cli import main; raise SystemExit(main())`.
- **Test:** `tests/test_hashengine_cli.py` — `main(["images"])` on an empty env prints the header
  and returns 0; `main([])` (no subcommand) returns 0 without raising; unknown command exits non-zero.

### Task 2 — `hashpass.student_cli`
**Files:** create `src/hashpass/student_cli.py`.
- `build_parser()` with `run` (ref), `list` (alias of images), `pull` (ref, registry),
  `login` (registry, `-u/--user`); `main(argv=None)`: env; **no subcommand → `task_mode`**;
  dispatch `run→cmd_run`, `list→cmd_images`, `pull→cmd_pull`, `login→cmd_login`; same error boundary.
- **Test:** `tests/test_student_cli.py` — `main([])` with no tasks returns 0 (task_mode empty);
  `main(["list"])` prints the header; unknown command exits non-zero.

### Task 3 — slim `hashpass.cli` + repoint `-m hashpass`
**Files:** modify `src/hashpass/cli.py`, `src/hashpass/__main__.py`.
- Remove `main`, `build_parser`, `_dispatch`, `_EXIT_ABORTED` from `cli.py` (now duplicated, tiny,
  in the two front-ends). Keep all `cmd_*` + helpers + constants.
- `__main__.py` → `from hashpass.student_cli import main; raise SystemExit(main())`.
- **Test:** existing tests calling `hashpass.cli.cmd_*` still pass unchanged (function-level API kept).

### Task 4 — packaging entry points
**Files:** modify `pyproject.toml`.
- `[project.scripts]`: `hashpass = "hashpass.student_cli:main"`, `hashengine = "hashengine.cli:main"`.
- `packages.find where=["src"]` already discovers `src/hashengine`; confirm.
- **Test:** `python -c "import hashengine.cli, hashpass.student_cli"` imports clean (add to smoke).

### Task 5 — Makefile
**Files:** modify `Makefile`.
- `install` unchanged (editable, both scripts). Add `install-student` (same editable install for
  now; comment: student-only dist arrives with Phase 8). Update `help`.

### Task 6 — migrate the two `cli.main` test callers
**Files:** modify `tests/test_cli.py`, `tests/test_cli_e2e.py`.
- `cli.main(["build", …])` → `hashengine.cli.main(["build", …])`.
- `cli.main(["images"])` → `hashengine.cli.main(["images"])` (engine-side listing).
- Keep everything else. Run `make test` — all fast tests green; `ruff` clean.
