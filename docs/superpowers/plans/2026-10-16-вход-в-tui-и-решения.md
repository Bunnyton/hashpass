# Вход в TUI, попытки и решения — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** вход/регистрация/relogin внутри Textual TUI; живые сессии попыток с выводом на пул;
решение = зачтённая сессия, видно в TUI (`p`), на сайте и подтягивается на новое устройство.

**Architecture:** сервер получает `AttemptStore` (файл на сессию) и маршруты `/attempt`,
`/solutions`, `/solution/<ref>`; клиент — `account.py` (вход без I/O), `attempts.py`
(аплоадер + outbox + синхронизация решений), `auth_screens.py` и `SolutionViewer` в TUI.
Сайт: матрица `/web` с тремя состояниями, `/web/history` с решением и попытками с выводами.

**Tech Stack:** Python 3.13, Flask + Jinja, Textual, pytest (`tier1`/`tier2` маркеры), ruff.

**Spec:** `docs/superpowers/specs/2026-10-16-вход-в-tui-и-решения-design.md`

## Global Constraints

- Весь UI-текст по-русски; идентификаторы/коммиты — по-английски.
- Вывод: 16 КБ на команду (`_MAX_OUTPUT = 16 * 1024`), 1000 команд, 512 КБ на сессию,
  30 незачтённых сессий на задачу; зачтённые не удаляются.
- «Идёт сейчас»: `final` пуст и `updated` < 60 с назад.
- Старый клиент ↔ новый сервер и новый клиент ↔ старый сервер работают (404 → молча).
- Прод 135.106.177.228 не трогать.
- Тесты гонять с `PYTHONPATH=src` (editable install может быть чужой копией).

## Review Focus

- Пул недоступен во время задания → консоль не тормозит, записи в outbox, досылаются позже.
- Студент A запрашивает `/solution/<ref>?user=B` → 403; на сайте студенту `/web/history` закрыт.
- Аккаунт удалён админом при живом токене → TUI открывает `LoginScreen`, не падает.
- Вывод с `</pre><script>` → экранирован на `/web/history`.
- Повторная/запоздалая отправка того же `seq` → без дублей (409 + досылка с нужного места).

### Task 1: AttemptStore на сервере

**Files:**
- Create: `src/hashpass/registry/attempt_store.py`
- Test: `tests/registry/test_attempt_store.py`

**Interfaces — Produces:**
```python
class AttemptStore:
    def __init__(self, root: Path) -> None
    def append(self, user: str, ref: str, session_id: str, seq: int,
               entries: list[dict], *, final: str | None = None, now: float | None = None) -> int
        # returns new length; raises SeqMismatch(have: int) if seq != current length
    def finish(self, user, ref, session_id, final: str, *, now=None) -> None
    def sessions(self, user: str, ref: str) -> list[dict]      # newest first, full records
    def summary(self, user: str) -> dict[str, dict]            # ref -> {sessions, passed, live}
    def solution(self, user: str, ref: str) -> dict | None     # latest passed session
    def solutions(self, user: str) -> dict[str, dict]          # ref -> {session_id, at}
    def delete_user(self, user: str) -> None
def is_live(rec: dict, now: float) -> bool
def sanitize_entries(raw: object) -> list[dict]                # command/output/ts/typing/pasted, capped
```
Запись: `{ref, session_id, started, updated (epoch float), final, truncated, entries}`.

- [ ] Тесты: append с seq=0 → 2 записи; повтор seq=0 → `SeqMismatch(have=2)`; лимит 16 КБ
  вывода обрезан с `…обрезано`; >512 КБ → `truncated=True`, лишнее отброшено; ротация:
  31-я незачтённая сессия удаляет самую старую, `passed` выживает; `solution` берёт
  последнюю passed; `is_live` по 60 с; `ref` с `/` и `:` → безопасное имя каталога.
- [ ] Реализация, `pytest tests/registry/test_attempt_store.py` зелёный, коммит.

### Task 2: маршруты `/attempt`, `/solutions`, `/solution/<ref>`, связь с `/submit`

**Files:**
- Modify: `src/hashpass/registry/server.py` (accessor `attempts()`, `_register_routes`,
  `_route_submit`, `_web_users_delete*`)
- Modify: `src/hashpass/registry/remote.py` (`attempt`, `solutions`, `solution`, `submit(session_id=)`)
- Test: `tests/registry/test_attempts_routes.py`

**Interfaces — Produces (client):**
```python
RemoteRegistry.attempt(ref, session_id, seq, entries, *, final=None, token=None) -> dict  # {"length": n}
RemoteRegistry.solutions(*, token=None) -> dict[str, dict]
RemoteRegistry.solution(ref, *, user=None, token=None) -> dict
RemoteRegistry.submit(..., session_id: str | None = None)
```
Сервер: `POST /attempt` JSON `{task_ref, session_id, seq, entries, final?}` → 200
`{"length"}` | 409 `{"length": have}` | 404 неизвестный ref | 401. `session_id`
`^[0-9a-f]{32}$`. `/submit` с `session_id` и зачётом → `attempts.finish(..., "passed")`.
`GET /solutions` → `{"solutions": …}` своих. `GET /solution/<path:ref>[?user=]` — чужое
только author/admin (403), нет → 404. Удаление пользователя чистит попытки.

- [ ] Тесты: студент шлёт 2 порции, 409 при неверном seq, submit с session_id делает
  `solutions()` = {ref}, `solution()` возвращает выводы; студент B → 403 на `?user=stud`;
  неизвестный ref → 404.
- [ ] Реализация, тесты, коммит.

**Files:**

**Interfaces — Produces:**
```python
class AttemptUploader:
    def __init__(self, client, ref: str, history: list[dict], *, outbox: Path,
                 session_id: str | None = None, interval: float = 3.0) -> None
    session_id: str
    def start(self) -> None
    def close(self, final: str) -> None      # flush rest + final; on network error -> outbox
def flush_outbox(client, outbox: Path) -> int
def save_solution(env_root: Path, ref: str, record: dict) -> None
def load_solution(env_root: Path, ref: str) -> dict | None
def sync_solutions(env_root: Path, client, token: str) -> int   # also adds refs to solved.json
def safe_name(ref: str) -> str
```
`_run_pool_task`: создаёт `history=[]`, `AttemptUploader(...).start()`, передаёт `history`
в `cmd_run`; в `_submit` — `close("passed"|"abandoned")`, при зачёте `save_solution` +
`submit(session_id=...)`. 404 от `/attempt` → аплоадер выключается без outbox.

- [ ] Тесты с фейковым клиентом: порции идут по seq, 409 → досылка с `have`, URLError →
  outbox файл, `flush_outbox` досылает и удаляет; 404 → молчит; `sync_solutions` качает
  недостающее и пополняет `solved.json`. `_render_observe` кладёт `output` ≤ 16 КБ.
- [ ] Реализация, тесты, коммит.
