# Wiki заданий — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** у задания есть wiki (`wiki.md` + `wiki/`) со своей историей версий, страницами на сайте пула, правкой в браузере, тегами и поиском; `hashpass push`/`clone` отправляют и забирают её без затирания чужих правок.

**Architecture:** новое хранилище `WikiStore` на репозиторий (`<store>/.repos/<ns>/<name>/wiki/`): полные снимки версий `v<N>/` (неизменённые файлы — жёсткие ссылки) + `versions.json`. Одна операция записи `save(base, changes)` с проверкой конфликтов по страницам; ею пользуются и API клиента, и формы сайта. Маршруты — отдельный модуль `wiki_web.py` по образцу `course_web.py`; доступ — существующие `_session_user`/`_token_user` + `_may_see_repo` (чтение) и `_may_write` (правка).

**Tech Stack:** Python 3.13, Flask, Jinja2, markdown-it-py (уже есть), pytest (`tier1`).

**Spec:** `docs/superpowers/specs/2026-11-03-wiki-заданий-design.md`

## Global Constraints

- Пути wiki: только `wiki.md` и `wiki/<сегменты>`; сегмент — `[A-Za-z0-9][A-Za-z0-9._-]*`; никаких `..`, абсолютных, скрытых.
- Типы файлов: `*.md` (UTF-8) и картинки PNG/JPEG/GIF/WebP по первым байтам; SVG и прочее — отказ.
- Лимиты: файл ≤ 8 МиБ; вся wiki одной версии ≤ 64 МиБ.
- Wiki **не** входит в `task/`, `build_key`, `source.tar.gz`; правка wiki не создаёт ревизию задания.
- Чтение: вошёл + `_may_see_repo(user, repo)`; `hide_sources` не влияет. Правка: `_may_write(user, repo)`.
- Ссылки любые, кроме выполняющих код (`javascript:`, `vbscript:`, `data:` не-картинки) — их режет `validateLink` markdown-it; сырой HTML выключен; встраивание видео — только YouTube (`youtube-nocookie.com`).
- Тексты для людей — по-русски; идентификаторы, коммиты — по-английски; коммит с трейлером `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Push из папки, которую никогда не клонировали, когда на пуле wiki уже есть → отказ «скачай изменения», ничего не затёрто (Task 1 + Task 5).
2. Два автора правят разные страницы от одной версии → оба сохранения проходят, вторая версия содержит обе правки (Task 1).
3. Задание с `hide_sources` → wiki всё равно открывается у читателя; исходники — нет (Task 3).
4. Файл `wiki/x.png`, внутри которого HTML/SVG → отказ при сохранении; отдаётся с `nosniff` (Task 1 + Task 3).
5. Поиск анонимом/чужим по тексту wiki приватного задания → ничего не показывает (Task 4).

### Task 1: WikiStore — версии, проверка файлов, конфликты

**Files:**
- Create: `src/hashpass/registry/wiki_store.py`
- Test: `tests/registry/test_wiki_store.py`

**Interfaces:**
- Produces:
  - `class WikiConflict(Exception)` с полем `paths: list[str]`; `class WikiRejected(ValueError)` (плохой путь/тип/размер, текст по-русски).
  - `check_path(path: str) -> str`, `check_file(path: str, data: bytes) -> str` (возвращает `Content-Type`).
  - `class WikiStore(root: Path, name: str)` — `root` = `<store>/.repos`:
    - `head() -> int` (0 — wiki нет), `exists() -> bool`, `versions() -> list[dict]` (`{n, by, at, message, changed}`, новые сверху);
    - `files(n: int | None = None) -> dict[str, bytes]` (None = head; 0 = `{}`), `read(path, n=None) -> bytes`;
    - `changed_since(base: int) -> set[str]`;
    - `save(base: int, changes: dict[str, bytes | None], *, by: str, message: str = "") -> int` — None = удалить; пустые изменения → вернуть head без новой версии; пересечение `changes` и `changed_since(base)` → `WikiConflict`; запись под `fcntl`-блокировкой файла `wiki/.lock`, новая версия собирается во временном каталоге и переименовывается;
    - `local_changes(base: int, local: dict[str, bytes]) -> dict[str, bytes | None]` — разница `files(base)` → `local`;
    - `rebase(base: int, local: dict[str, bytes]) -> tuple[int, dict[str, bytes]]` — head + локальные изменения, конфликт → `WikiConflict`; ничего не пишет;
    - `diff(a: int, b: int) -> list[dict]` — через `merges.tree_diff(snapshot(a), snapshot(b))`;
    - `copy_to(other: "WikiStore") -> None` (форк: копия каталога с историей), `drop() -> None`.
  - `pack(files: dict[str, bytes]) -> bytes` / `unpack(blob: bytes) -> dict[str, bytes]` (tar.gz; unpack проверяет каждый путь `check_path` и лимиты).
  - `parse_tags(text: str) -> tuple[list[str], str]` — блок в начале `wiki.md`: `---\ntags: regex, grep\n---` (также `tags: [a, b]`); теги в нижнем регистре, без `#`; вернуть (теги, текст без блока).
