```
Те самые 3 буквы... 

  _   ________  ___
 | | / /  _/  |/  /
 | |/ // // /|_/ / 
 |___/___/_/  /_/  
                   


Когда-то люди придумали настолько мощный текстовый редактор, что до сих пор его используют вместо IDE. Встраивают в командную строку, браузер...

Суть в том, что он позволяет превратить каждое нажатие клавиши в осмысленное действие. 

Можно в 3 нажатия удалить весь текст, 2 слова, 15 символов и многое другое

Для того, чтобы познакомиться с ним есть стандартный vimtutor, который Вы можете запустить прямо здесь:
vimtutor -l ru -c 1
vimtutor -l ru -c 2
vimtutor -l ru -c 3...

Однако мы предлагаем воспользоваться проектом openvim, адаптированным на русский язык 

Для Вас openvim_ru доступен по адресу http://185.212.148.108:8889

Для того, чтобы приступить к заданию:
./task.sh

```

```bash
#!/bin/bash

if [[ -z "$(diff edit.txt true.txt)" ]]
then
	echo "key{}"
else
	echo "Внимательнее, салага!"
fi
```

task.sh
```bash
#!/bin/bash

vim -O ./edit.txt ./true.txt
```

```python
@command(stages=None)
def cmd_whitelist(cmd: str, stage: int):
    res = {"before": ["echo \"Команда запрещена\""]
            , "cmd": []
            , "after": []}

    cmds = parse_cmds(cmd)
    if len(cmds) == 1:
        if cmds[0] == Cmd("./check.sh") or cmds[0] == Cmd("./task.sh"):
            res = {"before": []
                    , "cmd": [cmd]
                    , "after": []}

        if cmds[0] == Cmd("ls") or cmds[0].basecmd == "vimtutor":
            res = {"before": []
                    , "cmd": [cmd]
                    , "after": []}


    return res
```
