Все пакеты устанавливаются из .deb файлов (в debian подобных linux: debian, ubuntu, linux mint). И из .rpm (arch, fedora и др.)

По сути - это архив, в котором лежат конфигурационные файлы с указанием зависимостей (других необходимых для работы пакетов), скрипт для установки, скрипт для удаления и непосредственно сами файлы.

Так вот, из этого deb пакета можно устанавливать напрямую.
Можно 2-м нажатием, но мы сделаем это из терминала

#Задание
wget http://ftp.debian.org/debian/pool/main/c/cmatrix/cmatrix_2.0-3_amd64.deb
JUST GOOGLE IT!

#Примечание
Не запускай эту команду, серьезно!
