Есть еще одна команда, с которой я не могу Вас не познакомить...

Это apt, очень важная команда для любого пользователя linux

apt - это пакетный менеджер, то есть программа, которая устанавливает и управляет пакетами (программами). 

Если нужно установить приложение, например, firefox:

sudo apt install firefox

Кстати, старая версия этой команды - apt-get, ее до сих пор можно использовать

Но откуда берутся все эти приложения? Откуда то они скачиваются?

А скачиваются они из репозиториев. Это такое хранилище приложений. в репозиторий попадают не всегда самые новые пакеты. Пакет может написать любой желающий, но его еще нужно проверить, протестировать. Отсюда есть ветки репозиториев (stable, main, restricred). Если stable - то туда попадают только хорошо оттестированные пакеты.

А репозиториев может быть несколько и содержать разные версии пакетов. Устанавливается самая свежая из репозиториев. 

Но и тут еще не все. Вместо того, чтобы каждый раз получать самые свежие пакеты терминал позволяет частично регулировать свежесть пакетов через обновление репозиториев. Пока не стало известно, что вышли новые версии пакетов, они не установятся, вместо этого будут устанавливаться те, которые были зафиксированы в последнее обновления списка репозиториев. 

То есть, если я сделал sudo apt update () 4 месяца назад, то sudo apt install firefox, установит ту версию, которая была доступна 4 месяца назад.

Если я хочу обновить список репозиториев, чтобы установить самый свежий firefox, то я делаю:

sudo apt update
sudo apt install firefox
