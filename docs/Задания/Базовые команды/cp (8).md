В качестве второго аргумента у cp может быть не только директория, но также файл. 
Это будет равносильно: "Скопируй как" (скопируй с именем файла)

Иногда нужно скопировать все содержимое директории, тут на помощь приходят ключи

Иногда же достаточно:
cp ./* dest_dir
Здесь * подменяется на содержимое в директории, то есть, если в нашей директории находятся файл file1 и file2, то:
cp ./* dest_dir        равносильно      cp ./file1 ./file2 dest_dir

Кстати, cp может принимать сколько угодно аргументов. Последний будет местом назначения.

В команде cp последний аргумент означает место, куда нужно будет скопировать файлы.

#Задание
Скопируйте все содержимое из директории dir1 в dir2

#Подсказка
Нужно решить задачу в одну команду

def not_cp_without_r(cmd: str, stage:int):
    parts = shlex.split(cmd)
    
    if parts[0] == "cp":
        parser = argparse.ArgumentParser(add_help=False)
        parser.add_argument('-r', '--recursive', action='store_true')
        
        args, _ = parser.parse_known_args(parts[1:])

        if args.recursive:
            return None

    return False
