#Скрытые файлы

В Linux существует понятие скрытых файлов, это файлы, название которых начинается с '.'
Так например скрывают конфигурационные файлы, чтобы они не мешали пользователю.

#Команды
#Опции
#Ключи

Практически у каждой команды есть опции. Они немного, а иногда значительно корректируют действия команды. Их принято называть ключами, чтобы задать ключ используется следующий формат:

команда -ключ

#Пример
Например, ls может сортировать по размеру, показывать полных формат и так далее если добавить ключ '-l'
ls -l

Если ключей несколько их можно писать слитно или раздельно. 
ls -t -l
или
ls -tl
или
ls -lt


#Задание 
Выведите информцию о файлах, используя ключ -l
```

/opt/readme2.txt
```

Ключ -l выводит более полную информацию о файлах в текущей директории, но не выводит все файлы
Чтобы вывести все файлы воспользуйтесь ключем -a (all), можно -la или -al
