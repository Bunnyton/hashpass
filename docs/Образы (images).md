Для удобства создания любых заданий используются образы. По сути - это слепок файловой системы с выставленными необходимыми переменными, значениями конфигураций и т.д. 

Образы бывают 3-х видов:
- Базовые (base)
- Промежуточные (simple)
- Задания (task)

#### Базовые образы (base)
Базовые образы - те образы, которые лежат в основе системы (lowerdir). Пока доступен только один базовый образ. В базовом образе обязательно должны быть все необходимые пакеты для совместимости (python3 и его составляющие, rsync)

Чтобы создать базовый образ:
```
sudo ./hashengine.py new
```

#### Промежуточные образы (simple)
Промежуточные образы - те, которые созданы на основе какого-либо другого образа, создаются из базовых или других simple и даже заданий. По сути - дополнительный слой, содержащий какие-либо изменения

Чтобы создать простой на основе другого
```
sudo ./hashengine.py create bunnyton/student:latest
```

Вносим изменения, затем внутри системы:
```
image update
```

Если нужно сохранить образ и выйти из системы:
```
image save
```

Если нужно отредактировать образ (любой):
```
sudo ./hashengine.py edit bunnyton/student:latest
```

Для удаления (осторожно, удаления образа удалит все образы, которые от него зависят):
```
sudo ./hashengine.py rm bunnyton/student:latest
```

#### Задания (task)
Задания - это образ с конфигурационным файлом, позволяющим отслеживать действия пользователя, и в случае достижения необходимых условий - выполнять соответствующие действия. В остальном - это такой же образ как и все остальные. В конце действия выдается ключ от задания.

Создается задание как обычный образ - смотри инструкцию по созданию заданий:
[Создание заданий (tasks)](Создание%20заданий%20(tasks).md)



#### Реестр образов (Registry)
Для хранения образов используется сервер, который умеет их сохранять и отправлять:

Чтобы посмотреть, какие образы есть в registry:
```
sudo ./hashengine.py pull
```

Чтобы получить какой-то образ (автоматически подтягиваются зависимости):
```
sudo ./hashengine.py pull bunnyton/student:latest
```

Чтобы отправить какой-то образ (название должно быть уникальным):
```
sudo ./hashengine.py push bunnyton/custom:no_latest
```
