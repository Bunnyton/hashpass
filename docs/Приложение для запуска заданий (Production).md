Под production подразумевается то, что будет видеть пользователь, который пришел, чтобы выполнять задания


#### Для пользователя
Для выполнения заданий после установки достаточно запустить 
```
sudo hashpass.py
```

Далее интерфейс подскажет что делать :)

Учетные данные от всех образов:
```
student:student
```

#### Для создателя
Для того чтобы добавить новое задание - достаточно в settings.py прописать номер задания и соответствующий ему образ (и все).


[![Watch the video](../photo/hashpass.png)](https://rutube.ru/video/private/912253505f21eac1dc4faaa60f004951/?p=KbuMQ-nRAqtgYDwNrUU65w)

#### Механизм работы ключей
Каждый пользователь вводит уникальный ник, после чего ключ вычисляется при помощи необратимой функции:
```
key_calc(masterkey + nickname + task_fullname)
```

Под task_fullname подразумевается bunnyton/image:version

Соответственно у каждого пользователя будет уникальный ключ, который в случае необходимости можно получить вручную преподавателем

Доступ к следующему заданию осуществляется в случае, если введен предыдущий ключ
